# 微電影分鏡主題（`public/microfilm/`，16 篇）

先讀上一層的 [`../README.md`](../README.md)（總入口、設計規範、指令）。本文件只記微電影主題特有的事。**已確認的決定不要再問使用者。**

## 已確認的決定

- 讀者：**從未拍過微電影的高中生**，能依頁面自學。盡量用示意畫面、一步一步跟著做；只適合講觀念的部分才純文字。
- 難度：一開始極簡單，再慢慢加概念與複雜實作。16 篇、五階段（基礎／景別／角度與焦段／運鏡／敘事與實作），第 11、12 篇為進階選讀。
- 檔名 `microfilm-<子題>-guide.html`；eyebrow「微電影分鏡入門 · 第 N 篇 · …」；等級名稱：入門／基礎／進階／實作。
- **完全不依賴器材**：讀者用手機、相機、平板都能自學。第 8 篇只講廣角／標準／望遠的視角、透視與景深差異，不列 mm 數字與手機倍率；第 10、11 篇只講每種運鏡「畫面怎麼變、觀眾感受、適合什麼情節」，不寫穩定器怎麼用、無人機法規或替代做法；第 16 篇只講鏡頭本身，不列器材清單。
- 術語：中文為主，旁註英文縮寫（mono 字型，如 ELS / LS / MS / CU / ECU）。景別名稱：大遠景、遠景、全景、中景（含膝上景、腰上景）、近景、胸上景、特寫、大特寫。第 3 篇明說「不同學校或書籍的叫法略有不同，這裡採用的是……」。
- 第 12 篇可舉常被廣泛討論的片名當「想看實例可以找」，**只寫文字，不放劇照或截圖**，不寫沒驗證的鏡頭秒數或拍攝細節。
- 這個主題沒有「官方文件」：結尾放「可自查的延伸閱讀」描述，**不放沒驗證過的外部連結**。頁尾查證文字改為「不依賴特定器材…內容整理日期」（2026-11-10）。
- 第 15 篇（分鏡編輯器）是唯一允許 `localStorage` 的子頁，key 為 `mf-practice-v1`，包 try/catch，失敗退回記憶體；另有「複製分鏡表」（Markdown 表格）。

## 難度階梯（教學設計規則）

- 第 1 篇極簡：只教分鏡圖是什麼、一格的三個欄位（畫面／動作對白／鏡頭說明）、親手畫出第 1 格。箭頭只教「人物移動」與「鏡頭移動」兩種；推拉、橫移、軸線等細緻符號分散到第 9–13 篇各自再教。
- 第 2 篇分兩層：前半只講比例＋三分法；頭上空間、視線空間放後半，標「再進一步」。
- 每篇內部三級：Level 1 跟著做 → Level 2 自己改 → Level 3 挑戰；每篇只新增 1–2 個新概念。
- 第 6、12、13 篇內容多，依「簡單到複雜」排序（第 6 篇：雙人 → 過肩 → 反應 → 插入 → POV）。
- 前面的篇章不引用後面才教的概念（必要時只說「第 N 篇會教」）。

## 示範劇本《紙條》（第 1–13 篇共用）

2 位角色（小安、小宇）、2 個場景（放學走廊、校門口），六個段落：
1. 放學鐘響，走廊空蕩，小安背著書包快步走（行走 → 跟拍／橫移）。
2. 她停在置物櫃前，看見櫃門縫夾著一張紙條（插入鏡頭）。
3. 她讀紙條，表情從疑惑變驚訝（特寫／反應）。
4. 窗外，小宇在校門口低頭看手機等人（主觀鏡頭 POV）。
5. 小安衝下樓（追逐／搖攝）。
6. 兩人在校門口面對面，小安遞出紙條，兩人笑了（雙人／過肩／正反打）。

第 14 篇的八種情節各用獨立小場景；第 15 篇回到《紙條》做總實作，讓讀者能改成自己的劇本。

## 畫風與繪圖積木

- 全部內嵌 SVG，只用站內色票，零外部圖片；風格是幾何剪影（圓形頭、圓角身體、簡單走廊／校門口背景）。每個 SVG 要有 `role="img"` 與 `aria-label`。
- **示意畫面一律由 `kit.js` 產生**（世界座標 320×180，地平線 y=130）。新增圖形請擴充 kit，不要手寫座標。`kit.js` 是單一來源：瀏覽器與 Node 共用，互動頁以 `inline_kit()` 內嵌，靜態頁在組頁時由 Node 預先算出 SVG。
  - 場景：`hallway`、`gate`、`blank`、`none`。角色 `who`：`an`（小安，橘）／`yu`（小宇，綠）／`x`（路人）。
  - 姿勢 `pose`：stand / walk / run / read / phone / wave。表情 `expr`：neutral / smile / surprise / puzzled / sad / angry / fear。朝向 `facing`：r / l / f / b。
  - 景別用 `zoom`、`cx`、`cy`；`grid:true` 疊三分線。其他函式：`angleShot`（第 7 篇）、`lens`（第 8、10、12 篇，以距離與焦距倍率重算透視，`blur` 控制景深，**不用任何 mm 或倍率數字**）、`topdown`（第 13 篇軸線／機位俯視圖）、`camarrow`、`aerial`（空拍）、`moveFrame(name, t)`（運鏡動畫畫面，靜態與互動共用）。
- 箭頭記法（全站固定）：`A(...,"move")` 黑色實線＝人物移動；`A(...,"cam")` 橘色虛線＝鏡頭移動。運鏡箭頭：搖攝＝橫向橘色虛線；俯仰、升降＝縱向；推／拉＝四個小箭頭朝內／朝外；橫移、跟拍＝底部橫向；環繞＝弧形。
- 分鏡卡 `.sb`（畫面／動作／鏡頭，可加對白）；`.sbrow.c2/c3/c4` 排列；`.shotfig` 單張示意圖；`.lv.l1/l2/l3` 是 Level 標籤。這些 CSS 放在 `mh.py` 的 `MF_CSS`，由各頁 `defaults()` 帶入。

## 互動與動畫

- 指定的四個互動：第 3 篇拖動取景框、第 8 篇焦段滑桿、第 14 篇選情節看建議與理由（`SCENES` 資料由 Python 組成 JSON）、第 15 篇分鏡編輯器。另有第 2 篇疊層開關、第 7 篇角度切換、第 9–12 篇每種運鏡一個短動畫。
- 運鏡動畫：`animbox()` ＋ `ANIM_JS`（`mh.py`）。先放預先畫好的「起點 → 終點」靜態兩格（`mvpair()`，終點格帶橘色運鏡箭頭），再放播放／暫停與進度滑桿。`prefers-reduced-motion` 時隱藏播放鈕、不自動播放，只留滑桿。

## 檔案與工具

| 檔案 | 作用 |
|---|---|
| `m1.py` … `m16.py` | 各頁規格；開頭 `from mh import *`，`SPEC = defaults(...)`（帶入 `dir`、`topic`、`foot`、`css`） |
| `mh.py` | 微電影共用：`MF_CSS`、`defaults()`、`lv()`、`fig()`、`figrow()`、`mvpair()`、`animbox()` / `ANIM_JS` / `anim_page()` / `mvf()`、`fx_buttons()`、`feel()` |
| `svgkit.py` | `kit.js` 的薄包裝（需要 `node`）：`shot(...)`、`P()` 角色、`A()` 箭頭、`N()` 道具、`sb()` 分鏡卡、`sbrow()`、`angle()`、`lens()`、`topdown()`、`move(name, t, cam=...)` |
| `kit.js` | 繪圖積木（見上） |
| `check.py` | 單頁快速檢查：`python3 _build/microfilm/check.py angle lens --shot`（1280／390 溢出、JS 錯誤、重複 id、`http`、實際點測驗／選擇題／動畫／按鈕；`--shot` 存整頁截圖到 /tmp） |

共用的 `shared/fw.py`：`build.py` 對微電影頁面自動套用全形標點（JS 裡含反斜線的字串不會被轉，請直接寫全形）。

新增或修改一篇：改 `mN.py`（互動與動畫頁參考 `m9.py`、`m7.py` / `m8.py`、`m14.py`、`m15.py`）→ `python3 _build/build.py mN` → `python3 _build/microfilm/check.py <子題> --shot` → `python3 _build/update_index.py microfilm done N` → `python3 _build/verify.py`。

16 篇的標題、順序、等級與時間以首頁 `SITE.microfilm` 為準。
