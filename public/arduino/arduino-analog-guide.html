類比輸入:讀「多少」,不只是「有沒有」

按鈕只有兩種狀態:HIGH 或 LOW。但現實世界的很多東西是「連續」的:旋鈕轉了多少、光有多亮、溫度多高。Arduino 用類比輸入來讀這些。

三個關鍵

  • 類比輸入腳位 A0–A5:可以量 0–5 V 之間任意大小的電壓。
  • ADC(類比數位轉換器)把電壓換成數字:0 V → 0,5 V → 1023(共 1024 級,即 10 位元)。每一級約 4.9 mV。
  • analogRead(A0):讀出 A0 的數字,0–1023。

電位器:能轉動的可變電阻

電位器有三隻腳。兩個外側腳之間是一整條固定的電阻(這顆是 10 kΩ),中間腳(滑動腳)隨旋鈕在這條電阻上移動。旋鈕轉到哪裡,中間腳就把這條電阻分成上下兩段:

分壓:兩端接 5V 與 GND 時,中間腳的電壓 = 5 V × (下段電阻 ÷ 總電阻)。旋鈕轉一圈,中間腳就從 0 V 平順地變到 5 V。拖拖看:

小技巧A0 腳位量的是「中間腳的電壓」,所以中間腳必須接 A0。兩個外側腳一個接 5V、一個接 GND,哪邊接哪邊只會影響旋轉方向,不會影響能不能用。

接線:電位器(A0)加 LED(9 號腳)

電位器兩端接 5V 與 GND,中間腳接 A0;LED 接 9 號腳(有 ~,能做 PWM)。

Uno 轉了 180 度擺放:電源腳位與類比腳位(A0–A5、5V…)在上緣,數位腳位在下緣。A0 與 5V 兩條線要繞過 Uno 的左邊,才接得到麵包板。圖只畫左邊 22 欄,以欄號與 a–j 為準(手機上可以左右滑動圖)。

    換算成電壓

    同時印出數值與電壓
    // 第 9 篇:把數值換算成電壓,同時印出兩者
const int POT_PIN = A0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int value = analogRead(POT_PIN);
  float volts = value * 5.0 / 1023.0;    // 換算成伏特(5.0 要寫成小數,結果才會有小數)
  Serial.print("value = ");
  Serial.print(value);
  Serial.print("  voltage = ");
  Serial.println(volts);
  delay({gap});
}
    這一行
    它在做什麼
    float volts = value * 5.0 / 1023.0;
    數值 ÷ 1023 再乘 5,就是電壓。float 是帶小數的變數;5.0 與 1023.0 要寫小數點,否則整數除法會把小數吃掉。
    Serial.print(...) 連續幾次
    前面都用 print(不換行),最後一個用 println,同一行就印出數值和電壓。
    小技巧打開 Serial Plotter(第 8 篇)看程式一,旋鈕的變化會畫成一條曲線。

    程式二:旋鈕控制 LED 亮度

    電位器 → map() → analogWrite
    // 第 9 篇:旋鈕控制 LED 亮度
const int POT_PIN = A0;
const int LED_PIN = 9;          // 要用有 ~ 的腳位

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  int value = analogRead(POT_PIN);                  // 0–1023
  int brightness = map(value, 0, 1023, 0, 255);     // 換算成 0–255
  analogWrite(LED_PIN, brightness);                 // 用 PWM 輸出
}
    這一行
    它在做什麼
    int value = analogRead(POT_PIN);
    讀出 0–1023。
    map(value, 0, 1023, 0, 255)
    把一個範圍的數字,對應到另一個範圍。這裡把 0–1023 換成 0–255(analogWrite 能接受的範圍)。
    analogWrite(LED_PIN, brightness);
    用 PWM 輸出亮度(第 6 篇)。
    map 的五個參數
    意思
    這裡的值
    第 1 個
    要換算的數字
    value
    第 2、3 個
    原本的範圍(最小、最大)
    0, 1023
    第 4、5 個
    想換成的範圍(最小、最大)
    0, 255
    你會看到旋鈕轉到一端,LED 全暗;轉到另一端,LED 全亮,中間漸漸變化。如果方向和你想的相反,把電位器兩個外側腳對調(或把 map 後面的 0, 255 改成 255, 0)。
    注意map() 只處理整數,結果會直接捨去小數,而且不會限制數字不超出範圍。輸入的數字要在原本範圍內。

const int POT_PIN = A0;

  pinMode(LED_PIN, OUTPUT);

  int wait = analogRead(POT_PIN);   // 0–1023 毫秒

    常見卡關

    數字固定是 0,或固定是 1023
    1. 中間腳沒接到 A0,或接到了外側欄。三隻腳要在三個不同的欄,A0 的線接在中間那一欄。
    2. 兩個外側腳都接 5V,或都接 GND:一端接 5V、另一端接 GND。
    3. 電位器的腳沒插到底。
    數字亂跳,不隨旋鈕變化

    A0 沒接任何東西(浮接)時,讀到的是雜訊。檢查中間腳的綠線是否真的接在電位器中間腳的那一欄。

    數字有變化,但 LED 亮度沒有漸變

    LED 沒接在有 ~ 的腳位(第 6 篇)。確認接 9 號腳,而且程式的 LED_PIN 是 9。

    旋轉方向和我想的相反

    不是錯誤:兩個外側腳對調,方向就會顛倒。或在程式裡把 map 的輸出範圍反過來。

    數字最大只到 1000 多,或最小不是 0

    正常。電位器與 ADC 都有一點誤差,範圍可能是 3–1020。不需要為此煩惱。
