Arduino 入門 · 第 17 篇 · I2C 與 SPI

用少少的線，控制很多東西：I2C 與 SPI

用 I2C 掃描器找出裝置位址，再用 SPI 控制 74HC595 移位暫存器，用 3 條線驅動多顆 LED。

TL;DR I2C:SDA、SCL 兩條線，靠位址找裝置（Uno:A4、A5）。SPI:MOSI、SCK 加選擇線，不用位址。74HC595:SPI.transfer(位元組) 把 8 個位元移進去，鎖存腳拉高後一次輸出到 8 個腳。

兩種「用少少的線，溝通很多東西」的方法

Uno 的腳位不多。如果每一顆 LED、每一個感測器都占一個腳位，很快就不夠用。通訊協定讓你用幾條共用的線，跟很多裝置溝通。第 14 篇的 LCD 用了 I2C，這一篇再認識 SPI。

I2C
SPI
線數
2 條：SDA（資料）、SCL（時脈）
3 條 + 每個裝置 1 條選擇線：MOSI（出）、MISO（入）、SCK（時脈）、SS
怎麼找到裝置
每個裝置有位址（例如 0x27），主控端依位址叫人
用選擇線（SS / 鎖存）叫誰，沒有位址
速度
較慢（常見 100–400 kHz）
快（可到數 MHz）
Uno 上的腳位
A4 = SDA、A5 = SCL
11 = MOSI、12 = MISO、13 = SCK、10 = SS
常見裝置
LCD、OLED、許多感測器
74HC595、SD 卡、LED 矩陣、無線模組
小技巧這一篇是進階選讀。你不一定會用到，但看得懂這兩種協定，以後遇到新的模組（「它是 I2C 還是 SPI?」）就知道怎麼接、怎麼找函式庫。

I2C：用位址找到裝置，並寫一個掃描器

I2C 匯流排上每個裝置都有一個 7 位元的位址。LCD 轉接板常見的位址是 0x27 或 0x3F。不知道裝置位址時，最直接的辦法是掃描：把 1 到 126 的位址都「敲門」一次，有人回應的就是裝置。

接線沿用第 14 篇的 LCD（只要接著 Uno 的 SDA、SCL、5V、GND 就好）：

    I2C 掃描器
    // 第 17 篇:I2C 掃描器——找出匯流排上所有裝置的位址
#include <Wire.h>

void setup() {
  Serial.begin(9600);
  Wire.begin();                              // 啟動 I2C(Uno 是主控端)
  Serial.println("I2C scanner");
}

void loop() {
  int found = 0;
  for (byte address = 1; address < 127; address++) {   // I2C 位址是 7 位元:1 到 126
    Wire.beginTransmission(address);         // 試著叫這個位址
    byte error = Wire.endTransmission();     // 結束,並取得結果:0 表示有人回應
    if (error == 0) {
      Serial.print("Found device at 0x");
      if (address < 16) {
        Serial.print("0");                   // 補一個 0,讓格式整齊
      }
      Serial.println(address, HEX);
      found++;
    }
  }
  if (found == 0) {
    Serial.println("No I2C device found");
  }
  Serial.println("--- scan done ---");
  delay({gap});
}
    這一行
    它在做什麼
    Wire.begin();
    啟動 I2C,Uno 擔任主控端（負責發起溝通）。
    Wire.beginTransmission(address);
    準備對這個位址的裝置說話，也就是「敲門」。
    Wire.endTransmission();
    結束並真的送出去。回傳 0 表示對方有回應（ACK），其他數字表示沒人理（或出錯）。
    Serial.println(address, HEX);
    以十六進位印出位址（第 8 篇學過）。0x27 的 0x 只是標示這是十六進位。
    你會看到Serial Monitor(baud 9600)印出 Found device at 0x27（你的轉接板可能是 0x3F）。沒接任何 I2C 裝置時，印 No I2C device found。
    小技巧如果之後用「LiquidCrystal I2C」函式庫，LiquidCrystal_I2C lcd(0x27, 16, 2); 裡的位址就填掃描出來的數字。第 14 篇用的 hd44780 函式庫會自己做這件事。

    SPI：用 3 條線控制 8 個輸出（74HC595）

    74HC595 在做什麼

    74HC595 是移位暫存器：有一排 8 個「抽屜」(Q0–Q7)。你用 SER 線一個位元一個位元把資料送進去，每送一個位元，SRCLK（時脈）就「敲」一下，所有資料往下移一格。送滿 8 個位元後，RCLK（鎖存）敲一下，8 個位元同時出現在 8 個輸出腳。

    Uno 的 SPI 硬體會自動做送位元與敲時脈這些事，你只要SPI.transfer(一個位元組)。一個位元組有 8 個位元，剛好對應 8 個輸出。

    程式：SPI 跑馬燈

    SPI 控制 74HC595,4 顆 LED 由左到右
    // 第 17 篇:用 SPI 控制 74HC595,讓 4 顆 LED 由左到右依序亮
#include <SPI.h>                    // SPI 函式庫(內建)

const int LATCH_PIN = 12;           // 接 74HC595 的 RCLK(鎖存)
const byte patterns[] = {           // 每個位元組的每一個位元,對應一個輸出腳的亮 / 滅
  0b00010000,                       // 只有 Q4 亮 → 最左邊的 LED1
  0b00001000,                       // 只有 Q3 亮 → LED2
  0b00000100,                       // 只有 Q2 亮 → LED3
  0b00000010                        // 只有 Q1 亮 → LED4
};

void setup() {
  pinMode(LATCH_PIN, OUTPUT);
  SPI.begin();                      // 啟動 SPI(11 號腳 MOSI、13 號腳 SCK 由函式庫接管)
}

void loop() {
  for (int i = 0; i < 4; i++) {
    digitalWrite(LATCH_PIN, LOW);   // 鎖存腳先拉低:準備送資料
    SPI.transfer(patterns[i]);      // 送出 1 個位元組(8 個位元),晶片依序把它們移進去
    digitalWrite(LATCH_PIN, HIGH);  // 鎖存腳拉高:晶片把剛移進去的 8 個位元,一次推到輸出腳
    delay({step});
  }
}
    這一行
    它在做什麼
    #include <SPI.h>
    SPI 函式庫（Arduino 內建）。
    0b00010000
    二進位寫法：0b 開頭，後面是 8 個位元。只有 Q4 那個位元是 1，所以只有 Q4 輸出 HIGH,LED1 亮。
    SPI.begin();
    啟動 SPI。11 號腳（MOSI）與 13 號腳（SCK）從此由 SPI 硬體控制。
    digitalWrite(LATCH_PIN, LOW);
    鎖存腳拉低：準備接收新資料。
    SPI.transfer(patterns[i]);
    送出 1 個位元組。8 個位元依序移進晶片（最高位元先送，最後落在 Q7）。
    digitalWrite(LATCH_PIN, HIGH);
    鎖存腳拉高：8 個位元一次推到輸出腳，LED 才會變化。少了這行，資料只留在晶片裡面、輸出不變。
    你會看到四顆 LED 由左到右依序亮起（紅 → 黃 → 綠 → 藍），一次只亮一顆，不斷重複。
    小技巧一個位元組控制 8 個輸出。想讓兩顆同時亮，把對應的位元都設成 1：例如 0b00011000 讓 LED1 與 LED2 一起亮。想接 8 顆 LED，就接滿 Q0–Q7（也可以串接多顆 74HC595，控制幾十個輸出，只用同樣 3 條線）。

    常見卡關

    四顆 LED 都不亮
    1. 晶片方向：缺口朝左，16 腳接 5V。
    2. OE（13 腳）必須接 GND：接到 5V 會停用輸出。
    3. SRCLR（10 腳）必須接 5V：接到 GND 會一直清除。
    4. VCC、GND 是否接好；b-12 的 GND 線是否真的接到。
    5. 程式有沒有上傳成功，LATCH_PIN 是 12。
    燈亮了，但順序亂掉或亮到別顆
    1. 輸出線（j8→j14 等）有沒有接到對的欄。
    2. 資料（14 腳）與時脈（11 腳）是不是接反：SER 接 11 號腳、SRCLK 接 13 號腳。
    3. LED 方向、電阻是否在同一欄。
    燈一直閃、或亮一些怪圖案

    鎖存（12 腳）沒接好，或 LATCH_PIN 與接線不一致。也可能是接觸不良，把杜邦線與晶片的腳重新壓緊。

    掃描器找不到 LCD
    1. LCD 的四條線（第 14 篇）有沒有接對：SDA、SCL 不要接反。
    2. VCC 要接 5V。
    3. 找不到位址不代表壞掉，先檢查杜邦線有沒有接觸不良。
    編譯錯誤：找不到 SPI.h 或 Wire.h

    這兩個都是內建函式庫。確認板子選的是 Arduino Uno。仍然找不到就重新安裝 IDE。
