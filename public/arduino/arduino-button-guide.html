輸入:讓 Arduino「聽到」外面的世界

前面幾篇都是輸出(Arduino 控制 LED、蜂鳴器)。這一篇換方向:輸入。按鈕是最簡單的輸入裝置:按下去,Arduino 就能知道。

按鈕怎麼運作

按鈕內部是兩個接點。沒按時是斷開的,按下去就接通,放開又斷開。所以它就是一個「用手控制的線」。

Arduino 要知道有沒有按,是讀 2 號腳的電壓:HIGH(約 5 V)或 LOW(約 0 V)。問題是:沒按的時候,2 號腳接著什麼?

浮接,與上拉電阻

如果按鈕一端接 2 號腳、另一端接 GND,沒按時 2 號腳什麼都沒接,它會像天線一樣收到雜訊,讀值亂跳(浮接)。解決辦法是讓沒按時有個「預設值」:Uno 內建一顆上拉電阻,可以用程式打開。試試看,切換模式與按鈕:

小技巧「上拉」就是沒按時,透過一顆電阻把腳位輕輕拉向 5 V,讀到 HIGH;按下去時按鈕把腳位接到 GND,讀到 LOW。所以用 INPUT_PULLUP 時,按下是 LOW、放開是 HIGH(和直覺相反,但很快會習慣)。

接線:一個按鈕(2 號腳)加一個 LED(8 號腳)

LED 這一組和第 3 篇相同;新的是按鈕:一腳接 2 號腳,另一腳接 GND。按鈕不需要電阻,因為程式會啟用內建上拉電阻。

Uno 轉了 180 度擺放,數位腳位排在下緣。圖只畫左邊 22 欄,以欄號與 a–j 為準(手機上可以左右滑動圖)。

最常見的錯誤按鈕要用「對角」的兩隻腳。四腳按鈕的內部,同一側的兩隻腳永遠相通。如果你把接線接在同一側的兩腳,按鈕等於一直按著(或完全按不動),是新手最常見的按鈕錯誤。對角的兩腳,在任何方向下都是「按下才相通」。

先填入去彈跳的等待時間

空白時顯示範例值;橘底文字就是會被替換的部分。

空白時用範例值 30 毫秒。一般按鈕的彈跳在 1–10 毫秒內,30 毫秒很夠用。

程式一:按住,LED 才亮

按住按鈕,LED 才亮
// 第 7 篇(寫法一):按住按鈕,LED 才亮
const int BUTTON_PIN = 2;   // 按鈕接在 2 號腳
const int LED_PIN = 8;      // LED 接在 8 號腳

void setup() {
  pinMode(BUTTON_PIN, INPUT_PULLUP);  // 輸入模式,並啟用內建上拉電阻
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  int state = digitalRead(BUTTON_PIN);  // 讀取 2 號腳:HIGH(1)或 LOW(0)
  if (state == LOW) {                   // 等於 LOW:按鈕被按下(2 號腳被接到 GND)
    digitalWrite(LED_PIN, HIGH);        // 亮
  } else {                              // 否則:沒按
    digitalWrite(LED_PIN, LOW);         // 滅
  }
}
這一行
它在做什麼
pinMode(BUTTON_PIN, INPUT_PULLUP);
把 2 號腳設成輸入,並啟用內建上拉電阻。沒按時讀到 HIGH。
int state = digitalRead(BUTTON_PIN);
讀取 2 號腳的電位,存進整數變數 state(HIGH 是 1、LOW 是 0)。
if (state == LOW) { … } else { … }
條件判斷:如果括號裡成立,做第一個大括號的事;否則做 else 後面的事。
==
兩個等號是「比較是否相等」。一個等號 = 是「放進去(指定)」,兩者不同,新手常搞混。

程式二:按一下,切換亮或滅

想要「按一下亮、再按一下滅」,程式必須記住 LED 現在是亮還是滅。這就是變數的用處。

按一下切換 LED,並處理彈跳
// 第 7 篇(寫法二):按一下切換 LED(亮 ↔ 滅),並處理彈跳
const int BUTTON_PIN = 2;
const int LED_PIN = 8;
bool ledOn = false;                    // 記住 LED 現在是不是亮著

void setup() {
  pinMode(BUTTON_PIN, INPUT_PULLUP);
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  if (digitalRead(BUTTON_PIN) == LOW) {        // 偵測到按下
    ledOn = !ledOn;                            // 反轉:true 變 false,false 變 true
    if (ledOn) {
      digitalWrite(LED_PIN, HIGH);
    } else {
      digitalWrite(LED_PIN, LOW);
    }
    delay({wait});                             // 等彈跳過去
    while (digitalRead(BUTTON_PIN) == LOW) {   // 一直等,直到手放開
    }
    delay({wait});                             // 放開時也會彈跳,再等一下
  }
}
這一行
它在做什麼
bool ledOn = false;
布林變數:只有 true(是)與 false(否)兩種值。拿來記「LED 現在亮不亮」。寫在函式外面,值才會一直保留。
ledOn = !ledOn;
! 是「相反」:true 變 false,false 變 true。每按一次,翻轉一次。
delay({wait});
按下去的瞬間,按鈕的金屬片會彈跳:短短幾毫秒內開開關關好幾次(見下圖)。等一下,讓它穩定。
while (digitalRead(BUTTON_PIN) == LOW) { }
while 迴圈:條件成立就一直重複。大括號裡是空的,表示什麼都不做、只是等到你放手。這樣按住不放也只會切換一次。

什麼是彈跳?

    Arduino 一秒能讀幾萬次,彈跳的每一下它都看得到。沒有處理的話,「按一下」可能被當成「按了好幾下」,LED 就會亂切換。去彈跳最簡單的做法就是:偵測到變化後,等一小段時間再繼續。

    你會看到每按一下,LED 切換一次(亮 → 滅 → 亮 …),不會亂跳。
    先記著這個寫法有個限制:按住按鈕的那段時間,Arduino 被「卡」在 while 裡,做不了別的事(例如讓另一顆燈閃)。第 15 篇的 millis() 會教你不卡住的做法。

    別的教學的寫法:外接上拉 / 下拉電阻

    你會在別的教學看到另一種做法:不用 INPUT_PULLUP,改成在按鈕旁外接一顆 10 kΩ 電阻。下面是「下拉」版本的原理圖,只讀不用做:

      1. 按鈕一端接 5V,另一端接 2 號腳,2 號腳再經過 10 kΩ 電阻接 GND。
      2. 沒按:2 號腳透過電阻接 GND → 讀 LOW。按下:2 號腳接到 5V → 讀 HIGH(和 INPUT_PULLUP 剛好相反)。
      3. 程式用 pinMode(2, INPUT);(不啟用內建上拉)。
      小技巧INPUT_PULLUP 把這顆電阻搬進晶片裡,省零件、省接線,本主題採用它。看到外接電阻的寫法,知道它在做同樣的事就夠了。

      常見卡關

      LED 一直亮著,按了也沒反應
      1. 按鈕接在同一側的兩腳:換成對角(e5 與 f7)。
      2. 按鈕沒有跨在中間凹槽上,四隻腳其實在同一半:重新插好,讓它跨過凹槽。
      3. 2 號腳的藍線沒接好,或接到了錯誤的欄。
      按了沒有任何反應
      1. GND 沒接上:按鈕下腳的黑色短線(j7 → b-7)、上下 − 軌的綠色連接線、Uno GND 到 − 軌的黑線,三處都要有。
      2. 你的麵包板電源軌如果中間斷開,檢查黑色短線與 GND 線是否接在同一半。
      3. 程式裡的腳位(2、8)與接線一致。
      LED 亂閃,或手靠近就變
