DHT11：同時量溫度和濕度

認識 DHT11

DHT11 是便宜的溫濕度感測器：一條訊號線（DATA）就能讀出溫度與濕度。常見規格：溫度 0–50 °C（誤差約 ±2 °C）、濕度 20–80 %（誤差約 ±5 %），讀取速度很慢：兩次讀取至少隔 1–2 秒。電壓 3.3–5.5 V，用 Uno 的 5V 就可以。

它用一種單線通訊協定：Arduino 先拉低訊號線叫醒它，它再用一連串長短不同的脈衝，把 40 個位元的資料（溫度、濕度、檢查碼）送回來。這段脈衝時序很精細，自己寫很麻煩，所以我們用別人寫好的函式庫。

小技巧這裡的規格是常見資料手冊的數值，以你的模組為準。DHT11 精度有限，適合看趨勢（例如「現在悶不悶」），不適合需要精確數字的場合。要更準可以升級 DHT22 或其他感測器，用法類似。

安裝函式庫：用 Library Manager

上一篇的 Servo 是 IDE 內建的。DHT11 的函式庫不是內建的，要自己安裝。這是你以後用任何感測器都會做的步驟。

1

打開 Library Manager

IDE 2 左側邊欄有一排圖示，函式庫管理員是其中一個。

  1. 點左側邊欄的函式庫圖示（Library Manager）（由上往下第三個）。
  2. 或用選單 Sketch → Include Library → Manage Libraries…。
2

搜尋並安裝

函式庫要找對作者，不然會裝到不相容的版本。

  1. 在搜尋欄輸入 DHT sensor library。
  2. 找到作者是 Adafruit 的那一個，按 INSTALL。
3

安裝相依的函式庫

有些函式庫需要別的函式庫才能運作，IDE 會問你。

  1. 跳出「Install library dependencies」視窗，詢問是否要同時安裝 Adafruit Unified Sensor。
  2. 按 INSTALL ALL（安裝全部）。
你會看到等一下，函式庫清單裡這兩個都會標上 INSTALLED。
別漏掉一定要按 INSTALL ALL。只裝 DHT 本體、不裝相依的 Adafruit Unified Sensor，編譯時會出現找不到 Adafruit_Sensor.h 的錯誤（見常見卡關）。
4

確認可以使用

裝好之後，程式最上面加 #include <DHT.h> 就能用。

  1. 也可以看內建範例：File → Examples → DHT sensor library → DHTtester。
  2. 之後所有第三方函式庫都是同樣的流程：搜尋、安裝、（裝相依）、#include。

接線：DHT11（2 號腳）加 LED（8 號腳）

Uno 轉了 180 度擺放：5V 在上緣，要繞過左邊；數位腳位（2、8、GND）在下緣。圖只畫左邊 22 欄，模組不是按比例畫的。以欄號與 a–j 為準（手機上可以左右滑動圖）。

      程式一：讀溫度與濕度

      DHT11：印出濕度與溫度
      // 第 13 篇:讀 DHT11 的溫度與濕度
#include <DHT.h>                 // 引入 Adafruit 的 DHT 函式庫(要先用 Library Manager 安裝)

const int DHT_PIN = 2;           // DATA 接在 2 號腳
DHT dht(DHT_PIN, DHT11);         // 建立感測器物件:腳位 2、型號 DHT11

void setup() {
  Serial.begin(9600);
  dht.begin();                   // 啟動感測器
}

void loop() {
  delay({gap});                  // DHT11 很慢:兩次讀取至少隔 1–2 秒
  float h = dht.readHumidity();          // 讀濕度(%)
  float t = dht.readTemperature();       // 讀溫度(攝氏)

  if (isnan(h) || isnan(t)) {            // isnan:不是數字 → 讀取失敗
    Serial.println("讀取失敗,請檢查接線");
    return;                              // 結束這一輪 loop,等下一輪重來
  }

  Serial.print("濕度 = ");
  Serial.print(h);
  Serial.print(" %   溫度 = ");
  Serial.print(t);
  Serial.println(" C");
}
      這一行
      它在做什麼
      #include <DHT.h>
      引入剛安裝的函式庫。沒安裝會出錯。
      DHT dht(DHT_PIN, DHT11);
      建立一個 DHT 物件，取名 dht。括號是「建立時要給的設定」：接在哪個腳位、感測器型號。
      dht.begin();
      啟動感測器。
      dht.readHumidity()、dht.readTemperature()
      讀濕度（%）與溫度（攝氏）。回傳 float。想要華氏，readTemperature(true)。
      isnan(h) || isnan(t)
      isnan 檢查「這不是個數字」。讀取失敗時函式庫回傳 NaN。|| 是「或者」：濕度或溫度任一個失敗就算失敗。
      return;
      在 loop() 裡提早結束這一輪，回到開頭等下一輪。避免把壞資料印出來。
      你會看到Serial Monitor(baud 9600)每 1.2 秒印一行，例如 濕度 = 55.00 % 溫度 = 26.00 C。用手捂住感測器（或對它哈氣），濕度會明顯上升，溫度也會慢慢變。

      程式二：高溫警示

      溫度超過門檻，LED 亮
      // 第 13 篇:高溫警示——溫度超過門檻就亮燈
#include <DHT.h>

const int DHT_PIN = 2;
const int LED_PIN = 8;
const float ALARM_TEMP = {alarm};        // 警示溫度(攝氏)
DHT dht(DHT_PIN, DHT11);

void setup() {
  Serial.begin(9600);
  pinMode(LED_PIN, OUTPUT);
  dht.begin();
}

void loop() {
  delay({gap});
  float t = dht.readTemperature();
  if (isnan(t)) {
    Serial.println("讀取失敗,請檢查接線");
    return;
  }
  Serial.print("溫度 = ");
  Serial.println(t);
  if (t > ALARM_TEMP) {                  // 超過警示溫度
    digitalWrite(LED_PIN, HIGH);
  } else {
    digitalWrite(LED_PIN, LOW);
  }
}
      這一行
      它在做什麼
      const float ALARM_TEMP = 28;
      float 常數，警示溫度。
      if (t > ALARM_TEMP) { … } else { … }
      溫度高於警示就亮燈，否則熄滅。和第 10 篇的光敏電阻判斷是同樣的結構。
      你會看到手捂住感測器讓溫度上升，超過警示溫度時 LED 亮；放開、溫度降下來後熄滅。
      小技巧和第 10 篇一樣，溫度在門檻附近會讓 LED 來回切換。想避免的話，用兩個門檻（遲滯）。

      常見卡關

      編譯錯誤：找不到 DHT.h 或 Adafruit_Sensor.h

      DHT.h: No such file or directory 表示 DHT 函式庫沒裝；Adafruit_Sensor.h 找不到表示相依的函式庫沒裝。回到 Library Manager，搜尋 DHT sensor library,安裝時按 INSTALL ALL;或另外搜尋 Adafruit Unified Sensor 安裝。

      一直印「讀取失敗」
      1. DATA 腳位沒接對：模組的 S 要接 2 號腳。
      2. 電源接錯：+ 接 5V、− 接 GND（對照模組印刷）。
      3. 程式裡 DHT_PIN 與接線的 2 號腳一致，型號選 DHT11。
      4. 讀得太快：兩次讀取至少隔 1 秒；delay 不要設太小。
      5. 模組是四腳單體、沒有上拉電阻。
      數字偶爾跳掉或不準

      DHT11 本來就不精確（溫度約 ±2 °C、濕度約 ±5 %），而且對氣流、手的溫度敏感。把它放在不被風吹、不被手碰的地方，看長時間的趨勢。

      模組發燙

      立刻拔掉 USB。很可能 + 與 − 接反了。確認腳位之後再通電；壞掉的模組要換新的。

      LED 不亮

      程式二有沒有成功上傳；警示溫度是否低於現在的溫度；LED 方向、8 號腳接線（第 3 篇）。
