LCD1602:Arduino 的小螢幕

認識 LCD1602

LCD1602 能顯示 2 行、每行 16 個字元（共 32 個字），是最常見的字元型液晶。它本身有 16 隻接腳，接起來很麻煩；所以我們買已經焊好 I2C 轉接板的版本，只要四條線。

不只能顯示英文字母和數字，但預設不能顯示中文。這一篇只顯示英文與數字。

I2C：用兩條線說話

I2C（讀作 I-squared-C）是一種只用兩條線就能和多個裝置溝通的方式：SDA 傳資料、SCL 是節拍（時脈）。一條 I2C「匯流排」上可以掛很多裝置，每個裝置有自己的位址，Arduino 叫誰，誰才回應。Uno 上 A4 是 SDA、A5 是 SCL（數位腳位排靠近 AREF 處也有一組同樣訊號的 SDA、SCL）。第 17 篇會更深入。

小技巧LCD 的液晶模組是 5 V 供電。接 Uno 的 5V 腳就好，不要接 3.3V，否則背光會很暗、字也看不清楚。

安裝函式庫：hd44780

和第 13 篇一樣，用 Library Manager 安裝。這次我選 hd44780 函式庫（作者 Bill Perry）：它能自動找出轉接板的 I2C 位址，不用猜 0x27 還是 0x3F，新手最容易卡關的地方它幫你處理掉了。

  1. 點左側 Library Manager，搜尋 hd44780。
  2. 找到 hd44780(Bill Perry)，按 INSTALL。
  3. 如果跳出相依視窗，按 INSTALL ALL。
  4. 裝好後可看範例：File → Examples → hd44780 → ioClass → hd44780_I2Cexp → HelloWorld。
小技巧很多網路教學用的是 LiquidCrystal I2C 這個函式庫（要手動填 I2C 位址）。它也能用，本篇最後有它的寫法。但同名的函式庫有好幾個版本，初始化函式有的叫 init()、有的叫 begin()：看到編譯錯誤找不到其中一個，換成另一個試試。

接線：四條線，不用麵包板

LCD 的實物比圖大（約 8 公分寬）；圖只是示意。5V 的線要繞過 Uno 的左邊。以轉接板上印的針腳名稱為準（手機上可以左右滑動圖）。

原理圖

    點原理圖裡的 LCD 方框，看它在實物上是哪一個。

    接上之後的第一件事：調對比

    轉接板上有一個藍色的小旋鈕（對比旋鈕，其實是一顆微調電阻）。對比調錯時，畫面會是「整排白色方塊」或「完全空白」，即使程式與接線都對。

    1. 上傳程式一，讓背光亮起。
    2. 用小十字或一字螺絲起子，慢慢轉那顆藍色旋鈕，一邊看螢幕。
    3. 轉到白色方塊消失、字清楚出現就停。
    你會看到對比正確時，第一行是 Hello, Arduino!，第二行是 LCD1602 I2C。
    小技巧這是 LCD 最常見的「明明都對卻沒字」原因，幾乎每個人都會遇到一次。

    程式一：顯示兩行字

    先在這裡預覽：輸入文字，看看螢幕與對應的程式碼：

    LCD1602：顯示 Hello 與第二行
    // 第 14 篇:LCD1602 顯示文字
#include <Wire.h>
#include <hd44780.h>                         // 函式庫 hd44780(要先用 Library Manager 安裝)
#include <hd44780ioClass/hd44780_I2Cexp.h>   // 這個類別能自動找出 I2C 位址

hd44780_I2Cexp lcd;                          // 建立 LCD 物件

void setup() {
  int status = lcd.begin(16, 2);             // 16 欄、2 列。回傳 0 表示成功
  if (status) {                              // 不是 0:找不到 LCD
    hd44780::fatalError(status);             // 用板子上的 L 燈閃爍代表錯誤,並停在這裡
  }
  lcd.print("Hello, Arduino!");              // 第一行(游標一開始在左上角)
  lcd.setCursor(0, 1);                       // 游標移到第 0 欄、第 1 列(也就是第二行開頭)
  lcd.print("LCD1602 I2C");
}

void loop() {
}
    這一行
    它在做什麼
    hd44780_I2Cexp lcd;
    建立 LCD 物件。I2Cexp 表示「透過 I2C 轉接板、自動偵測」。
    lcd.begin(16, 2)
    啟動 LCD:16 欄、2 列。回傳 0 表示成功，不是 0 表示出錯（找不到）。
    hd44780::fatalError(status);
    出錯時，用 Uno 的 L 燈閃爍來報告，並停住。看到 L 燈在閃，就是 LCD 沒找到（檢查接線）。
    lcd.print("…")
    在游標位置印出文字。和 Serial.print 用法一樣，可以印文字、數字。
    lcd.setCursor(0, 1);
    把游標移到第 0 欄、第 1 列。欄、列都是從 0 開始：第一行是 0、第二行是 1。
    你會看到調好對比後，第一行顯示 Hello, Arduino!，第二行顯示 LCD1602 I2C。

    程式二：會動的數字

    LCD：每 0.5 秒加 1
    // 第 14 篇:會動的數字
#include <Wire.h>
#include <hd44780.h>
#include <hd44780ioClass/hd44780_I2Cexp.h>

hd44780_I2Cexp lcd;
int count = 0;

void setup() {
  int status = lcd.begin(16, 2);
  if (status) {
    hd44780::fatalError(status);
  }
  lcd.print("Counter");
}

void loop() {
  lcd.setCursor(0, 1);              // 每次都回到第二行開頭
  lcd.print("count: ");
  lcd.print(count);                 // print 也能印數字
  lcd.print("   ");                 // 多印幾個空白,把上一次殘留的字蓋掉
  count = count + 1;
  delay({gap});
}
    這一行
    它在做什麼
    lcd.setCursor(0, 1);
    每次都先回到第二行開頭，才不會越寫越右。
    lcd.print(count);
    印出變數的值，例如 12。
    lcd.print(" ");
    多印三個空白。數字由 10 變成 9 這種情況（位數變少）時，把上一次殘留的字蓋掉。
    你會看到第二行顯示 count: 0、count: 1… 不斷增加。
    函式
    作用
    例子
    lcd.print(x)
    在游標處印出文字或數字
    lcd.print("Hi");
    lcd.setCursor(欄, 列)
    移動游標（從 0 算起）
    lcd.setCursor(5, 1);
    lcd.clear()
    清除整個螢幕（游標回左上角）
    lcd.clear();
    lcd.noBacklight() / lcd.backlight()
    關閉 / 打開背光
    lcd.noBacklight();

    別的教學用的函式庫：LiquidCrystal I2C

    LiquidCrystal I2C 版本
    // 另一個常見的函式庫:LiquidCrystal I2C(很多教學用它)
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

LiquidCrystal_I2C lcd(0x27, 16, 2);   // I2C 位址 0x27(有些模組是 0x3F)、16 欄、2 列

void setup() {
  lcd.begin();                        // 較舊的版本要寫成 lcd.init();
  lcd.backlight();                    // 打開背光
  lcd.print("Hello, Arduino!");
  lcd.setCursor(0, 1);
  lcd.print("LiquidCrystal I2C");
}

void loop() {
}
    1. 位址要自己填：0x27 或 0x3F。不確定就用第 17 篇的 I2C 掃描程式查。
    2. 初始化依版本不同：lcd.begin() 或 lcd.init()。
    3. 打開背光：lcd.backlight()。後面的 setCursor、print 和上面完全一樣。

    常見卡關

    背光亮，但螢幕只有一排白色方塊，或完全空白

    對比沒調好。用小螺絲起子慢慢轉轉接板上的藍色旋鈕，直到字出現。這是最常見的原因，先做這個。

    L 燈一直規律地閃（程式停在 fatalError）
    1. 找不到 LCD：檢查四條線。SDA 與 SCL 沒有接反、VCC 是 5V、GND 有接。
    2. 杜邦線的母頭有沒有插緊轉接板的針腳。
    3. 你的轉接板針腳順序，是否和接線一致（對照上面印的字）。
    編譯錯誤：找不到 hd44780.h

    函式庫沒裝。回 Library Manager，搜尋 hd44780，安裝作者 Bill Perry 的那一個。

    完全沒反應，背光也不亮

    VCC 與 GND 沒有接好。用另一條杜邦線、或換一組針腳確認。USB 有沒有接上、ON 燈有沒有亮。

    顯示亂碼、或字母怪怪的

    電壓不足或接觸不良，檢查 VCC 是否為 5V。也要確認顯示的是英文與數字，預設的 LCD 不能直接顯示中文。
