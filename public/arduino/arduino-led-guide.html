Arduino 入門 · 第 3 篇 · 外接 LED

用一顆電阻和一顆 LED,讓你自己接的燈閃起來

第一次把線接在麵包板上,第一次寫控制外部零件的程式。每一步先說明為什麼,再告訴你插哪個孔、會看到什麼。

TL;DR 先拔掉 USB,再接線:Uno 8 號腳 → 220Ω 電阻 → LED 長腳(+),LED 短腳(−)→ GND。程式用 pinMode 把 8 號腳設為輸出,再用 digitalWrite 與 delay 讓它每秒開關一次。

LED 有方向,而且一定要配一顆電阻

兩個規則,先記住

LED 有方向。LED(發光二極體)只讓電流從長腳(正極,+)流向短腳(負極,−)。插反了不會亮;所以接線時永遠先確認長腳在哪一側。

LED 一定要串一顆電阻。LED 自己幾乎不會限制電流,Uno 的腳位輸出 5V 時,沒有電阻的話電流會大到可能燒掉 LED,甚至傷到腳位。電阻就像水管上的閥門,把電流壓在安全範圍。

這個電路的電流
≈ 13.6 mA
Uno 每腳建議上限
20 mA
每腳絕對上限(不可超過)
40 mA

算法:電流 = (電源電壓 − LED 壓降)÷ 電阻 = (5 − 2.0)÷ 220 ≈ 0.0136 A。紅色 LED 的順向壓降約 2 V,這是常見的範例值,實際請以你的 LED 規格為準;第 2 篇會把這個公式講清楚。

接線:先麵包板、後 Arduino,一次一步

麵包板的規則只有一條:同一欄(同一個數字)的 a–e 五個孔,內部是相通的;f–j 是另一組。所以把兩個零件的腳插在同一欄,它們就接在一起了。

點圖上的任何零件,它會亮起橘色光圈,而且在下一節的原理圖裡也會跟著亮。

圖中的 Uno 轉了 180 度擺放:數位腳位排(0–13、GND)在下緣,朝向麵包板;電源與類比腳位在上緣。圖只畫出麵包板最左邊 16 欄,你的麵包板更長,以欄號與 a–j 為準(手機上可以左右滑動圖);各廠牌字母與數字印刷的位置可能不同,但「同欄 5 孔相通」的規則一樣。

原理圖:同一個電路的另一種畫法

原理圖不管零件長什麼樣子,只畫「誰接到誰」,是電子電路共通的語言。上面的接線圖是「照著插」,原理圖是「看懂它」。以後每次出現新符號,我都會標上新符號。

  1. 1新符號電阻:鋸齒線。串在 LED 旁邊,把電流限制在安全範圍。有些教科書把電阻畫成長方形,意思相同。
  2. 2新符號LED(發光二極體):三角形加一條槓。三角形的底是正極 A(長腳),槓那一側是負極 K(短腳);電流只能從三角形往槓的方向流。旁邊兩個小箭頭表示「會發光」。
  3. 3新符號接地 GND:電路的 0 V 參考點。三條漸短的橫線是它的符號;圖上出現幾次,就代表那幾處接到同一個 GND。
點原理圖裡的電阻、LED(或上面接線圖裡的零件),看它在另一張圖裡是哪個東西。

兩張圖說的是同一件事:8 號腳 → 電阻 → LED 的 A(正極)→ LED 的 K(負極)→ GND。電流只會順著這個方向流,所以 LED 的方向很重要。

空白時顯示範例值;橘底文字就是會被替換的部分。

空白時用範例值(8 號腳、1000 毫秒)。如果你把腳位改成別的數字,橘色那條線也要改插 Uno 對應的腳,接線和程式必須一致。不要用 0 和 1 號腳,它們留給 USB 通訊使用。

照著做:五個步驟

1

對照檢查接線,然後接上 USB

動手前最後一次檢查。接線錯誤是 LED 不亮最常見的原因,比程式錯更常見。

  1. 電阻:b5 ↔ b9。
  2. LED:長腳在 d9、短腳在 d10(長腳靠近電阻那一側)。
  3. 橘線:Uno 8 號腳 ↔ a5;黑線:Uno GND ↔ a10。
  4. 沒有兩隻零件腳或兩條導線擠在同一個孔,也沒有任何金屬腳碰在一起。

確認後,用 USB 線把 Uno 接到電腦。Uno 的電源燈(標示 ON 的小燈)會亮。此時 LED 還不會閃,因為程式還沒寫進去。

2

開新草稿碼,貼上程式

Arduino 把程式叫做「草稿碼(sketch)」。我們要從空白的開始。

  1. 打開 Arduino IDE。選單 File → New Sketch。
  2. 編輯區裡有預設的 setup() 與 loop(),用 Ctrl + A 全選後刪掉。
  3. 按下面程式右上角的 Copy,貼進編輯區(Ctrl + V)。
Arduino 程式(會依你上面填的值更新)
// 第 3 篇:外接 LED 閃爍
const int LED_PIN = {pin};   // LED 接在哪個腳位(用名字代替數字,之後好改)

void setup() {
  pinMode(LED_PIN, OUTPUT);  // 把這個腳位設成「輸出」:Arduino 要送電壓出去
}

void loop() {
  digitalWrite(LED_PIN, HIGH);  // 輸出 5V:LED 亮
  delay({ms});                  // 等待 {ms} 毫秒(1000 毫秒 = 1 秒)
  digitalWrite(LED_PIN, LOW);   // 輸出 0V:LED 滅
  delay({ms});                  // 再等一次
}
小技巧程式裡 // 後面是註解,給人看的,Arduino 不會執行。貼上時有沒有註解都可以。
3

選擇板子與連接埠

IDE 要知道你用的是哪一種板子、接在電腦的哪個埠,才知道把程式送到哪裡。

  1. 看視窗上方工具列,勾號(Verify)與右箭頭(Upload)旁邊有一個下拉選單。Uno 接好後,通常會自動顯示 Arduino Uno 與一個 COM 埠,例如 COM3。
  2. 如果沒有自動出現:點下拉選單,選 Select other board and port…,或用選單 Tools → Board → Arduino AVR Boards → Arduino Uno,再用 Tools → Port 選後面標有 (Arduino Uno) 的那個 COM 埠。
你會看到下拉選單顯示 Arduino Uno,連接埠旁邊寫著 COM 數字。
注意Port 選單是灰的或找不到 Uno:先換一條 USB 線(有些線只能充電,不能傳資料),再換一個 USB 孔。相容板如果仍抓不到,可能需要裝 CH340 驅動,第 1 篇與第 19 篇會詳細說明。
4

先驗證,再上傳

「驗證」只檢查程式有沒有寫錯、能不能編譯,不會動到板子。養成先驗證的習慣,出錯時比較好找原因。

  1. 按工具列左邊的勾號(Verify),等下方輸出視窗跑完,沒有紅字錯誤就可以。
  2. 按旁邊的右箭頭(Upload)。IDE 會再編譯一次,然後把程式送進 Uno。上傳期間,Uno 上的 TX、RX 小燈會快速閃爍。
你會看到輸出視窗結尾出現上傳完成的提示(Done uploading)。
5

看 LED 閃爍

上傳完成後,Uno 會立刻開始執行程式,不需要再按任何東西。

你會看到麵包板上的紅色 LED 亮 1 秒、滅 1 秒,不斷重複。Uno 板子上自己的 L 燈不會閃,因為它接在 13 號腳,而我們用的是 8 號腳。
小技巧把 USB 拔掉再插上,或按 Uno 上的 Reset 小按鈕,程式會從頭再跑一次。程式存在 Uno 裡,拔掉電源也不會消失。
注意LED 完全不亮?先不要急著改程式,到下面「常見卡關」照順序檢查,九成是接線的問題。

逐行看懂這支程式

這一行
它在做什麼
const int LED_PIN = 8;
宣告一個叫 LED_PIN 的整數常數,值是 8。用名字代替數字,以後換腳位只要改這一行。const 表示它不會被改變。行尾的分號 ; 不能少。
void setup() { … }
開機或按 Reset 後,只執行一次。放「準備工作」。大括號 { } 圈住這個區塊的內容。
pinMode(LED_PIN, OUTPUT);
設定腳位的模式。OUTPUT 表示輸出:由 Arduino 決定這隻腳的電壓。忘了這行,LED 會很暗(見常見卡關)。
void loop() { … }
setup() 跑完之後,一直重複執行,直到斷電。
digitalWrite(LED_PIN, HIGH);
輸出高電位(5V)。電流從 8 號腳出發,經過電阻、LED,流回 GND,LED 亮。HIGH 要全大寫。
delay(1000);
暫停 1000 毫秒(1 秒)。這段時間程式什麼都不做,LED 維持現在的狀態。
digitalWrite(LED_PIN, LOW);
輸出低電位(0V)。LED 兩端沒有電壓差,所以熄滅。

執行順序:開機 → setup() 一次 → loop() 從上到下 → 跑到最後一行,回到 loop() 第一行 → 一直重複。LED 就是在這個圈裡被不斷開、關。

小技巧delay 的單位是毫秒,不要寫成 delay(1.5) 之類的小數:它只接受整數。想要 1.5 秒就寫 delay(1500)。

常見卡關(照順序檢查)

LED 完全不亮

九成是接線。由最常見的開始檢查:

  1. LED 插反了:長腳(+)要在靠近電阻、也就是 d9 的那一側。拔出來,轉 180 度再插回去。
  2. 零件沒有插在同一欄:電阻右腳與 LED 長腳必須同一欄(第 9 欄),橘線與電阻左腳同一欄(第 5 欄)。
  3. GND 線沒接好:黑線的另一端要插在 LED 短腳同一欄(第 10 欄)。
  4. 腳位和程式不一致:橘線插的是 8 號腳,程式裡 LED_PIN 就必須是 8。
  5. 程式其實沒有上傳成功:看輸出視窗有沒有上傳完成的提示。
LED 亮了,但很暗、而且一直不閃

如果程式裡少了 pinMode(LED_PIN, OUTPUT);,腳位預設是輸入。這時呼叫 digitalWrite(…, HIGH) 只會開啟內部的上拉電阻,LED 會微微地亮,看起來像很暗。補上 pinMode 就恢復正常。

LED 亮得很暗,但程式沒問題

先看電阻色環。紅、紅、棕是 220Ω;紅、紅、黃是 220kΩ(多了一千倍),電流小到幾乎不亮。把電阻拿起來對照色環,或用第 2 篇的色環計算機。

驗證時出現紅字錯誤

IDE 會在輸出視窗指出是第幾行。新手最常見的三種:

訊息大意
原因
expected ';' before …
上一行結尾少了分號 ;。
'digitalwrite' was not declared in this scope
大小寫打錯。Arduino 區分大小寫,正確是 digitalWrite,HIGH、OUTPUT 也要全大寫。
expected '}' at end of input
大括號 { } 沒有成對。每個 { 都要有對應的 }。
上傳失敗,或 Port 選單是灰的

先換一條 USB 線(有些線只能充電),再換一個 USB 孔,然後重新打開 IDE。相容板抓不到 COM 埠,多半要裝 CH340 驅動;第 1 篇的安裝章節與第 19 篇的決策選擇器會一步一步帶你排查。

我想把 LED 換到別的腳位

兩邊要一起改:接線(橘線從 Uno 8 號腳換到新腳位,另一端不動)與程式(上面填入表單裡的腳位數字)。只改其中一邊,LED 不會亮。
