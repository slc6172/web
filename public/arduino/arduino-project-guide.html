把學過的合在一起：倒車雷達

要做的東西

一個會用聲音、燈光與螢幕告訴你距離的倒車雷達：超音波量距離，LCD 顯示幾公分，蜂鳴器越近嗶得越快，太近時 LED 亮起。

每個零件你都做過了，這一篇的新東西只有一個：把好幾件事排進同一個 loop()，各自按自己的節奏進行（第 15 篇的 millis()）。

接線：這次是全部合在一起

每一組你都接過。新增的只有：LCD 的電源取自下方電源軌（Uno 只有一個 5V 腳），所以上下電源軌要用兩條線連起來。圖很寬，手機上可以左右滑動。

Uno 轉了 180 度擺放。LCD 與超音波模組不是按比例畫的。以接線表與模組上印的針腳名稱為準。

完整程式

倒車雷達：四個工作共用一個 loop
// 第 18 篇:倒車雷達——用 millis() 同時做好幾件事
#include <Wire.h>
#include <hd44780.h>
#include <hd44780ioClass/hd44780_I2Cexp.h>

hd44780_I2Cexp lcd;

const int TRIG_PIN = 9;
const int ECHO_PIN = 10;
const int BUZZER_PIN = 12;
const int LED_PIN = 13;

const float FAR_CM = {far};                         // 超過這個距離就安靜
const float NEAR_CM = {near};                       // 小於這個距離,LED 亮
const unsigned long MEASURE_INTERVAL = 100;         // 每 100 毫秒量一次距離
const unsigned long LCD_INTERVAL = 250;             // 每 250 毫秒更新一次螢幕

unsigned long lastMeasure = 0;
unsigned long lastLcd = 0;
unsigned long lastBeep = 0;
float distanceCm = -1;                              // 最新的距離;-1 代表量不到
bool beepOn = false;

float readDistanceCm() {                            // 第 11 篇的量距離函式
  digitalWrite(TRIG_PIN, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG_PIN, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG_PIN, LOW);
  long duration = pulseIn(ECHO_PIN, HIGH, 30000);
  if (duration == 0) {
    return -1;
  }
  return duration * 0.0343 / 2;
}

void setup() {
  pinMode(TRIG_PIN, OUTPUT);
  pinMode(ECHO_PIN, INPUT);
  pinMode(BUZZER_PIN, OUTPUT);
  pinMode(LED_PIN, OUTPUT);
  int status = lcd.begin(16, 2);
  if (status) {
    hd44780::fatalError(status);
  }
  lcd.print("Parking Sensor");
}

void loop() {
  unsigned long now = millis();

  // ---- 工作 1:定時量距離 ----
  if (now - lastMeasure >= MEASURE_INTERVAL) {
    lastMeasure = now;
    distanceCm = readDistanceCm();
  }

  // ---- 工作 2:定時更新螢幕 ----
  if (now - lastLcd >= LCD_INTERVAL) {
    lastLcd = now;
    lcd.setCursor(0, 1);
    if (distanceCm < 0) {
      lcd.print("out of range    ");
    } else {
      lcd.print(distanceCm, 1);
      lcd.print(" cm       ");                      // 多印空白,蓋掉殘留的字
    }
  }

  // ---- 工作 3:蜂鳴器,越近越密(不用 delay)----
  if (distanceCm > 0 && distanceCm < FAR_CM) {
    int gap = map((int)distanceCm, 5, (int)FAR_CM, 50, 500);
    gap = constrain(gap, 50, 500);
    unsigned long interval = beepOn ? 30 : gap;     // 響 30 毫秒,停 gap 毫秒
    if (now - lastBeep >= interval) {
      lastBeep = now;
      beepOn = !beepOn;
      if (beepOn) {
        digitalWrite(BUZZER_PIN, HIGH);
      } else {
        digitalWrite(BUZZER_PIN, LOW);
      }
    }
  } else {
    beepOn = false;
    digitalWrite(BUZZER_PIN, LOW);
  }

  // ---- 工作 4:太近就亮 LED ----
  if (distanceCm > 0 && distanceCm < NEAR_CM) {
    digitalWrite(LED_PIN, HIGH);
  } else {
    digitalWrite(LED_PIN, LOW);
  }
}

怎麼讀這支程式

這一段
它在做什麼
最上面的 const 與變數
把「設定」集中在一起：腳位、距離門檻、時間間隔。以後要調整，只改這裡。每個定時的工作各有一個 lastXxx 記上次的時間。
readDistanceCm()
第 11 篇的量距離函式，原封不動搬過來。
setup()
設定腳位，啟動 LCD（begin 失敗就用 L 燈閃爍報錯並停住），印出標題。
工作 1：定時量距離
每 100 毫秒量一次，把結果放進 distanceCm。量測結果存起來，其他工作只讀這個變數，不各自重新量。
工作 2：定時更新螢幕
每 250 毫秒更新第二行。LCD 更新比較慢，不用太頻繁，也不影響其他工作。
工作 3：蜂鳴器
用 beepOn 記「現在是在響還是在停」：響 30 毫秒，停的時間依距離而定。用時間差決定何時切換，沒有 delay。
工作 4:LED
太近就亮，否則滅。
你會看到手（或一本書）由遠而近靠近超音波：LCD 顯示的距離變小，蜂鳴器由慢變快，小於 25 公分時紅 LED 亮起；離開或超出範圍，全部安靜，LCD 顯示 out of range。
小技巧這種寫法叫協同工作（cooperative multitasking）：沒有誰是老大，每個工作都快速檢查一下「該不該動」，不該動就立刻讓出去。loop() 每一圈都很短，所以每件事都很即時。

怎麼分段除錯

  1. 先看 Serial：暫時在工作 1 後面加一行 Serial.println(distanceCm);（第 8 篇），看量到的距離對不對。
  2. 再看輸出：距離對了，蜂鳴器與 LED 還不對，就是工作 3、4 的邏輯；距離不對，回去查超音波接線（第 11 篇）。
  3. LCD 沒字：調對比旋鈕（第 14 篇）。L 燈一直閃：LCD 沒找到，檢查 SDA、SCL 與電源。

常見卡關

整個系統沒反應，或 Uno 一直重開機

電流不夠或短路。立刻拔掉 USB，檢查 5V 與 GND 有沒有碰在一起；上下電源軌是否用兩條線連好；逐一拔掉模組，找出是哪一組造成的。

LCD 完全不亮或 L 燈在閃

LCD 的電源取自下方電源軌：確認 t+30→b+30 與 t-29→b-29 兩條連接線有接，以及 LCD 的 VCC、GND 有插到 b+24、b-25。

蜂鳴器一直響或很不規則

檢查 loop() 裡有沒有誤用 delay()；距離變數是否正確。也可能是超音波讀值亂跳，先用 Serial 看一下距離。

距離一直是 out of range

回到第 11 篇：Trig、Echo 腳位，VCC、GND，以及前方要有硬平面。這一篇的超音波接法和第 11 篇相同。

改了程式之後燈亂閃

檢查每個工作的 lastXxx = now; 有沒有寫（漏了就會每一圈都觸發），以及比較用的是減法、變數是 unsigned long。
