讓燈漸漸變亮變暗,再讓蜂鳴器開口說話

學會 PWM:不用真的變電壓,也能控制亮度。再接一顆蜂鳴器,認識主動式與被動式的差別。

TL;DR PWM = 很快地開關,調整開的比例。analogWrite(腳位, 0–255) 只能用在有 ~ 的腳位(3、5、6、9、10、11)。主動式蜂鳴器通電就響,被動式要用 tone() 給頻率。

數位腳位只有「開」和「關」,怎麼做出「半亮」?

到目前為止,LED 只有亮或滅。要讓它漸漸變亮、變暗,需要「中間值」。Arduino 的做法叫 PWM(脈衝寬度調變):每秒開關幾百次,調整「開」佔多少比例。

三個關鍵

  • 閃得夠快,眼睛看不出來:Uno 的 PWM 每秒約開關 490 次(5、6 號腳約 980 次),眼睛只看到平均亮度。
  • 工作週期(duty cycle):一個週期裡「開」的時間占比。占 50% = 約一半亮。
  • analogWrite(腳位, 值):值 0–255。0 是一直關,255 是一直開,128 約 50%。

主動式與被動式蜂鳴器,差在哪裡?

主動式(Active)
被動式(Passive)
內部
有振盪電路
沒有,只是一個會震動的喇叭
怎麼讓它響
只要通電就響(digitalWrite(HIGH))
要送變化的頻率給它(tone(腳位, 頻率))
聲音
只有一種固定音高

怎麼分辨
背面通常封著黑色膠;直接接 5V 會響

別混用主動式蜂鳴器請不要用 tone()。它自己會振盪,收到變化的訊號會變成雜音。本篇主線用主動式;tone() 放在選修,需要被動式蜂鳴器。
小技巧小型 5 V 蜂鳴器的電流常在 10–30 mA 之間,接近 Uno 每腳 20 mA 的建議上限。本篇在蜂鳴器前串了 220Ω 電阻當保險,聲音會小一點,但比較安全。以你手上蜂鳴器的規格為準,電流大的蜂鳴器需要電晶體驅動,本主題不涵蓋。

程式一:呼吸燈

呼吸燈(接在 9 號腳的 LED)
// 第 6 篇:呼吸燈(PWM)
const int LED_PIN = 9;       // 必須是有 ~ 的腳位(3、5、6、9、10、11)

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  for (int b = 0; b <= 255; b += 5) {   // 由暗到亮:0、5、10 … 255
    analogWrite(LED_PIN, b);            // 輸出 PWM,b 是亮度(0–255)
    delay({fade});
  }
  for (int b = 255; b >= 0; b -= 5) {   // 由亮到暗:255、250 … 0
    analogWrite(LED_PIN, b);
    delay({fade});
  }
}
這一行
它在做什麼
const int LED_PIN = 9;
LED 接的腳位,必須是有 ~ 的腳位。
for (int b = 0; b <= 255; b += 5)
b 從 0 開始,每圈加 5,到 255 為止。b += 5 是 b = b + 5 的簡寫。
analogWrite(LED_PIN, b);
輸出 PWM,亮度是 b。不需要寫 digitalWrite。
for (int b = 255; b >= 0; b -= 5)
反過來:從 255 每圈減 5,減到 0。b -= 5 是 b = b - 5。
你會看到紅色 LED 在約 1 秒內由暗漸亮,再用約 1 秒由亮漸暗,不斷重複,像呼吸一樣。
小技巧pinMode 還是要寫:analogWrite 不會幫你把腳位設成輸出。名字叫 analog(類比),但它輸出的其實是 PWM 的快速開關,不是真正的類比電壓。

程式二:蜂鳴器「嗶嗶嗶」

蜂鳴器:嗶 3 聲、停一下、重複
// 第 6 篇:蜂鳴器「嗶嗶嗶」,停一下,再重複
const int BUZZER_PIN = 8;

void setup() {
  pinMode(BUZZER_PIN, OUTPUT);
}

void loop() {
  for (int i = 0; i < 3; i++) {          // 嗶 3 聲
    digitalWrite(BUZZER_PIN, HIGH);      // 通電:主動式蜂鳴器就會響
    delay(100);
    digitalWrite(BUZZER_PIN, LOW);       // 斷電:停止
    delay(100);
  }
  delay({pause});                        // 停一下再重複
}
這一行
它在做什麼
digitalWrite(BUZZER_PIN, HIGH);
輸出 5 V,主動式蜂鳴器通電就響。
delay(100);
響 100 毫秒(0.1 秒)。
digitalWrite(BUZZER_PIN, LOW);
斷電,停止。再 delay(100) 是兩聲之間的空檔。
for (int i = 0; i < 3; i++)
把「響、停」做 3 次(第 4 篇學過的 for)。
delay({pause});
3 聲之後停一下,再回到 loop() 開頭。
你會看到蜂鳴器發出「嗶、嗶、嗶」三聲短音,停一秒,再重複。
選修:被動式蜂鳴器與 tone()

如果你有被動式蜂鳴器,接線和上面完全一樣(換下主動式即可)。tone(腳位, 頻率) 會讓腳位以指定頻率快速開關,不需要自己寫迴圈。

tone():送 440 Hz 的聲音 0.5 秒
// 選修:被動式蜂鳴器,用 tone() 指定音高(主動式蜂鳴器請不要用)
const int BUZZER_PIN = 8;

void setup() {
}

void loop() {
  tone(BUZZER_PIN, 440);   // 輸出 440 Hz 的聲音(國際標準音 A)
  delay(500);
  noTone(BUZZER_PIN);      // 停止
  delay(500);
}
這一行
它在做什麼
tone(BUZZER_PIN, 440);
持續輸出 440 次/秒的方波,蜂鳴器發出對應音高。程式不會停在這一行,會繼續往下跑。
noTone(BUZZER_PIN);
停止發聲。

頻率越高音越高:262 Hz 是 Do,294 Hz 是 Re,330 Hz 是 Mi。改 440 試試。

// 挑戰:SOS 求救訊號(三短、三長、三短)
const int BUZZER_PIN = 8;

void beep(int ms) {                      // 自己定義的函式:響 ms 毫秒,再停 100 毫秒
  digitalWrite(BUZZER_PIN, HIGH);
  delay(ms);
  digitalWrite(BUZZER_PIN, LOW);
  delay(100);
}

void setup() {
  pinMode(BUZZER_PIN, OUTPUT);
}

void loop() {
  for (int i = 0; i < 3; i++) { beep(100); }   // 三短
  for (int i = 0; i < 3; i++) { beep(300); }   // 三長
  for (int i = 0; i < 3; i++) { beep(100); }   // 三短
  delay({pause});
}
這一行
它在做什麼
void beep(int ms) { … }
自己定義的函式:響 ms 毫秒再停 100 毫秒。以後想響多久,只要寫 beep(…)。
beep(100); 與 beep(300);
短音 100 毫秒,長音 300 毫秒。

常見卡關

LED 不會漸變,只是一直亮或突然亮暗

LED 沒接在有 ~ 的腳位。analogWrite 在非 PWM 腳位上只會「值 < 128 關、≥ 128 開」。把訊號線改插 9、10 或 11 號腳,並同步修改程式。

蜂鳴器完全不響
  1. 蜂鳴器是不是主動式:被動式用 digitalWrite(HIGH) 只會喀一聲,要用 tone()。
  2. + 腳方向:長腳(或標 + 的那隻)靠電阻那側。
  3. 兩隻腳有沒有插在不同欄,且 − 腳那一欄有黑色短線接到 − 軌。
  4. 程式腳位(8)與訊號線插的腳位一致。
蜂鳴器一直響不停

多半是蜂鳴器接到了 5V 而不是 8 號腳,或程式沒有上傳成功(還跑著上一個程式)。重新檢查訊號線,重新上傳。

聲音很小

正常:串了 220Ω 電阻,電流變小。想要大聲一點,可以換小一點的電阻(例如 100Ω),但要確認蜂鳴器規格的電流不超過 20 mA。

LED 呼吸時閃爍、不順

檢查 delay 值是不是太大(超過 40 毫秒就看得到一格一格變亮),或太小(小於 5 毫秒就變化得太快看不出來)。
