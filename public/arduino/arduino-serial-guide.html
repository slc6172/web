Serial:讓 Arduino 開口說話,也能聽你說話

學會把數字和文字從 Arduino 傳到電腦,看清楚程式到底在做什麼;也學會從電腦鍵盤控制 Arduino。這是除錯最重要的工具。

TL;DR Serial.begin(9600) 開始,Serial.print / println 印出,IDE 右上角放大鏡開 Serial Monitor,baud 要和程式一致,否則亂碼。用 Serial.available() 與 Serial.read() 接收鍵盤輸入。不要用 0、1 號腳。

Serial:Arduino 與電腦之間的對話視窗

為什麼要學它

前面的程式做了什麼,你只能從 LED 有沒有亮去猜。Serial(序列通訊)讓 Arduino 能把文字與數字透過 USB 線傳到電腦,顯示在 Arduino IDE 的 Serial Monitor 上。

它是你除錯最重要的工具:想知道變數是多少、按鈕有沒有讀到、程式跑到哪一步,印出來看就知道。

別用 0、1 號腳0 號腳與 1 號腳(標示 RX、TX)被 Serial 使用。用 Serial 時,不要把任何零件接在這兩個腳位上,否則上傳程式或印資料時會出問題。

第一個 Serial 程式:不需要接線

只要 Uno 接著電腦,不用接任何零件。每秒印一行計數。

空白時顯示範例值;橘底文字就是會被替換的部分。
Hello Serial:印出計數
// 第 8 篇:第一個 Serial 程式(不需要接任何線)
int count = 0;                 // 計數器

void setup() {
  Serial.begin(9600);          // 開始序列通訊,速度 9600(要和 Serial Monitor 一致)
  Serial.println("Hello, Arduino!");   // 印一行文字,結尾自動換行
}

void loop() {
  Serial.print("count = ");    // 印文字,不換行
  Serial.println(count);       // 印變數的值,並換行
  count = count + 1;           // 加 1
  delay({gap});                // 等一下,不然會刷太快
}
這一行
它在做什麼
Serial.begin(9600);
開始序列通訊,速度是 9600(每秒傳 9600 個位元,叫 baud)。必須寫在 setup() 裡。
Serial.println("…");
印一段文字,結尾自動換行(ln 是 line)。文字要用雙引號括起來。
Serial.print("count = ");
印出但不換行,下一次印會接在後面。
Serial.println(count);
印出變數的值(不用雙引號)。引號裡的是文字,沒有引號的是變數名字。

開啟 Serial Monitor

1

先上傳程式

和之前一樣:選好板子與連接埠,按 Upload,等到出現上傳完成。

2

打開 Serial Monitor

它整合在 IDE 裡,不會另外開視窗。

  1. 按 IDE 右上角的放大鏡圖示(Serial Monitor),或選單 Tools → Serial Monitor。
  2. 下方的面板會切換成 Serial Monitor。右上角有個下拉選單可以選 baud rate。
3

把 baud 選成 9600

Serial Monitor 的速度必須和程式裡 Serial.begin() 的數字一致。

  1. 點 baud rate 下拉選單,選 9600 baud。
你會看到面板裡出現 Hello, Arduino!,接著每秒一行 count = 0、count = 1 …
小技巧有時打開 Serial Monitor 會讓 Uno 重新啟動,所以你可能會從頭看到 Hello, Arduino!。這是正常的。

速度不一致,就會看到亂碼

怎麼印:文字、數字、進位與小數

各種印法(只在開機時印一次)
// 第 8 篇:數字怎麼印
void setup() {
  Serial.begin(9600);
  int n = 42;
  float x = 3.14159;
  Serial.print("n = ");          Serial.println(n);        // n = 42
  Serial.print("n in BIN = ");   Serial.println(n, BIN);   // 二進位:101010
  Serial.print("n in HEX = ");   Serial.println(n, HEX);   // 十六進位:2A
  Serial.print("x = ");          Serial.println(x);        // 小數,預設印 2 位:3.14
  Serial.print("x (4 digits) = "); Serial.println(x, 4);   // 指定 4 位小數:3.1416
}

void loop() {
}
你會看到
寫法
說明
n = 42
Serial.println(n);
整數,直接印
101010
Serial.println(n, BIN);
第二個參數:BIN 二進位、HEX 十六進位、DEC 十進位
3.14
Serial.println(x);
小數(float),預設印 2 位小數
3.1416
Serial.println(x, 4);
第二個參數是要印幾位小數
小技巧print 不換行、println 換行。想在同一行印好幾樣東西,前面都用 print,最後一個用 println。中文字串也可以印,Serial Monitor 會顯示;但記得用雙引號。

用 Serial 除錯:親眼看到按鈕的值

接線沿用第 7 篇(按鈕接 2 號腳,對角兩腳,另一腳接 GND)。第 7 篇我說「按下去讀到 LOW」,現在你可以自己看。

    這張圖與第 7 篇相同。LED 這一組在這一篇只有最後一個程式會用到。

    印出按鈕的值
    // 第 8 篇:用 Serial 親眼看按鈕的值(接線沿用第 7 篇)
const int BUTTON_PIN = 2;

void setup() {
  Serial.begin(9600);
  pinMode(BUTTON_PIN, INPUT_PULLUP);
}

void loop() {
  int state = digitalRead(BUTTON_PIN);
  Serial.print("button = ");
  Serial.println(state);       // 沒按印 1,按下印 0
  delay({gap});
}
    你會看到Serial Monitor 每 0.5 秒印一行 button = 1;按住按鈕時變成 button = 0,放開又變回 1。這證實了:INPUT_PULLUP 時,按下 = LOW(0)。

    除錯的基本流程

    1. 懷疑:「我覺得按鈕沒被讀到。」
    2. 印出來看:在可疑的地方加 Serial.println(…),印出變數或狀態。
    3. 比對:印出的值和你預期的一樣嗎?一樣就往下一個地方查;不一樣,問題就在這附近。
    4. 修好後把除錯用的 Serial 拿掉(或留著,但要知道它會讓程式變慢一點點)。

    反過來:用電腦鍵盤控制 Arduino

    Serial 是雙向的。Arduino 也能收到你在 Serial Monitor 輸入的字。下面用鍵盤控制 8 號腳的 LED(接線同第 7 篇)。

    輸入 1 開燈、輸入 0 關燈
    // 第 8 篇:用電腦鍵盤控制 LED(接線沿用第 7 篇)
const int LED_PIN = 8;

void setup() {
  Serial.begin(9600);
  pinMode(LED_PIN, OUTPUT);
  Serial.println("Type 1 = LED on, 0 = LED off");
}

void loop() {
  if (Serial.available() > 0) {        // 電腦有送資料進來嗎?
    char c = Serial.read();            // 讀進一個字元
    if (c == '1') {
      digitalWrite(LED_PIN, HIGH);
      Serial.println("LED on");
    } else if (c == '0') {
      digitalWrite(LED_PIN, LOW);
      Serial.println("LED off");
    }
  }
}
    這一行
    它在做什麼
    Serial.available() > 0
    電腦有送資料進來、還沒被讀走嗎?有幾個位元組可讀,就回傳幾。
    char c = Serial.read();
    讀進一個字元,存進 char 變數(放單一字元,用單引號)。
    c == '1'
    比較是不是字元「1」。注意是單引號 '1',不是數字 1。
    else if (c == '0')
    「否則,如果……」:第一個條件不成立時,再檢查另一個條件。
    1

    上傳後打開 Serial Monitor

    baud 選 9600。

    2

    在上方輸入欄打 1,按 Enter(或旁邊的送出)

    字元會被送到 Arduino。

    你會看到8 號腳的 LED 亮起,Serial Monitor 印出 LED on。再輸入 0,LED 熄滅,印出 LED off。
    小技巧輸入欄旁邊有個決定「送出時要不要多加換行字元」的下拉選單。本程式只看 '1' 與 '0',多出來的換行會被忽略,所以選哪個都可以。

    選修:Serial Plotter 把數字畫成線

    如果每一行只印一個數字,IDE 還能幫你畫成曲線,很適合看感測器的變化(第 9 篇會用到)。

    印 0 到 99,Serial Plotter 會畫出斜線
    // 選修:給 Serial Plotter 畫圖(每行印一個數字)
void setup() {
  Serial.begin(9600);
}

void loop() {
  for (int i = 0; i < 100; i++) {
    Serial.println(i);
    delay(20);
  }
}
    1. 上傳後,按右上角 Serial Plotter 圖示(Serial Monitor 旁邊),或選單 Tools → Serial Plotter。
    2. baud 一樣選 9600。你會看到一條從 0 爬升到 99 的斜線,重複出現。

    常見卡關

    Serial Monitor 一片亂碼

    baud 不一致。程式是 Serial.begin(9600),就把 Serial Monitor 選成 9600。把上面的互動示意玩一遍,你會記得這個畫面。

    什麼都沒有印出來
    1. 程式有沒有 Serial.begin(9600);(寫在 setup())。
    2. 有沒有打開 Serial Monitor,而且選的是正確的連接埠。
    3. 上傳有沒有成功;板子上的 TX 燈在印資料時會閃。
    4. 是不是把零件接在 0 或 1 號腳了。
    文字刷得太快,看不清楚

    在 loop() 最後加 delay(500) 之類的等待。也可以按面板右側的暫停自動捲動圖示(Toggle Autoscroll)。

    上傳時說連接埠被佔用

    別的程式正在用這個 COM 埠(例如另一個 IDE 視窗的 Serial Monitor)。關掉它,再重新上傳。

    輸入 1 沒反應

    確認程式比對的是單引號的字元 '1',而不是數字 1;確認 Serial Monitor 的 baud 是 9600;確認 LED 腳位與接線一致。
