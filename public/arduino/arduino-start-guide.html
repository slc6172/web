Arduino 是一台你能自己寫程式的小電腦

三句話講完

Arduino Uno 是一塊電路板,中間有一顆晶片(微控制器),你寫的程式就存在裡面。

它能做兩件事:讀取外面世界的訊號(按鈕、感測器),以及控制外面的零件(燈、馬達、蜂鳴器)。

你要學的有兩半:電路(零件怎麼接在板子的腳位上),和程式(板子該怎麼反應)。這個主題會兩邊一起,一次只加一點點。

認識 Uno 板子

先不用背,知道有這些東西就好。之後每次用到,我會再指出來。

  1. 1USB-B 接頭:接電腦。同時負責供電、上傳程式、傳資料回電腦。
  2. 2RESET 按鈕:按一下,程式從頭再跑一次。
  3. 3數位腳位 0–13:可以輸出 0 V / 5 V,也可以讀取高低電位。前面有 ~ 的腳位可輸出 PWM(第 6 篇)。旁邊的 GND 是接地腳。
  4. 4電源腳位:5V 與 3.3V 是輸出電源,GND 是接地(0 V)。VIN 是外部電源輸入。
  5. 5類比輸入 A0–A5:讀取 0–5 V 之間的電壓大小(第 9 篇)。
  6. 6ATmega328P 晶片:Uno 的大腦,你寫的程式就存在裡面。
  7. 7小燈:L 接在 13 號腳(程式能控制);TX、RX 在傳資料時閃;右下 ON 表示有電。
  8. 8DC 電源孔:接 7–12 V 的外部電源。只用 USB 時用不到。

四條安全守則(整個主題都適用)

  1. 改接線之前,先拔掉 USB。先接好零件,最後才通電。
  2. LED 一定要串電阻。沒有電阻,電流過大會燒掉 LED 或腳位。
  3. 只用 USB 供電,電壓是 5 V。初學階段不要接其他電源,也不要把 5V 直接接到 GND(短路)。
  4. 不確定就停手。零件發燙、有焦味,立刻拔掉 USB,再檢查接線。

每一篇都是「接線 → 程式 → 看到結果」的實作,從最簡單的開始。照順序做最順,後面的篇章會用到前面學過的東西。

安裝 Arduino IDE(Windows)

IDE 是你寫程式、檢查、再送進 Uno 的軟體。本主題使用 Arduino IDE 2.x,需要 Windows 10 以上的 64 位元系統。

1

下載安裝檔

只從官方下載,避免抓到夾帶其他軟體的安裝檔。

  1. 用瀏覽器開 arduino.cc 的 Software 下載頁。
  2. 找到 Arduino IDE 2.x,點 Windows 版本(Win 10 and newer, 64 bits)的安裝檔。
  3. 下載頁可能問你要不要捐款,可以直接按 Just Download。
2

執行安裝程式

安裝程式只是一個精靈,一路按下一步即可。

  1. 雙擊下載好的 arduino-ide_….exe。
  2. 同意授權條款,安裝選項與安裝位置維持預設,按 Install。
  3. 安裝需要幾分鐘,完成後勾選 Run Arduino IDE 並按 Finish。
3

第一次開啟

第一次開啟時 IDE 會做初始設定,不要中途關掉。

  1. 第一次開啟時,IDE 會自動安裝 Uno 需要的板子套件(Arduino AVR Boards)與內建函式庫,視網路速度可能要一兩分鐘。
  2. Windows 防火牆或安全性提示可能跳出幾次,詢問是否允許 IDE 或安裝裝置驅動,允許即可。
你會看到看到編輯區裡有預設的 void setup() 與 void loop()。左邊是一排圖示的側邊欄,上方是工具列。

接上 Uno,確認電腦找得到它

1

用 USB 線把 Uno 接到電腦

先確認電腦與板子之間有一條「能傳資料」的線。

  1. USB-B 那頭(方形)插 Uno,另一頭插電腦。
  2. Uno 上標示 ON 的小燈會亮,表示有電。
線材有些 USB 線只能充電、不能傳資料。如果後面抓不到板子,第一個要懷疑的就是這條線。
2

到「裝置管理員」確認

這一步確認 Windows 真的認得這塊板子,比在 IDE 裡猜原因快。

  1. 在 Windows 搜尋列輸入「裝置管理員」並開啟。
  2. 展開連接埠(COM 和 LPT)。
你會看到原廠 Uno 會顯示 Arduino Uno (COM3) 這類名稱,後面的數字依電腦而異。相容板常顯示 USB-SERIAL CH340 (COM4)。這個 COM 數字就是之後在 IDE 選的連接埠。
相容板:裝置管理員裡有黃色驚嘆號,或根本沒有連接埠

多半是缺少 CH340 晶片的 USB 驅動。Windows 有時會自動安裝;沒有的話,到晶片廠商 WCH(沁恆)的官網搜尋 CH341SER 驅動,下載後執行安裝,再重新插拔 USB。這一步不是 Arduino 官方文件的內容,請只從 WCH 官網下載。

裝好後,裝置管理員會出現 USB-SERIAL CH340 (COM數字)。

我的板子是 Uno R4(USB-C)

接線與程式和 R3 完全相同(兩者都是 5V 邏輯、腳位位置相同),但 IDE 需要多一個設定:點左側邊欄的 Boards Manager,搜尋 UNO R4,安裝 Arduino UNO R4 Boards 套件。之後在板子下拉選單選你的 R4 型號(Minima 或 WiFi)。

本主題的範例都能在 R4 上編譯,但驗證是以 R3 為準;R4 的內建 LED 腳位同樣用 LED_BUILTIN 表示。

第一次上傳:讓板子自己的 L 燈閃起來

這一步不需要麵包板、不需要任何線,只有 Uno 與電腦。目的是確認「IDE → USB → 板子」整條路是通的,之後有問題就能排除這一段。

空白時顯示範例值;橘底文字就是會被替換的部分。
1

開新草稿碼並貼上程式

Arduino 稱程式為「草稿碼(sketch)」。

  1. 選單 File → New Sketch。
  2. Ctrl + A 全選預設內容後刪掉。
  3. 按下面程式的 Copy,貼進編輯區。
Arduino 程式(會依上面填的間隔更新)
// 第 1 篇:讓 Uno 板子上自己的 L 燈閃爍(不需要接任何線)
void setup() {
  pinMode(LED_BUILTIN, OUTPUT);   // LED_BUILTIN 是板子內建 LED 的腳位;Uno 上就是 13 號腳
}

void loop() {
  digitalWrite(LED_BUILTIN, HIGH);  // 輸出 5V:L 燈亮
  delay({ms});                      // 等 {ms} 毫秒(1000 毫秒 = 1 秒)
  digitalWrite(LED_BUILTIN, LOW);   // 輸出 0V:L 燈滅
  delay({ms});
}
小技巧你也可以用內建範例:File → Examples → 01.Basics → Blink,效果相同。
2

選板子與連接埠

告訴 IDE 要把程式送到哪塊板子。

  1. 看工具列,勾號與右箭頭旁有下拉選單。Uno 接好後通常會自動顯示 Arduino Uno 與 COM 埠。
  2. 沒有的話:點下拉選單 → Select other board and port…,或用 Tools → Board → Arduino AVR Boards → Arduino Uno 加上 Tools → Port,選後面標著 (Arduino Uno) 的那個。
3

驗證,再上傳

驗證只檢查程式,不動板子。先驗證,出錯時比較好找原因。

  1. 按勾號(Verify),等 Output 視窗跑完,沒有紅字。
  2. 按右箭頭(Upload)。上傳時 Uno 上的 TX、RX 燈會快速閃。
你會看到Output 視窗結尾出現上傳完成的提示(Done uploading)。
4

看板子的 L 燈

上傳完成後,Uno 會立刻執行,不用再按任何東西。

你會看到Uno 上標示 L 的小燈亮 1 秒、滅 1 秒,不斷重複。你的第一個程式成功了!
小技巧按一下 Uno 的 RESET 按鈕,程式會從頭再跑一次。程式存在板子裡,拔掉 USB 再插上,它還是會自己開始閃。

這支程式在做什麼

這一行
它在做什麼
void setup() { … }
開機或按 RESET 後只執行一次,放準備工作。
pinMode(LED_BUILTIN, OUTPUT);
把內建 LED 的腳位設成輸出:由 Arduino 決定這隻腳的電壓。LED_BUILTIN 在 Uno 上就是 13 號腳。
void loop() { … }
setup() 跑完後一直重複執行。
digitalWrite(LED_BUILTIN, HIGH);
輸出 5 V,L 燈亮。HIGH 要全大寫。
delay(1000);
暫停 1000 毫秒(1 秒),這段時間維持現在的狀態。
digitalWrite(LED_BUILTIN, LOW);
輸出 0 V,L 燈滅。

下一篇開始會自己接線,並把每個關鍵字再講仔細;這一篇先知道「能動」就好。

常見卡關

Port 選單是灰色的,或 IDE 說找不到板子
  1. 先確認 Uno 上的 ON 燈有亮。
  2. 換一條 USB 線(有些線只能充電),再換一個 USB 孔。
  3. 到「裝置管理員」看有沒有連接埠;相容板請看前面的 CH340 驅動。
  4. 關掉其他可能佔用連接埠的程式(例如另一個開著的 IDE 或序列埠軟體),重新插拔 USB。
上傳失敗,出現 avrdude 或 stk500 開頭的紅字

這類訊息的意思大多是「IDE 跟板子溝通不上」。依序檢查:板子是否選成 Arduino Uno、連接埠是否選對、USB 線是否能傳資料、同時有沒有別的程式佔用連接埠。這四項都對,才懷疑板子本身。

驗證時出現紅字錯誤

第 1 篇的程式是直接貼上的,若出錯通常是貼上時少了一部分(例如最後的 })。把編輯區清空,重新複製貼上一次。

上傳成功但 L 燈不閃

先按一下 RESET。還是不閃的話,檢查程式裡 pinMode 與 digitalWrite 的拼字與大小寫;Arduino 區分大小寫,HIGH、OUTPUT 必須全大寫。
