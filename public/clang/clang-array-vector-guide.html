C++ 入門 · 第 9 篇 · 陣列與 vector

索引從 0 開始，越界不會報錯卻會出事

用一個名字放下一整排資料。從固定長度的陣列，到會自己長大的 vector，並親手體驗什麼叫越界。

TL;DR 陣列用索引取值，從 0 開始，長度 N 的最後一個是 N−1。越界不會有編譯錯誤，結果不可預期。日常優先用 vector：push_back 加元素、size() 取長度，除錯時用 at() 抓越界。

陣列：一排有編號的盒子

像一排編了號的置物櫃

要記 5 個人的成績，不會宣告 score1、score2……五個變數。陣列讓你用一個名字，放下一整排同型態的資料，再用編號（索引）取出其中一個。

最重要的一件事：編號從 0 開始。5 個元素的編號是 0、1、2、3、4，沒有 5。這是 C++ 初學者最常被咬到的地方。

六個名詞

名詞
白話說明
元素
陣列裡的每一格資料。
索引（index）
元素的編號，從 0 開始。寫在方括號裡，例如 scores[2]。
長度
陣列有幾格。宣告時就固定，不能改。
越界
用了不存在的索引，例如長度 5 卻去讀 scores[5]。
vector
可以變長變短的陣列，是日常寫程式時的首選。
範圍 for
for (int x : a)：不用管索引，逐個取出元素。

小技巧日常寫程式優先用 vector：不用事先決定長度、不用自己記長度、還能加減元素。陣列要先學，是因為它是 vector 的基礎，也常出現在別人的程式裡。

照著做：六個步驟

1

宣告陣列，用索引取值

先猜每一行印出什麼。下面的格子可以點著玩：輸入索引，讀取或寫入，也可以故意輸入 5 看看越界。

main.cpp · 點有 ⓘ 的行看說明
#include <iostream>using namespace std;int main() {    int scores[5] = {80, 92, 75, 60, 88};    cout << scores[0] << endl;    cout << scores[4] << endl;    scores[2] = 77;    cout << scores[2] << endl;    return 0;}
點程式碼中有 ⓘ 的那一行，這裡會說明它在做什麼。
執行結果
80
88
77
你會看到長度是 5，合法的索引是 0 到 4。最後一個元素永遠是「長度 − 1」。
2

用迴圈走訪陣列

陣列配迴圈是最常見的組合。i 從 0 跑到「長度 − 1」，用條件 i < 5。

main.cpp · 點有 ⓘ 的行看說明
#include <iostream>using namespace std;int main() {    int scores[5] = {80, 92, 75, 60, 88};    int sum = 0;    for (int i = 0; i < 5; i++) {        sum += scores[i];    }    double avg = sum / 5.0;    cout << "總分:" << sum << endl;    cout << "平均:" << avg << endl;    return 0;}
點程式碼中有 ⓘ 的那一行，這裡會說明它在做什麼。
執行結果
總分:395
平均:79
小技巧走訪陣列的條件用 i < 長度，不是 i <= 長度。這就是第 7 篇的差一錯誤，在陣列上會變成越界。
3

找出最大值

經典的「擂台」做法：先假設第一個最大，再逐一比較，遇到更大的就換人。

main.cpp · 點有 ⓘ 的行看說明
#include <iostream>using namespace std;int main() {    int scores[5] = {80, 92, 75, 60, 88};    int best = scores[0];    for (int i = 1; i < 5; i++) {        if (scores[i] > best) {            best = scores[i];        }    }    cout << "最高分:" << best << endl;    return 0;}
點程式碼中有 ⓘ 的那一行，這裡會說明它在做什麼。
執行結果
最高分:92
4

範圍 for：不用管索引

只想「每個元素都處理一遍」，不需要知道是第幾個時，範圍 for 最簡單，也不可能越界。

main.cpp · 點有 ⓘ 的行看說明
#include <iostream>using namespace std;int main() {    int scores[5] = {80, 92, 75, 60, 88};    for (int s : scores) {        cout << s << " ";    }    cout << endl;    return 0;}
點程式碼中有 ⓘ 的那一行，這裡會說明它在做什麼。
執行結果
80 92 75 60 88
5

vector：會自己長大的陣列

按下面的按鈕操作 v，看每個操作前後的內容。注意 push_back 會讓長度加 1,v[i] = x 只改那一格。

main.cpp · 點有 ⓘ 的行看說明
#include <iostream>#include <vector>using namespace std;int main() {    vector<int> v = {3, 5, 8};    v.push_back(10);    cout << "長度:" << v.size() << endl;    cout << "v[1] = " << v[1] << endl;    for (int x : v) {        cout << x << " ";    }    cout << endl;    v.pop_back();    cout << "現在長度:" << v.size() << endl;    return 0;}
點程式碼中有 ⓘ 的那一行，這裡會說明它在做什麼。
執行結果
長度:4
v[1] = 5
3 5 8 10 
現在長度:3
6

邊讀邊加：不知道有幾個數字

陣列的長度要事先決定，vector 就不用：有幾個，就 push_back 幾個。橘色是你要輸入的。

main.cpp · 點有 ⓘ 的行看說明
#include <iostream>#include <vector>using namespace std;int main() {    vector<int> v;    int n, x;    cout << "要輸入幾個數字?";    cin >> n;    for (int i = 0; i < n; i++) {        cin >> x;        v.push_back(x);    }    int best = v[0];    for (int e : v) {        if (e > best) {            best = e;        }    }    cout << "共 " << v.size() << " 個,最大的是 " << best << endl;    return 0;}
點程式碼中有 ⓘ 的那一行，這裡會說明它在做什麼。
執行結果（橘色是你要輸入的部分）
要輸入幾個數字?4
7 3 9 5
共 4 個,最大的是 9

最後補充二維陣列：想成一張表格，用兩個索引取值。

main.cpp · 點有 ⓘ 的行看說明
#include <iostream>using namespace std;int main() {    int grid[2][3] = {{1, 2, 3}, {4, 5, 6}};    for (int r = 0; r < 2; r++) {        for (int c = 0; c < 3; c++) {            cout << grid[r][c] << " ";        }        cout << endl;    }    cout << grid[1][2] << endl;    return 0;}
點程式碼中有 ⓘ 的那一行，這裡會說明它在做什麼。
執行結果
1 2 3 
4 5 6

越界：C++ 不會替你檢查

用了不存在的索引（越界），C++ 的陣列不會報錯：它直接去存取那個位置的記憶體。可能讀到無關的資料，可能改壞別的變數，也可能一切看起來正常——所以最難找。上面步驟 1 的格子可以親手試試。

想要「越界就明確報錯」，vector 提供了 at()。同樣是取第 10 個元素，對照看看：v[10] 是未定義行為，v.at(10) 則會讓程式立刻停下來並告訴你原因：

main.cpp · 點有 ⓘ 的行看說明
#include <iostream>#include <vector>using namespace std;int main() {    vector<int> v = {1, 2, 3, 4, 5};    cout << "準備讀取 v.at(10)" << endl;    cout << v.at(10) << endl;    cout << "這一行不會被執行" << endl;    return 0;}
點程式碼中有 ⓘ 的那一行，這裡會說明它在做什麼。
程式輸出（中止之前）
準備讀取 v.at(10)
程式異常中止（執行時錯誤，g++ 的訊息）
terminate called after throwing an instance of 'std::out_of_range'
  what():  vector::_M_range_check: __n (which is 10) >= this->size() (which is 5)
重要程式用 at() 越界會「當掉」，這已經比默默出錯好太多：你馬上知道哪裡錯。除錯時可以暫時把 v[i] 換成 v.at(i) 來找問題。（例外處理第 16 篇會學，現在先認得這個訊息。）

初學者最常卡住的四個地方

想用 a[5] 取最後一個元素

長度 5 的陣列，最後一個是 a[4]。可以記成：長度是「幾個」，索引是「第幾個，從 0 起算」。

宣告陣列時用變數當長度

int n = 5; int a[n]; 在標準 C++ 裡不合法（有些編譯器勉強接受，但不要依賴）。長度需要在編譯時就知道。要長度由程式決定，請用 vector。

忘了 #include <vector>

編譯器會說 vector 不是 std 的成員或沒有宣告。補上 #include <vector> 就好。

陣列沒給初始值，印出奇怪的數字

int a[5]; 的內容是不確定的舊資料。要全部歸零可以寫 int a[5] = {};；vector<int> v(5); 也會把 5 個元素都設成 0。

動手演練：陣列與 vector

每題先自己寫，再展開看參考解答。

練習 1：總和、平均與最大值

陣列 {12, 7, 30, 4, 19, 8}。用一個迴圈同時算出總和、平均與最大值。

看參考解答（先自己寫再看）
main.cpp
#include <iostream>using namespace std;int main() {    int a[6] = {12, 7, 30, 4, 19, 8};    int sum = 0, best = a[0];    for (int i = 0; i < 6; i++) {        sum += a[i];        if (a[i] > best) {            best = a[i];        }    }    cout << "總和:" << sum << endl;    cout << "平均:" << sum / 6.0 << endl;    cout << "最大:" << best << endl;    return 0;}
執行結果
總和:80
平均:13.3333
最大:30

平均要用 sum / 6.0，才不會被整數除法捨去小數（第 5 篇）。

練習 2：反過來印

把 {1, 2, 3, 4, 5} 由最後一個印到第一個。提示：迴圈從 4 倒數到 0。

看參考解答（先自己寫再看）
main.cpp
#include <iostream>using namespace std;int main() {    int a[5] = {1, 2, 3, 4, 5};    for (int i = 4; i >= 0; i--) {        cout << a[i] << " ";    }    cout << endl;    return 0;}
執行結果
5 4 3 2 1
練習 3：去除重複

vector 裡有 {3, 1, 3, 2, 1, 4}。建立另一個 vector，只放「第一次出現」的數字，最後印出 3 1 2 4。提示：對每個數字，先到新的 vector 裡找找看有沒有。

看參考解答（先自己寫再看）
main.cpp
#include <iostream>#include <vector>using namespace std;int main() {    vector<int> v = {3, 1, 3, 2, 1, 4};    vector<int> result;    for (int x : v) {        bool found = false;        for (int u : result) {            if (u == x) {                found = true;                break;            }        }        if (!found) {            result.push_back(x);        }    }    for (int u : result) {        cout << u << " ";    }    cout << endl;    return 0;}
執行結果
3 1 2 4

內層迴圈用 found 旗標記錄「找到了沒」，找到就 break；沒找到才 push_back。這是巢狀迴圈加旗標的經典寫法。
