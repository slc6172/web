if 決定走哪條路，switch 適合一長串選項

讓程式依情況做不同的事：if / else if / else、switch、巢狀條件與三元運算子，並用追蹤器看清楚到底是哪個分支被執行。

TL;DR if / else if / else 依序檢查條件，只執行第一個成立的分支，所以範圍條件要從最嚴格的開始寫。switch 依值跳轉，每個 case 結尾要 break。條件裡用 ==，不是 =。

條件判斷讓程式在路口選路

像走路遇到岔路

到目前為止，程式都是從上到下一路走到底。條件判斷讓它在路口先看一個條件，依成立或不成立，走不同的路。這就是「分支」。

條件就是第 5 篇的比較與邏輯運算式。C++ 的規則很簡單：結果是 0 就是假，不是 0 就是真。

五個名詞

名詞
白話說明
條件
放在小括號裡、算出來是真或假的運算式，例如 age >= 18。
分支
程式可能走的其中一條路。
if / else if / else
依序檢查條件，執行第一個成立的分支。
switch
依一個整數或字元的值，直接跳到對應的 case。
巢狀
條件裡面再放條件。

照著做：五個步驟

1

if 與 else：二選一

if 後面的條件成立，就做第一段；不成立，做 else 那一段。橘色是你要輸入的。

main.cpp · 點有 ⓘ 的行看說明
#include <iostream>using namespace std;int main() {    int age;    cout << "年齡:";    cin >> age;    if (age >= 18) {        cout << "成年" << endl;    } else {        cout << "未成年" << endl;    }    return 0;}
點程式碼中有 ⓘ 的那一行，這裡會說明它在做什麼。
執行結果（橘色是你要輸入的部分）
年齡:20
成年
最常見的錯條件的小括號後面不要加分號：if (age >= 18); 會讓 if 變成「什麼都不做」，後面的大括號永遠會執行。
小技巧即使裡面只有一行，也養成加大括號的習慣。以後再加第二行時，才不會出錯。
2

else if：多選一

超過兩種情況，就用 else if 接著問。下面先看程式，再用追蹤器觀察：輸入不同的分數，看哪一個分支被執行。

main.cpp · 綠色底 = 這一步新增或改過的行 · 點有 ⓘ 的行看說明
#include <iostream>using namespace std;int main() {    int score;    cout << "分數:";    cin >> score;    if (score >= 90) {        cout << "A" << endl;    } else if (score >= 80) {        cout << "B" << endl;    } else if (score >= 60) {        cout << "C" << endl;    } else {        cout << "不及格" << endl;    }    return 0;}
點程式碼中有 ⓘ 的那一行，這裡會說明它在做什麼。
執行結果（橘色是你要輸入的部分）
分數:85
B
你會看到只有第一個成立的分支會執行。輸入 95 時，後面的 score >= 80 雖然也成立，卻根本不會被檢查。所以條件的順序很重要：要從最嚴格的開始寫。
3

switch：依值跳轉

當條件是「某個整數或字元等於幾」時，switch 比一長串 else if 清楚。下面的追蹤器可以取消 break，看「穿透」是什麼。

main.cpp · 點有 ⓘ 的行看說明
#include <iostream>using namespace std;int main() {    int choice;    cout << "1 查詢  2 新增  3 離開,請選擇:";    cin >> choice;    switch (choice) {        case 1:            cout << "查詢中" << endl;            break;        case 2:            cout << "新增中" << endl;            break;        case 3:            cout << "再見" << endl;            break;        default:            cout << "沒有這個選項" << endl;    }    return 0;}
點程式碼中有 ⓘ 的那一行，這裡會說明它在做什麼。
執行結果（橘色是你要輸入的部分）
1 查詢  2 新增  3 離開,請選擇:2
新增中

真的把 break 全部拿掉的程式長這樣（輸入 2，和上面追蹤器取消勾選的結果一樣）：

main.cpp · 綠色底 = 這一步新增或改過的行
#include <iostream>using namespace std;int main() {    int choice;    cout << "請選擇:";    cin >> choice;    switch (choice) {        case 1:            cout << "查詢中" << endl;            // fall through        case 2:            cout << "新增中" << endl;            // fall through        case 3:            cout << "再見" << endl;            // fall through        default:            cout << "沒有這個選項" << endl;    }    return 0;}
執行結果（橘色是你要輸入的部分）
請選擇:2
新增中
再見
沒有這個選項
注意漏寫 break 是 switch 最常見的錯。除非你刻意要穿透（而且寫上註解說明），否則每個 case 結尾都要有 break。
4

巢狀：條件裡面再放條件

先判斷年齡，成年的人再判斷是不是學生。只有外層成立，才會走進去檢查內層。

main.cpp · 點有 ⓘ 的行看說明
#include <iostream>using namespace std;int main() {    int age, student;    cout << "年齡與是否學生(1 是、0 否):";    cin >> age >> student;    if (age >= 18) {        if (student == 1) {            cout << "學生票" << endl;        } else {            cout << "全票" << endl;        }    } else {        cout << "兒童票" << endl;    }    return 0;}
點程式碼中有 ⓘ 的那一行，這裡會說明它在做什麼。
執行結果（橘色是你要輸入的部分）
年齡與是否學生(1 是、0 否):20 1
學生票
小技巧巢狀超過兩三層就很難讀。如果發現自己縮排越來越深，考慮改用 && 合併條件，或拆開處理。
5

三元運算子：二選一取值

只是要在兩個值中挑一個時，可以用 條件 ? 值1 : 值2 代替整段 if / else。

main.cpp · 點有 ⓘ 的行看說明
#include <iostream>using namespace std;int main() {    int a = 17, b = 5;    int bigger = (a > b) ? a : b;    cout << "較大的數:" << bigger << endl;    return 0;}
點程式碼中有 ⓘ 的那一行，這裡會說明它在做什麼。
執行結果
較大的數:17
小技巧三元運算子適合簡短的二選一。需要做很多事，還是用 if 比較清楚。

初學者最常卡住的四個地方

if (x = 5) 永遠成立

單個 = 是賦值：它把 5 放進 x，然後整個式子的值是 5（不是 0），所以條件永遠為真，而且 x 還被改掉了。要比較請寫 ==。許多編譯器開啟警告選項（例如 -Wall）時會提醒你。

成績 95 分卻得到 C

檢查順序反了。若先寫 if (score >= 60),95 分馬上成立，後面的 >= 90 就沒有機會被檢查。範圍型條件要從最嚴格的開始寫。

switch 裡用了小數或文字

switch 括號裡只能是整數或字元（int、char 等），不能用 double 或字串。需要比較那些，就用 if / else if。

case 裡宣告變數，編譯失敗

在 case 下面直接宣告變數常會編譯失敗。把該 case 的內容用大括號 { } 包起來即可。目前先避免在 case 裡宣告變數。

動手演練：讓程式自己做決定

每題先自己寫，再展開看參考解答。可以自己換不同的輸入值測試每個分支。

練習 1：判斷奇偶

讀入一個整數，印出它是奇數還是偶數。提示：第 5 篇學過 n % 2。

看參考解答（先自己寫再看）
main.cpp
#include <iostream>using namespace std;int main() {    int n;    cout << "整數:";    cin >> n;    if (n % 2 == 0) {        cout << n << " 是偶數" << endl;    } else {        cout << n << " 是奇數" << endl;    }    return 0;}
執行結果（橘色是你要輸入的部分）
整數:7
7 是奇數
練習 2：成績等級

讀入分數，依序印出 A（90 以上）、B（70 以上）、C（60 以上）、D（其餘）。如果分數不在 0 到 100 之間，要印出錯誤訊息。

看參考解答（先自己寫再看）
main.cpp
#include <iostream>using namespace std;int main() {    int score;    cout << "分數:";    cin >> score;    if (score > 100 || score < 0) {        cout << "分數必須在 0 到 100 之間" << endl;    } else if (score >= 90) {        cout << "等級 A" << endl;    } else if (score >= 70) {        cout << "等級 B" << endl;    } else if (score >= 60) {        cout << "等級 C" << endl;    } else {        cout << "等級 D" << endl;    }    return 0;}
執行結果（橘色是你要輸入的部分）
分數:72
等級 B

先檢查不合法的輸入，再從最嚴格的條件往下寫。多試幾個分數：100、70、69、-5。

練習 3：簡易計算機

讀入「數字 運算子 數字」，例如 12 + 30。用 switch 依運算子（char）計算並印出結果；不認識的運算子印出「不支援的運算子」。

看參考解答（先自己寫再看）
main.cpp
#include <iostream>using namespace std;int main() {    int a, b;    char op;    cout << "算式(例如 12 + 30):";    cin >> a >> op >> b;    switch (op) {        case '+':            cout << a + b << endl;            break;        case '-':            cout << a - b << endl;            break;        case '*':            cout << a * b << endl;            break;        case '/':            cout << a / b << endl;            break;        default:            cout << "不支援的運算子" << endl;    }    return 0;}
執行結果（橘色是你要輸入的部分）
算式(例如 12 + 30):12 + 30
42

case 後面的字元要用單引號：case '+':。
