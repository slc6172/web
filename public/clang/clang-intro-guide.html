寫、編譯、執行：三步就能讓 C++ 動起來

這一篇不教新語法，只做一件事：讓你的第一支 C++ 程式真的跑起來。選好環境、貼上現成的程式、看到輸出，就完成了第一步。

TL;DR C++ 程式要先編譯成機器看得懂的檔案才能執行：寫 → 編譯 → 執行。新手先用線上編譯器，貼上程式按 Run 就能看到結果；想離線練習再安裝 g++。

C++ 是「先翻譯、再執行」的語言

用「食譜與廚師」來想

你寫的程式像一份用人類語言寫的食譜，但電腦這位廚師只看得懂機器碼。所以中間需要一位翻譯：編譯器。翻譯一次，就得到一份廚師能直接照做的版本。

這和 Python 那種「邊讀邊做」的直譯式語言不同。C++ 多了編譯這一步，好處是跑起來很快、而且很多錯誤在執行前就會被揪出來。

先認識六個名詞

名詞
白話說明
原始碼
你寫的程式，一個純文字檔，副檔名 .cpp。
編譯器
把原始碼檢查並翻譯成機器碼的工具，例如 g++。
編譯
執行翻譯這個動作。有文法錯誤就會失敗並告訴你錯在哪。
可執行檔
編譯的成果，Windows 上是 .exe，可以直接執行。
執行
讓可執行檔真的跑起來，看到程式的結果。
IDE
整合開發環境：把編輯器、編譯器與「執行」按鈕包在一起的軟體，例如 VS Code 加外掛、Code::Blocks。

全貌：寫、編譯、執行，三步循環

點任一個方塊，或按「下一步」。勾選右下角的選項，看看編譯失敗時會怎樣。

小技巧整本教學都是同一個循環：寫一點 → 編譯 → 執行 → 看結果 → 再改。每次只改一點點，出錯時就很容易找到原因。

選一條路：先用線上編譯器，之後再裝本機

目標只有一個：今天就看到第一行輸出。環境問題是初學者最常放棄的地方，所以建議先走左邊。

路線 A · 線上編譯器（推薦）

免安裝，打開網頁就能寫、編譯、執行。

  1. 用瀏覽器開啟任一個線上 C++ 編譯器（本頁最下方有連結）。
  2. 確認語言選的是 C++；如果有版本選項，選 C++17。
  3. 把程式貼進編輯區，按 Run（或 Execute），看輸出區。
  4. 需要輸入資料時（第 4 篇起），通常在網頁上的 Input / stdin 欄位填寫。

路線 B · 本機安裝 g++（進階）

想離線練習、或之後要做大一點的專案時再裝。

  1. Linux(Debian、Ubuntu):sudo apt install g++。
  2. macOS：在終端機執行 xcode-select --install。之後的 g++ 指令實際上是 Apple 的 clang，用法相同。
  3. Windows：最省事是先安裝 WSL（Windows 內建的 Linux 子系統），再照 Linux 的做法；也可以用 MSYS2。
  4. 安裝後用 g++ --version 確認有看到版本號。
本機要用到的三個指令（看一眼就好）

把程式存成 main.cpp，在同一個資料夾的終端機裡：

Linux / macOS
g++ -std=c++17 main.cpp -o main
./main
Windows（PowerShell 請用 .\main.exe）
g++ -std=c++17 main.cpp -o main.exe
main.exe

-std=c++17 指定語言版本，-o 指定可執行檔的名字。本教學全部以 C++17 為準。

跟著做：讓第一支程式跑起來

1

貼上一支現成的程式

先不用懂內容（第 2 篇會逐行解釋），只要能把它跑起來。

  1. 線上編譯器：把下面的程式整段貼進編輯區。
  2. 本機：存成 main.cpp。
main.cpp
#include <iostream>int main() {    std::cout << "Hello, C++!" << std::endl;    return 0;}
2

編譯並執行

線上：按 Run。本機：用上一節的兩行指令。兩種方式都該得到同樣的結果。

你會看到（輸出區）
Hello, C++!
你會看到輸出區出現 Hello, C++! 這一行。看到它，你就完成了從「寫」到「執行」的完整循環。
3

改一個字，再跑一次

把雙引號裡的內容改成別的字，再編譯、執行一次。這是你第一次「改程式、看結果」。

main.cpp · 綠色底 = 這一步新增或改過的行
#include <iostream>int main() {    std::cout << "Hello, 小明!" << std::endl;    return 0;}
執行結果
Hello, 小明!
小技巧每次改完程式，都要重新編譯（線上就是重新按 Run），輸出才會更新。很多人以為沒變，其實是執行到舊的版本。

初學者最常卡住的四個地方

本機輸入 g++ 顯示「找不到指令」或「不是內部或外部命令」

代表 g++ 還沒安裝，或安裝了但沒有加入系統的 PATH。先用 g++ --version 確認；如果只是想先學語法，改用線上編譯器最快。

線上編譯器按 Run 後出現奇怪的錯誤

先檢查頁面上選的語言是不是 C++。選成 C 或其他語言，同一段程式會因為語言不同而報一堆看不懂的錯。

中文輸出變成亂碼

多半是終端機的編碼不是 UTF-8。Windows 的命令提示字元可以先執行 chcp 65001；或直接改用線上編譯器，它通常沒有這個問題。

編譯成功了，但輸出還是舊的

幾乎都是忘了存檔，或是執行到舊的可執行檔。養成「存檔 → 編譯 → 執行」三個動作連著做的習慣。

動手演練：確認你真的跑得起來

每題先自己做，再展開看參考解答。

練習 1：多印一行

在 Hello, C++! 那一行的下面，再加一行，印出「我開始學 C++ 了」。編譯、執行，確認輸出有兩行。

看參考解答（先自己寫再看）
main.cpp · 綠色底 = 這一步新增或改過的行
#include <iostream>int main() {    std::cout << "Hello, C++!" << std::endl;    std::cout << "我開始學 C++ 了" << std::endl;    return 0;}
執行結果
Hello, C++!
我開始學 C++ 了
練習 2：故意搞壞它，再修好它

下面這支程式少了一個分號。先在你的環境裡編譯看看，是不是出現類似的訊息；再把它修好。第 2 篇會教你怎麼讀這些訊息。

main.cpp
#include <iostream>int main() {    std::cout << "Hello, C++!" << std::endl    return 0;}
編譯器的回應（g++）
main.cpp: In function ‘int main()’:
main.cpp:4:44: error: expected ‘;’ before ‘return’
    4 |     std::cout << "Hello, C++!" << std::endl
      |                                            ^
      |                                            ;
    5 |     return 0;
      |     ~~~~~~
看參考解答（先自己寫再看）
main.cpp · 綠色底 = 這一步新增或改過的行
#include <iostream>int main() {    std::cout << "Hello, C++!" << std::endl;    return 0;}
執行結果
Hello, C++!

分號補回來，就恢復正常了。編譯錯誤不可怕，它只是在告訴你「哪裡有問題」。
