vector 讀取很快，但在中間插入要搬家

vector 是學完 C++ 之後最常用的容器。這一篇用動畫看它裡面怎麼擺資料、為什麼在最前面插入很慢，以及它怎麼自己長大。

TL;DR vector 把元素連續放在一起，所以用索引讀取一步就到(O(1))。但在中間插入或刪除，後面的元素都要搬一格(O(n))；尾端 push_back 通常很快，只有容量滿了才要換新空間搬家。
先備：會用 vector、push_back 與 for。預估 12 分鐘。難度：入門。

vector 就是一排編號的置物櫃

用「一排緊貼的置物櫃」來想

想像走廊上有一排緊貼在一起的置物櫃，編號從 0 開始。要拿 5 號櫃的東西，你不用從 0 號開始一個個找，直接走到 5 號就好，這叫隨機存取，一步到位。

但如果想在 2 號和 3 號之間「再擠進一個新櫃子」，右邊每一個櫃子裡的東西，都得先往後搬一格。讀取很快、中間插入很貴，這就是這一篇要看懂的事。

五個名詞

名詞
白話說明
元素（element）
vector 裡存的每一筆資料，例如 {10, 20, 30} 有 3 個元素。
索引（index）
元素的編號，從 0 開始。v[0] 是第一個，最後一個是 v[size - 1]。
size
目前實際放了幾個元素。
capacity
目前向系統「租下」的格子數。永遠 ≥ size；容量用完了才需要換更大的空間。
連續記憶體
元素在記憶體中一個緊接一個排好。這讓 v[i] 能直接算出位置，也是「搬家」成本的來源。
原生陣列呢？你也許看過 int a[5];。它同樣是連續記憶體、同樣用索引讀取，但大小在寫程式時就固定，不能 push_back。這一篇的觀念兩者通用；實務上我們優先用 std::vector。

先認識 vector 的幾個寫法

這份程式用到本篇會出現的全部基本語法。先看一遍，不用背。

main.cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> v = {10, 20, 30};   // 建立,一開始有 3 個元素
    v.push_back(40);                     // 在尾端加一個
    std::cout << "size = " << v.size() << "\n";
    std::cout << "v[0] = " << v[0] << "\n";

    int total = 0;
    for (int i = 0; i < static_cast<int>(v.size()); ++i) {
        total += v[i];                   // 用索引逐一讀取
    }
    std::cout << "total = " << total << "\n";

    for (int x : v) {                    // range-for:不需要索引時更簡潔
        std::cout << x << " ";
    }
    std::cout << "\n";
}
執行結果
size = 4
v[0] = 10
total = 100
10 20 30 40
編譯並執行（g++ 或 clang++ 皆可）
g++ -std=c++17 -Wall -Wextra -o main main.cpp
./main
寫法
意思
std::vector<int> v = {10, 20, 30};
建立一個放 int 的 vector，一開始有 3 個元素。尖括號裡是元素的型別。
v.push_back(40);
在尾端加一個元素。vector 會自己長大，不用先決定大小。
v.size()
目前有幾個元素。
v[0]
用索引讀取（或修改）元素。
for (int x : v)
range-for：依序把每個元素拿出來給 x，不需要索引時最簡潔。
為什麼寫 static_cast<int>(v.size())?v.size() 的型別是無號整數(size_t)，不能是負數。拿它和 int 比較、相減，很容易出怪事（見下方「常見錯誤」）。本站一律先轉成 int 再用，讓初學階段少踩坑。

動手玩：在中間插入、從前面刪除

畫面上是一個 vector，下方的程式碼就是我們自己寫的 insertAt 與 eraseAt。每按一次「下一步」，就執行一小步，亮起來的行就是目前執行到的地方。

  1. 按「最前面插入」：看有幾個元素被搬動（橘色格子）。
  2. 按「尾端插入」：這次要搬幾個？
  3. 按「刪除最前面」，再按「刪除最後面」，比較搬動次數。
  4. 插入太多次後再按一次，看看會出現什麼提示。

猜猜看：這一步會發生什麼？

vector 現在有 5 個元素 {10, 20, 30, 40, 50}，在位置 0（最前面）插入一個新值，要搬動幾個既有元素？

選一個做法，看看對不對。

結論：搬動次數 = 插入位置之後有幾個元素。插在最前面要搬全部 n 個，插在尾端要搬 0 個。刪除也一樣，位置越靠前，後面要補位的元素越多。

動手玩：vector 怎麼自己長大

push_back 看起來永遠成功，但 vector 的格子是租來的。租的格子用完了，它就要換一塊更大的、把舊資料全部搬過去。

  1. 按幾次「push_back」，觀察 capacity 如何變化。
  2. 看到「已經滿了」時，注意舊空間與新空間兩列，以及累計複製的次數。
  3. 按「連續 9 次」，對照下方真實程式的輸出。
main.cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> v;
    for (int i = 1; i <= 9; ++i) {
        v.push_back(i);
        std::cout << v.size() << " " << v.capacity() << "\n";
    }
}
執行結果（size capacity）
1 1
2 2
3 4
4 4
5 8
6 8
7 8
8 8
9 16
你會看到capacity 依序是 1、2、4、4、8、8、8、8、16，每次滿了就變成 2 倍。這是 g++ 的做法；不同編譯器的倍數可能不同（例如 MSVC 是 1.5 倍），但「滿了就換更大的空間並搬家」是一樣的。
知道要放多少時，先 reserve如果事先知道大概會放 100 個，v.reserve(100) 一次租好，就不會在途中反覆搬家。
main.cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> v;
    v.reserve(100);                      // 一次先要 100 格,之後 push_back 不用再搬家
    for (int i = 0; i < 100; ++i) {
        v.push_back(i);
    }
    std::cout << "size = " << v.size() << ", capacity = " << v.capacity() << "\n";
}
執行結果
size = 100, capacity = 100

完整程式：自己寫一次插入與刪除

這就是動畫裡用的那兩個函式，加上 main 與印出的小函式。你可以複製到自己的電腦編譯執行。

main.cpp
#include <iostream>
#include <vector>

void insertAt(std::vector<int>& v, int pos, int value) {
    v.push_back(0);                      // 先在尾端多開一格
    int last = static_cast<int>(v.size()) - 1;
    for (int i = last; i > pos; --i) {
        v[i] = v[i - 1];                 // 把前一格搬過來
    }
    v[pos] = value;                      // 空位放進新值
}

void eraseAt(std::vector<int>& v, int pos) {
    int n = static_cast<int>(v.size());
    for (int i = pos; i + 1 < n; ++i) {
        v[i] = v[i + 1];                 // 把後一格搬過來
    }
    v.pop_back();                        // 丟掉最後一格
}

void print(const std::vector<int>& v) {
    for (int x : v) {
        std::cout << x << " ";
    }
    std::cout << "\n";
}

int main() {
    std::vector<int> v = {10, 20, 30, 40, 50};
    insertAt(v, 2, 99);
    print(v);                            // 插在位置 2
    eraseAt(v, 0);
    print(v);                            // 刪掉最前面
    insertAt(v, static_cast<int>(v.size()), 7);
    print(v);                            // 插在尾端
}
執行結果
10 20 99 30 40 50 
20 99 30 40 50 
20 99 30 40 50 7

重點在 for 迴圈：insertAt 從後面往前搬（不然會把還沒搬的資料蓋掉），eraseAt 從前面往後搬。順序反過來，結果就會錯。

實務上：直接用 STL

你不需要每次都自己寫迴圈。std::vector 已經提供 insert 與 erase，做的事和我們寫的一樣(一樣要搬動元素，一樣是 O(n))。v.begin() 是「指向第一個元素的位置」，v.begin() + 2 就是位置 2。

main.cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> v = {10, 20, 30, 40, 50};
    v.insert(v.begin() + 2, 99);         // 在位置 2 插入 99
    v.erase(v.begin());                  // 刪掉位置 0
    for (int x : v) {
        std::cout << x << " ";
    }
    std::cout << "\n";
}
執行結果
20 99 30 40 50

n 代表元素個數。O(1) 是「不管多少元素，都是固定幾步」；O(n) 是「元素越多，步數成正比」。（第 2 篇有完整說明。）

空間：O(n)。capacity 可能比 size 大（最多約 2 倍），這是用空間換「push_back 很少搬家」的代價。

初學者最常卡住的三個地方

v.size() - 1 在空 vector 上變成超大的數字

因為 size() 是無號整數，0 - 1 不會變成 -1，而是「繞回」最大值。如果拿它當迴圈上限，迴圈會跑到天荒地老。

main.cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> v;                      // 空的 vector
    std::cout << v.size() - 1 << "\n";       // 不是 -1!size() 是無號數
    int n = static_cast<int>(v.size());      // 先轉成 int 再計算
    std::cout << n - 1 << "\n";
}
執行結果（第一行就是那個超大數字）
18446744073709551615
-1

解法：先 static_cast<int>(v.size())，再計算。

v[10] 越界，程式卻沒有報錯

v[i] 不會檢查範圍。越界讀寫是未定義行為：可能剛好沒事、可能讀到亂值、也可能當掉，而且每次不一定一樣，最難除錯。

想要有保護，用 v.at(i)：越界時會丟出 std::out_of_range 例外，錯誤變得看得見。

main.cpp
#include <iostream>
#include <stdexcept>
#include <vector>

int main() {
    std::vector<int> v = {10, 20, 30};
    try {
        std::cout << v.at(10) << "\n";       // at() 會檢查範圍,越界就丟例外
    } catch (const std::out_of_range&) {
        std::cout << "out of range\n";
    }
}
執行結果
out of range
我 push_back 了很多次，程式變慢了

很可能是反覆擴容搬家。如果事先知道大概的數量，用 reserve（見上方「擴容」那一節）一次租好。另外，如果你常在最前面或中間插入，vector 本來就不適合，下一篇的鏈結串列是另一種取捨。

動手寫（兩題）

先自己在電腦上寫寫看，再展開參考答案。兩題的起始程式都能編譯，只是答案還不對。

第 1 題：把 x 加進 total（補一行）

下面的 sum 應該回傳所有元素的總和，但迴圈裡少了一行。補上它，輸出要是 14。

main.cpp
#include <iostream>
#include <vector>

int sum(const std::vector<int>& v) {
    int total = 0;
    for (int x : v) {
        // 在這裡加一行,把 x 加進 total
    }
    return total;
}

int main() {
    std::vector<int> v = {3, 1, 4, 1, 5};
    std::cout << sum(v) << "\n";         // 預期輸出 14
}
參考答案

迴圈裡加上這一行就好：total += x;

完整答案
#include <iostream>
#include <vector>

int sum(const std::vector<int>& v) {
    int total = 0;
    for (int x : v) {
        total += x;
    }
    return total;
}

int main() {
    std::vector<int> v = {3, 1, 4, 1, 5};
    std::cout << sum(v) << "\n";
}
執行結果
14

第 2 題：數有幾個大於 x（完整寫出函式）

完成 countGreater：回傳 v 裡「大於 x」的元素個數。範例的輸出應該是 4 和 0。

main.cpp
#include <iostream>
#include <vector>

int countGreater(const std::vector<int>& v, int x) {
    // 回傳 v 裡「大於 x」的元素有幾個
    return 0;
}

int main() {
    std::vector<int> v = {3, 1, 4, 1, 5, 9, 2, 6};
    std::cout << countGreater(v, 3) << "\n";   // 預期輸出 4
    std::cout << countGreater(v, 9) << "\n";   // 預期輸出 0
}
參考答案

用一個計數器，走訪每個元素，大於 x 就加 1。時間是 O(n)，因為每個元素都看一次。

完整答案
#include <iostream>
#include <vector>

int countGreater(const std::vector<int>& v, int x) {
    int count = 0;
    for (int y : v) {
        if (y > x) {
            ++count;
        }
    }
    return count;
}

int main() {
    std::vector<int> v = {3, 1, 4, 1, 5, 9, 2, 6};
    std::cout << countGreater(v, 3) << "\n";
    std::cout << countGreater(v, 9) << "\n";
}
執行結果
4
0
