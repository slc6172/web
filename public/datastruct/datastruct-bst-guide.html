C++ 演算法 · 第 12 篇 · 二元搜尋樹

小的往左、大的往右：一棵會自己排好序的樹

二元搜尋樹把二分搜尋做成指標連起來的樹。這一篇用動畫看插入、搜尋與刪除的三種情況，再看為什麼排序後插入會退化成一條鏈。

TL;DR BST 規則：左子樹全部比自己小、右子樹全部比自己大，所以搜尋、插入、刪除都是沿著一條路往下走，時間 O(h)（h 是高度）。樹平衡時 O(log n)，退化成鏈時 O(n)。實務上用自動平衡的 std::set / std::map。

直覺：把二分搜尋做成一棵樹

第 6 篇的二分搜尋，每次都先看「正中間」

在排好序的 1 2 3 4 5 6 7 裡找 5：先看中間的 4,5 比較大就往右半邊，再看 6，比較小就往左……每次砍掉一半。如果把「每次先看的那個數」畫成一棵樹，中間的 4 是根，左右兩邊各自再選中間的數當子節點。這就是一棵二元搜尋樹(BST)。

好處是：二分搜尋要求資料放在陣列裡、而且事先排好序，中間插入一個數得搬動一大堆元素（第 3 篇）；樹用指標連起來，插入只要接一條線（第 4 篇），又保留「每次砍一半」的找法。

唯一的規則，和幾個名詞

名詞
白話說明
BST 規則
對每一個節點：左子樹裡的值全部比它小，右子樹裡的值全部比它大（本篇不放重複的值）。
搜尋
比大小：小就往左、大就往右，走到相等就找到了，走到 nullptr 就是沒有。
插入
照搜尋的路走到 nullptr，新節點就放在那裡。新節點一定是葉。
後繼（successor）
比某個值大的值裡最小的那個。在 BST 裡，就是「右子樹一路往左走到底」的節點。刪除時會用到。
中序走訪
第 11 篇的「左 → 根 → 右」，在 BST 上剛好是由小到大。這是檢查 BST 有沒有壞掉的好方法。
節點長得和第 11 篇一樣還是 struct TreeNode { int val; TreeNode* left; TreeNode* right; };。差別不在長相，而在放進去的位置有規則。

搜尋與插入都只是「照路走」，刪除才需要想一下：拿掉節點之後，它的子樹要接去哪裡？

完整程式：插入、搜尋、刪除

四個函式都是遞迴，而且都長得像 node->left = f(node->left, val)：先處理子樹，再把回傳的新根接回來。回傳值就是這棵子樹「現在的根」，所以刪掉子樹的根時，上一層才能接到頂替的節點。

main.cpp
#include <iostream>

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
};

TreeNode* insert(TreeNode* node, int val) {
    if (node == nullptr) {
        return new TreeNode{val, nullptr, nullptr};
    }
    if (val < node->val) {
        node->left = insert(node->left, val);
    } else if (val > node->val) {
        node->right = insert(node->right, val);
    }
    return node;
}

bool search(const TreeNode* node, int val) {
    if (node == nullptr) {
        return false;
    }
    if (val == node->val) {
        return true;
    }
    if (val < node->val) {
        return search(node->left, val);
    }
    return search(node->right, val);
}

TreeNode* minNode(TreeNode* node) {
    while (node->left != nullptr) {
        node = node->left;
    }
    return node;
}

TreeNode* erase(TreeNode* node, int val) {
    if (node == nullptr) {
        return nullptr;
    }
    if (val < node->val) {
        node->left = erase(node->left, val);
    } else if (val > node->val) {
        node->right = erase(node->right, val);
    } else {
        if (node->left == nullptr) {
            TreeNode* r = node->right;
            delete node;
            return r;
        }
        if (node->right == nullptr) {
            TreeNode* l = node->left;
            delete node;
            return l;
        }
        TreeNode* succ = minNode(node->right);
        node->val = succ->val;
        node->right = erase(node->right, succ->val);
    }
    return node;
}

void inorder(const TreeNode* node) {
    if (node == nullptr) {
        return;
    }
    inorder(node->left);
    std::cout << node->val << " ";
    inorder(node->right);
}

void preorder(const TreeNode* node) {
    if (node == nullptr) {
        return;
    }
    std::cout << node->val << " ";
    preorder(node->left);
    preorder(node->right);
}

void destroy(TreeNode* node) {
    if (node == nullptr) {
        return;
    }
    destroy(node->left);
    destroy(node->right);
    delete node;
}

int main() {
    TreeNode* root = nullptr;
    for (int v : {5, 3, 8, 1, 4, 7, 9, 2, 6}) {
        root = insert(root, v);
    }
    std::cout << "inorder:  ";
    inorder(root);
    std::cout << "\npreorder: ";
    preorder(root);
    std::cout << "\nsearch 4, 10: " << search(root, 4) << " " << search(root, 10) << "\n";

    root = erase(root, 2);                   // 葉節點
    std::cout << "erase 2 : ";
    preorder(root);
    root = erase(root, 7);                   // 只有一個子節點
    std::cout << "\nerase 7 : ";
    preorder(root);
    root = erase(root, 3);                   // 有兩個子節點
    std::cout << "\nerase 3 : ";
    preorder(root);
    root = erase(root, 5);                   // 根節點,有兩個子節點
    std::cout << "\nerase 5 : ";
    preorder(root);
    std::cout << "\ninorder:  ";
    inorder(root);
    std::cout << "\n";
    destroy(root);
}

退化：同樣的資料，插入順序決定樹的高度

BST 的規則只管「大小關係」，完全不管「平不平衡」。資料如果本來就排好序，每個新值都比前面所有的值大，就一直往右接，樹變成一條鏈，其實就是第 4 篇的鏈結串列。

main.cpp
#include <algorithm>
#include <iostream>
#include <vector>

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
};

TreeNode* insert(TreeNode* node, int val) {
    if (node == nullptr) {
        return new TreeNode{val, nullptr, nullptr};
    }
    if (val < node->val) {
        node->left = insert(node->left, val);
    } else if (val > node->val) {
        node->right = insert(node->right, val);
    }
    return node;
}

int height(const TreeNode* node) {
    if (node == nullptr) {
        return 0;
    }
    return 1 + std::max(height(node->left), height(node->right));
}

void destroy(TreeNode* node) {
    if (node == nullptr) {
        return;
    }
    destroy(node->left);
    destroy(node->right);
    delete node;
}

int heightAfterInserting(const std::vector<int>& values) {
    TreeNode* root = nullptr;
    for (int v : values) {
        root = insert(root, v);
    }
    int h = height(root);
    destroy(root);
    return h;
}

int main() {
    std::cout << "4 2 6 1 3 5 7 -> height " << heightAfterInserting({4, 2, 6, 1, 3, 5, 7}) << "\n";
    std::cout << "1 2 3 4 5 6 7 -> height " << heightAfterInserting({1, 2, 3, 4, 5, 6, 7}) << "\n";
}
執行結果
4 2 6 1 3 5 7 -> height 3
1 2 3 4 5 6 7 -> height 7

7 個值，高度可以是 3，也可以是 7。差距隨 n 放大：100 萬個值，平衡的樹約 20 層，鏈卻有 100 萬層，搜尋從「走 20 步」變成「走 100 萬步」，遞迴還可能 stack overflow（第 7、11 篇）。

解法：自動平衡AVL 樹、紅黑樹會在插入、刪除之後旋轉子樹，讓高度維持在 O(log n)。旋轉的細節不在本篇範圍；下一節的 std::set 與 std::map 就已經幫你做好了。

實務上：std::set 與 std::map

自己寫 BST 是為了弄懂原理。實務上直接用 std::set（只存值）和 std::map（存 key 與 value）。C++ 標準只規定它們的複雜度是 O(log n)，常見實作是自動平衡的紅黑樹，所以不會退化成鏈。

main.cpp
#include <iostream>
#include <map>
#include <set>
#include <string>

int main() {
    std::set<int> s = {5, 3, 8, 1};          // 自動平衡的搜尋樹(紅黑樹),元素永遠排好序
    s.insert(4);
    s.erase(3);
    for (int x : s) {
        std::cout << x << " ";               // 由小到大
    }
    std::cout << "\n";
    std::cout << s.count(4) << s.count(3) << "\n";
    auto it = s.lower_bound(5);              // 第一個 >= 5 的元素
    std::cout << *it << "\n";

    std::map<std::string, int> age = {{"Cara", 30}, {"Ann", 25}, {"Bob", 28}};
    for (const auto& entry : age) {
        std::cout << entry.first << "=" << entry.second << " ";   // 依 key 排序
    }
    std::cout << "\n";
}

複雜度小表

n 是節點數，h 是樹的高度。搜尋、插入、刪除都是沿著一條從根往下的路走，所以時間是 O(h)。

一句話：BST 的速度取決於高度。所以才有各種「讓樹保持矮胖」的平衡樹。

初學者最常卡住的四個地方

刪除兩個子節點時，直接把節點拿掉

只有一個指標位置，卻有兩棵子樹要接，放不下。正確做法是找後繼（右子樹最小的）的值抄過來，再刪掉後繼。用「左子樹最大的」（前驅）也可以，對稱。

忘了把回傳值接回去

node->left = insert(node->left, val); 的 node->left = 不能省。寫成單獨一行 insert(node->left, val);，新節點 new 出來卻沒有任何指標指向它，樹沒變、記憶體也洩漏。呼叫端同理：要寫 root = insert(root, v);，否則空樹永遠是空的。

忽略重複的值

這份程式遇到相等的值什麼都不做（和 std::set 一樣）。如果需要重複值，要先決定規則：例如多存一個「出現次數」，或統一放右邊（std::multiset 就允許重複）。不決定就寫，搜尋和刪除會出現怪結果。

以為 BST 一定很快

資料已經排好序、或幾乎排好序時，依序插入會得到一條鏈，O(log n) 變成 O(n)。實務上用 std::set / std::map，或自己實作平衡樹。

動手演練：確認你真的懂了

動手寫（兩題）

兩題都在同一棵樹上測試：根 5，左邊 3（再接 1），右邊 7。

第 1 題：用迴圈寫 contains

不用遞迴，從根出發，小就往左、大就往右，直到找到或走到 nullptr。輸出應該是 1100。

main.cpp
#include <iostream>

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
};

// 用「迴圈」(不用遞迴)在二元搜尋樹裡找 val。
// 提示:從 root 出發,比較 val 和目前節點的值,往左或往右走,直到找到或走到 nullptr。
bool contains(const TreeNode* root, int val) {
    (void)root;
    (void)val;
    return false;
}

int main() {
    TreeNode n1{1, nullptr, nullptr};
    TreeNode n7{7, nullptr, nullptr};
    TreeNode n3{3, &n1, nullptr};
    TreeNode n5{5, &n3, &n7};
    std::cout << contains(&n5, 3) << contains(&n5, 7) << contains(&n5, 4) << contains(nullptr, 1) << "\n";   // 預期輸出 1100
}
參考答案

每一步只會走一邊，所以用 while 迴圈就夠了，額外空間只要 O(1)（遞迴版是 O(h)）。

完整答案
#include <iostream>

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
};

bool contains(const TreeNode* root, int val) {
    const TreeNode* cur = root;
    while (cur != nullptr) {
        if (val == cur->val) {
            return true;
        }
        cur = (val < cur->val) ? cur->left : cur->right;
    }
    return false;
}

int main() {
    TreeNode n1{1, nullptr, nullptr};
    TreeNode n7{7, nullptr, nullptr};
    TreeNode n3{3, &n1, nullptr};
    TreeNode n5{5, &n3, &n7};
    std::cout << contains(&n5, 3) << contains(&n5, 7) << contains(&n5, 4) << contains(nullptr, 1) << "\n";
}
執行結果
1100

第 2 題：把 BST 依序放進 vector

用中序走訪把值放進 out。輸出應該是 1 3 5 7（已經排好序）。

main.cpp
#include <iostream>
#include <vector>

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
};

// 用「中序走訪」把二元搜尋樹的所有值依序放進 out。BST 的中序結果會是由小到大。
void toSorted(const TreeNode* node, std::vector<int>& out) {
    (void)node;
    (void)out;
}

int main() {
    TreeNode n1{1, nullptr, nullptr};
    TreeNode n7{7, nullptr, nullptr};
    TreeNode n3{3, &n1, nullptr};
    TreeNode n5{5, &n3, &n7};
    std::vector<int> out;
    toSorted(&n5, out);
    for (int x : out) {
        std::cout << x << " ";
    }
    std::cout << "\n";                       // 預期輸出 1 3 5 7
}
參考答案

就是第 11 篇的中序：先左、再把自己放進去、最後右。不用排序，走完就是排好的，時間 O(n)。

完整答案
#include <iostream>
#include <vector>

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
};

void toSorted(const TreeNode* node, std::vector<int>& out) {
    if (node == nullptr) {
        return;
    }
    toSorted(node->left, out);
    out.push_back(node->val);
    toSorted(node->right, out);
}

int main() {
    TreeNode n1{1, nullptr, nullptr};
    TreeNode n7{7, nullptr, nullptr};
    TreeNode n3{3, &n1, nullptr};
    TreeNode n5{5, &n3, &n7};
    std::vector<int> out;
    toSorted(&n5, out);
    for (int x : out) {
        std::cout << x << " ";
    }
    std::cout << "\n";
}
執行結果
1 3 5 7
