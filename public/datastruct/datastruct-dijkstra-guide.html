邊有長短：每次確定「目前最近」的那個點

BFS 數的是步數；邊有權重時要用 Dijkstra。這一篇用動畫看距離表一步步被更新，理解「鬆弛」與優先佇列怎麼配合。

TL;DR Dijkstra 從起點出發，每次從優先佇列取出距離最小的點，把它的距離確定，再用它去鬆弛鄰居（d + w < dist[v] 就更新）。權重必須非負，時間 O((V + E) log V)。

直覺：邊有「長短」，最少步數不等於最短

三站直達 vs 轉兩次車，哪個比較快？

第 14 篇的 BFS 數的是步數：每走一條邊算 1。但真實的路有長短：公里數、分鐘、車資。給每條邊一個數字，叫權重(weight)。這時「最少步數」不一定是「總長最短」：一條邊權重 10 的直達路，可能比兩條權重 3 和 4 的路還長。

Dijkstra 演算法（讀作「迪克斯特拉」）找的就是：從一個起點出發，到每個點的總權重最小的路。想法是貪心：每次從「還沒確定的點」裡挑目前距離最小的，把它的最短距離確定下來，再用它去更新鄰居。

幾個名詞

名詞
白話說明
權重（weight）
邊上的數字，代表走這條邊的代價（距離、時間、費用）。本篇權重都是正數。
dist[v]
到目前為止，從起點走到 v 找到的最短距離。一開始起點是 0，其他是 ∞（還沒走到）。
鬆弛（relax）
看一條邊 u→v：如果「走到 u 的距離 + 邊的權重」比目前記的 dist[v] 更短，就更新。就像把繃緊的繩子放鬆一點。
確定（finalized）
從 pq 取出、距離最小的點，它的 dist 之後不會再變短。
prev[v]
最短路上 v 的前一個點。從終點一路往回找，就能還原整條路。
優先佇列
第 13 篇的堆積。放 (距離, 點)，每次先拿距離最小的。

猜猜看：最短距離是多少？

在「繞路更近」那張圖，起點 0 到點 1 有一條直達的邊，權重 10；另外還有 0→2（權重 3）與 2→1（權重 4）。起點 0 到點 1 的最短距離是？

為什麼「每次拿最小的」就是對的？

假設 pq 現在給出距離最小的點 u，距離 d。如果還有更短的路到 u，那條路必須先經過某個還沒確定的點；但那些點的距離都 ≥ d（因為 d 是最小的），再加上一條非負的邊，只會更長，不可能比 d 短。所以 u 的距離確定了。這個論證依賴權重不能是負的。

完整程式：Dijkstra

骨架和 BFS 很像：一個容器放待處理的點，取出一個、看它的鄰居。差別是容器換成優先佇列（最小堆積，所以 greater），而且多了「鬆弛」那一步。dist 是答案，prev 用來還原路徑。

main.cpp
#include <functional>
#include <iostream>
#include <queue>
#include <utility>
#include <vector>

struct Edge {
    int to;
    int w;
};

using Graph = std::vector<std::vector<Edge>>;
using Item = std::pair<int, int>;
const int INF = 1000000000;

void dijkstra(const Graph& g, int src, std::vector<int>& dist, std::vector<int>& prev) {
    dist.assign(g.size(), INF);
    prev.assign(g.size(), -1);
    std::priority_queue<Item, std::vector<Item>, std::greater<Item>> pq;
    dist[src] = 0;
    pq.push({0, src});
    while (!pq.empty()) {
        Item top = pq.top();
        pq.pop();
        int d = top.first;
        int u = top.second;
        if (d > dist[u]) {
            continue;
        }
        for (const Edge& e : g[u]) {
            if (d + e.w < dist[e.to]) {
                dist[e.to] = d + e.w;
                prev[e.to] = u;
                pq.push({dist[e.to], e.to});
            }
        }
    }
}

void addEdge(Graph& g, int a, int b, int w) {
    g[a].push_back({b, w});
    g[b].push_back({a, w});
}

void report(const Graph& g, int src, int target) {
    std::vector<int> dist;
    std::vector<int> prev;
    dijkstra(g, src, dist, prev);
    std::cout << "dist:";
    for (int d : dist) {
        std::cout << " " << d;
    }
    std::cout << "\n";
    std::vector<int> path;
    for (int v = target; v != -1; v = prev[v]) {
        path.push_back(v);
    }
    std::cout << "到 " << target << " 的路(" << dist[target] << "):";
    for (int i = static_cast<int>(path.size()) - 1; i >= 0; --i) {
        std::cout << " " << path[i];
    }
    std::cout << "\n";
}

int main() {
    Graph a(6);
    addEdge(a, 0, 1, 7);
    addEdge(a, 0, 2, 9);
    addEdge(a, 0, 5, 14);
    addEdge(a, 1, 2, 10);
    addEdge(a, 1, 3, 15);
    addEdge(a, 2, 3, 11);
    addEdge(a, 2, 5, 2);
    addEdge(a, 3, 4, 6);
    addEdge(a, 4, 5, 9);
    report(a, 0, 4);
    Graph b(5);
    addEdge(b, 0, 1, 10);
    addEdge(b, 0, 2, 3);
    addEdge(b, 2, 1, 4);
    addEdge(b, 1, 3, 2);
    addEdge(b, 2, 3, 8);
    addEdge(b, 3, 4, 7);
    report(b, 0, 4);
}

複雜度小表

V 是點數，E 是邊數。每條邊最多讓 pq 多一筆，pq 的 push / pop 各是 O(log)。

初學者最常卡住的四個地方

邊的權重是負的

Dijkstra 的「確定了就不會變」靠的是非負權重。有負權重的邊時，之後可能出現更短的路，答案會錯。遇到負權重要改用 Bellman-Ford 之類的演算法。

INF 加權重溢位

如果寫成 dist[u] + w 而 dist[u] 還是 INF,INF + w 可能超過 int 範圍。本篇只對從 pq 取出、一定走得到的點做加法，所以安全。INF 也不要設成 INT_MAX。

pq 用成最大堆積

priority_queue 預設最大的先出來（第 13 篇）。Dijkstra 要最小的，必須用 greater。寫錯時程式能跑，但答案是錯的。

無向圖的邊只加一次

無向圖的邊要兩個方向都放進鄰接表（addEdge 做了兩次 push_back）。只加一次，有些點會「走不回來」。

動手寫（兩題）

第 1 題：還原最短路徑

給 prev，回傳從起點到 target 的路徑。輸出應該是 0 2 3 4。

main.cpp
#include <iostream>
#include <vector>

// prev[v] 是「走到 v 之前的那個點」,起點的 prev 是 -1。
// 請回傳從起點到 target 的路徑(由起點到 target 的順序)。
std::vector<int> buildPath(const std::vector<int>& prev, int target) {
    (void)prev;
    (void)target;
    return {};
}

int main() {
    std::vector<int> prev = {-1, 0, 0, 2, 3};   // 路:0 -> 2 -> 3 -> 4
    for (int v : buildPath(prev, 4)) {
        std::cout << v << " ";
    }
    std::cout << "\n";   // 預期輸出 0 2 3 4
}
參考答案

從 target 沿著 prev 一路往回找，直到 -1（起點的 prev），這樣得到的是反過來的路徑，最後 reverse。

完整答案
#include <algorithm>
#include <iostream>
#include <vector>

std::vector<int> buildPath(const std::vector<int>& prev, int target) {
    std::vector<int> path;
    for (int v = target; v != -1; v = prev[v]) {
        path.push_back(v);
    }
    std::reverse(path.begin(), path.end());
    return path;
}

int main() {
    std::vector<int> prev = {-1, 0, 0, 2, 3};
    for (int v : buildPath(prev, 4)) {
        std::cout << v << " ";
    }
    std::cout << "\n";
}
執行結果
0 2 3 4

第 2 題：寫出「鬆弛」

實作 relax。輸出應該是 1 7 0 9 0 9。注意最後一次 7 + 2 = 9 和原本一樣長，不算更短，不更新。

main.cpp
#include <iostream>
#include <vector>

const int INF = 1000000000;

// 鬆弛(relax):如果「走到 u 的距離 du + 這條邊的權重 w」比目前記的 dist[v] 更短,
// 就更新 dist[v] 並回傳 true;否則什麼都不改、回傳 false。
bool relax(std::vector<int>& dist, int du, int v, int w) {
    (void)dist;
    (void)du;
    (void)v;
    (void)w;
    return false;
}

int main() {
    std::vector<int> dist = {0, INF, 9};
    std::cout << relax(dist, 0, 1, 7) << " " << dist[1] << " " << relax(dist, 7, 2, 5) << " " << dist[2] << " " << relax(dist, 7, 2, 2) << " " << dist[2] << "\n";   // 預期輸出 1 7 0 9 0 9(最後一次 7+2 = 9,和原本一樣長,不算更短)
}
參考答案

只有「嚴格小於」才更新。用 <= 的話，相等時也會更新並重複放進 pq，答案沒錯但做了白工。

完整答案
#include <iostream>
#include <vector>

const int INF = 1000000000;

bool relax(std::vector<int>& dist, int du, int v, int w) {
    if (du + w < dist[v]) {
        dist[v] = du + w;
        return true;
    }
    return false;
}

int main() {
    std::vector<int> dist = {0, INF, 9};
    std::cout << relax(dist, 0, 1, 7) << " " << dist[1] << " " << relax(dist, 7, 2, 5) << " " << dist[2] << " " << relax(dist, 7, 2, 2) << " " << dist[2] << "\n";
}
執行結果
1 7 0 9 0 9
