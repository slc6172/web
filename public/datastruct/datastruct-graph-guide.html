點加連線：怎麼存一張圖、怎麼走遍它

這一篇看圖怎麼存成鄰接矩陣與鄰接表，再用迷宮動畫比較 BFS(queue)與 DFS(stack)：一個一圈圈往外擴，一個一路往前鑽。

TL;DR 圖 = 點 + 邊。存法有鄰接矩陣(O(V²))與鄰接表（O(V+E)，邊少時用）。BFS 用 queue，一圈圈往外擴，無權重時保證最短路；DFS 用 stack，一路往前鑽。走圖一定要記錄已拜訪的點，時間 O(V+E)。

直覺：圖就是「點」加上「連線」

地圖、社群網路、迷宮，都是圖

城市是點，道路是邊；朋友是點，「互相認識」是邊；迷宮裡每個空格是點，相鄰的空格之間有邊。第 11 篇的樹其實是一種特別的圖（沒有繞圈的路、全部連在一起）。圖比樹自由：一個點可以連任意多個點，還可以繞回來形成環。

圖要回答的常見問題：從 A 走得到 B 嗎？最少要走幾步？這一篇學兩件事：圖怎麼存進程式，以及兩種走遍整張圖的方法 BFS 與 DFS。

幾個名詞

名詞
白話說明
點（vertex / node）與邊（edge）
圖由點和連接兩點的邊組成。本篇的點用 0, 1, 2… 編號。
無向 / 有向
無向圖：邊沒有方向，A-B 就是 B-A（好友關係）。有向圖：邊有方向，A→B 不代表 B→A（單行道、追蹤）。本篇用無向圖。
相鄰、度數
有邊直接連著的兩個點互為鄰居。一個點的鄰居數叫度數(degree)。
路徑、連通
沿著邊從 A 走到 B 的一串點叫路徑。任兩點之間都有路徑，就說這張圖連通。
環
沿著邊走了一圈又回到出發點。有環的圖，走訪時一定要記錄「來過了」，否則會一直繞圈。

圖怎麼存：鄰接矩陣與鄰接表

輸入邊的清單（例如 0-1 0-2 1-3，點編號 0~6），按「執行」，看同一張圖怎麼同時存成兩種樣子。每條邊會拆成四個小步驟，逐行看程式碼改了什麼。

  1. 直接按「執行」，看 0-1 這條邊為什麼要記兩次（矩陣對稱、兩個 list 各加一筆）。
  2. 按「星狀圖」：點 0 連很多點，矩陣大部分是 0，鄰接表很短。
  3. 按「四點全連」：每兩點都有邊，矩陣填滿，兩種存法用的空間差不多。

main.cpp
#include <iostream>
#include <utility>
#include <vector>

using Table = std::vector<std::vector<int>>;

void addEdge(Table& matrix, Table& adj, int a, int b) {
    matrix[a][b] = 1;
    matrix[b][a] = 1;
    adj[a].push_back(b);
    adj[b].push_back(a);
}

int main() {
    const int n = 5;
    std::vector<std::pair<int, int>> edges = {{0, 1}, {0, 2}, {1, 3}, {2, 3}, {3, 4}};
    Table matrix(n, std::vector<int>(n, 0));
    Table adj(n);
    for (const auto& e : edges) {
        addEdge(matrix, adj, e.first, e.second);
    }
    std::cout << "鄰接矩陣:\n";
    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < n; ++j) {
            std::cout << matrix[i][j] << " ";
        }
        std::cout << "\n";
    }
    std::cout << "鄰接表:\n";
    for (int i = 0; i < n; ++i) {
        std::cout << i << ":";
        for (int v : adj[i]) {
            std::cout << " " << v;
        }
        std::cout << "\n";
    }
    std::cout << "點 3 的度數: " << adj[3].size() << "\n";
}

走遍整張圖：BFS 與 DFS 走迷宮

迷宮是最好懂的圖：每個空格是點，上下左右的空格互為鄰居。BFS（廣度優先）用 queue，一圈一圈往外擴；DFS（深度優先）用 stack，一直往前鑽，走不通才退回來。同一個迷宮，兩種走法的樣子完全不同。

  1. 選「有牆的迷宮」，分別按「BFS 跑一次」與「DFS 跑一次」，比較最後的步數。
  2. 選「空地」跑 DFS：明明直走就到，它卻繞了一大圈，為什麼？（提示：看每一步新放進 stack 的格子，最後放的先出來。）
  3. 選「沒有出口」跑 BFS:queue 空了就知道走不到。
  4. 按「隨機迷宮」多試幾次，BFS 的步數是不是永遠 ≤ DFS?

本篇的 DFS 為什麼不用遞迴？DFS 也能寫成遞迴（呼叫堆疊就是那個 stack，第 7 篇）。這裡明確用 std::stack，才看得到「放進去的格子」，也避免格子很多時遞迴太深 stack overflow。

完整程式：bfs 與 dfs

兩個函式的骨架幾乎一樣：取出一個格子、看四個方向、把能走又沒到過的放進去。差別只在 queue 換成 stack。方向順序是上、下、左、右（DR / DC 兩個陣列）。

main.cpp
#include <iostream>
#include <queue>
#include <stack>
#include <string>
#include <vector>

struct Point {
    int r;
    int c;
};

struct Step {
    Point p;
    int steps;
};

const int DR[4] = {-1, 1, 0, 0};
const int DC[4] = {0, 0, -1, 1};

bool isOpen(const std::vector<std::string>& g, int r, int c) {
    return r >= 0 && r < static_cast<int>(g.size()) && c >= 0 && c < static_cast<int>(g[0].size()) && g[r][c] != '#';
}

int bfs(const std::vector<std::string>& g, Point s, Point t) {
    std::vector<std::vector<int>> dist(g.size(), std::vector<int>(g[0].size(), -1));
    std::queue<Point> q;
    dist[s.r][s.c] = 0;
    q.push(s);
    while (!q.empty()) {
        Point cur = q.front();
        q.pop();
        if (cur.r == t.r && cur.c == t.c) {
            return dist[cur.r][cur.c];
        }
        for (int d = 0; d < 4; ++d) {
            int nr = cur.r + DR[d];
            int nc = cur.c + DC[d];
            if (isOpen(g, nr, nc) && dist[nr][nc] == -1) {
                dist[nr][nc] = dist[cur.r][cur.c] + 1;
                q.push({nr, nc});
            }
        }
    }
    return -1;
}

int dfs(const std::vector<std::string>& g, Point s, Point t) {
    std::vector<std::vector<bool>> seen(g.size(), std::vector<bool>(g[0].size(), false));
    std::stack<Step> st;
    st.push({s, 0});
    while (!st.empty()) {
        Step cur = st.top();
        st.pop();
        if (seen[cur.p.r][cur.p.c]) {
            continue;
        }
        seen[cur.p.r][cur.p.c] = true;
        if (cur.p.r == t.r && cur.p.c == t.c) {
            return cur.steps;
        }
        for (int d = 0; d < 4; ++d) {
            int nr = cur.p.r + DR[d];
            int nc = cur.p.c + DC[d];
            if (isOpen(g, nr, nc) && !seen[nr][nc]) {
                st.push({{nr, nc}, cur.steps + 1});
            }
        }
    }
    return -1;
}

int main() {
    std::vector<std::vector<std::string>> mazes = {
        {"S......", ".......", ".......", ".......", "......G"},
        {"S....##", ".##....", ".#.....", "#..##..", "......G"},
        {"S.#....", ".#.###.", ".#...#.", ".###.#.", "....#.G"},
    };
    for (const auto& g : mazes) {
        Point s{0, 0};
        Point t{static_cast<int>(g.size()) - 1, static_cast<int>(g[0].size()) - 1};
        std::cout << "BFS 最短步數 " << bfs(g, s, t) << ",DFS 走到的步數 " << dfs(g, s, t) << "\n";
    }
}

V 是點數，E 是邊數。BFS 和 DFS 每個點最多放進去處理一次、每條邊最多看兩次。

一句話：走遍整張圖，每個點、每條邊只碰常數次，所以和圖的大小成正比。

初學者最常卡住的四個地方

沒有記錄「走過了」

圖有環時，不記錄已拜訪的點會一直繞圈，程式永遠不會結束（或 queue / stack 爆掉）。BFS 用 dist（-1 代表沒到過）、DFS 用 seen，都是這個用途。

BFS 要在「放進 queue 時」就標記

本篇 BFS 在放進 queue 的當下就設好 dist。如果等到取出才標記，同一個格子可能被好幾個鄰居重複放進去，浪費時間，距離也容易寫錯。

DFS 的順序和直覺相反

stack 是後進先出，所以最後放進去的方向最先走。方向陣列寫成上、下、左、右，DFS 就會先往右走。換個方向順序，走到的路就不一樣，這很正常。

邊界檢查在讀格子之後

要先確定 0 <= r < 列數 且 0 <= c < 行數，才能讀 g[r][c]。isOpen 把檢查包在同一個函式裡，而且 && 會短路，前面不成立就不會去讀。

動手寫（兩題）

第 1 題：度數最大的點

鄰接表裡，哪個點的鄰居最多？有多個時回傳編號最小的。輸出應該是 1。

main.cpp
#include <iostream>
#include <vector>

// 鄰接表 adj 裡,「度數最大」的點是哪一個?(度數 = 相鄰的點數;有多個時回傳編號最小的)
int maxDegreeNode(const std::vector<std::vector<int>>& adj) {
    (void)adj;
    return -1;
}

int main() {
    std::vector<std::vector<int>> adj = {{1, 2}, {0, 2, 3}, {0, 1, 3}, {1, 2, 4}, {3}};
    std::cout << maxDegreeNode(adj) << "\n";   // 預期輸出 1
}
參考答案

鄰接表裡，點 i 的度數就是 adj[i].size()。只在「嚴格大於」目前最佳時更新，就會留下編號最小的。O(V)。

完整答案
#include <iostream>
#include <vector>

int maxDegreeNode(const std::vector<std::vector<int>>& adj) {
    int best = -1;
    for (int i = 0; i < static_cast<int>(adj.size()); ++i) {
        if (best == -1 || adj[i].size() > adj[best].size()) {
            best = i;
        }
    }
    return best;
}

int main() {
    std::vector<std::vector<int>> adj = {{1, 2}, {0, 2, 3}, {0, 1, 3}, {1, 2, 4}, {3}};
    std::cout << maxDegreeNode(adj) << "\n";
}
執行結果
1

第 2 題：兩點連不連通

用 BFS 判斷點 a 到點 b 有沒有路。輸出應該是 101。

main.cpp
#include <iostream>
#include <queue>
#include <vector>

// 用 BFS 判斷點 a 和點 b 之間有沒有路(連不連通)。adj 是鄰接表。
bool connected(const std::vector<std::vector<int>>& adj, int a, int b) {
    (void)adj;
    (void)a;
    (void)b;
    return false;
}

int main() {
    std::vector<std::vector<int>> adj = {{1}, {0, 2}, {1}, {4}, {3}};   // 0-1-2 一組,3-4 一組
    std::cout << connected(adj, 0, 2) << connected(adj, 0, 4) << connected(adj, 3, 4) << "\n";   // 預期輸出 101
}
參考答案

和迷宮的 bfs 同一個骨架：seen 記錄來過的點、queue 放待處理的點，取出的點等於 b 就回傳 true;queue 空了還沒遇到就是 false。O(V + E)。

完整答案
#include <iostream>
#include <queue>
#include <vector>

bool connected(const std::vector<std::vector<int>>& adj, int a, int b) {
    std::vector<bool> seen(adj.size(), false);
    std::queue<int> q;
    seen[a] = true;
    q.push(a);
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        if (u == b) {
            return true;
        }
        for (int v : adj[u]) {
            if (!seen[v]) {
                seen[v] = true;
                q.push(v);
            }
        }
    }
    return false;
}

int main() {
    std::vector<std::vector<int>> adj = {{1}, {0, 2}, {1}, {4}, {3}};
    std::cout << connected(adj, 0, 2) << connected(adj, 0, 4) << connected(adj, 3, 4) << "\n";
}
執行結果
101
