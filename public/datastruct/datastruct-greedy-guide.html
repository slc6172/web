不回頭的貪婪、會退回的回溯，以及接下來怎麼練

貪婪每一步選當下最好的，快但不一定對；回溯試了走不通就退回再試。這一篇用找零與 N 皇后動畫看兩者，最後附上可篩選的 STL 速查表與刷題路線。

TL;DR 貪婪：每一步選當下最好的、不回頭，快，但要有證明或找不到反例才能用（找零 {4,3,1} 會失敗）。回溯：試、走不通就撤銷選擇退回、再試別的，要剪枝。學完全系列後，用速查表選容器，照路線刷題。

貪婪：每一步都拿「當下最好」的，不回頭

找零：先拿最大的硬幣

找 63 元，店員會先拿 25 元、再 25 元、再 10 元……每一步都拿「拿得下的最大面額」。這就是貪婪演算法(greedy)：每一步都選當下看起來最好的，選了就不反悔。程式短、速度快，但不保證答案最好。

下面的動畫讓你試試同一個貪婪程式在不同硬幣組合下的結果：有的組合剛好對，有的會輸給第 16 篇的 DP。

  1. 先跑「美國硬幣」湊 63：貪婪用 6 枚，最少也是 6 枚，對了。
  2. 改選「4, 3, 1」湊 6：貪婪拿 4+1+1 = 3 枚，但 3+3 只要 2 枚。
  3. 選「5, 2」湊 6：貪婪拿了 5 之後剩 1 湊不下，卡住；其實 2+2+2 就可以。
  4. 自己換金額多試幾次，看什麼時候貪婪會失敗。
main.cpp
#include <algorithm>
#include <iostream>
#include <vector>

std::vector<int> greedyChange(const std::vector<int>& coins, int amount) {
    std::vector<int> used;
    for (int c : coins) {
        while (amount >= c) {
            used.push_back(c);
            amount -= c;
        }
    }
    if (amount != 0) {
        used.clear();
    }
    return used;
}

int bestCount(const std::vector<int>& coins, int amount) {
    const int INF = 1000000000;
    std::vector<int> dp(amount + 1, INF);
    dp[0] = 0;
    for (int a = 1; a <= amount; ++a) {
        for (int c : coins) {
            if (a >= c && dp[a - c] != INF) {
                dp[a] = std::min(dp[a], dp[a - c] + 1);
            }
        }
    }
    return dp[amount] == INF ? -1 : dp[amount];
}

void show(const std::vector<int>& coins, int amount) {
    std::vector<int> used = greedyChange(coins, amount);
    std::cout << "金額 " << amount << ",貪婪用 " << used.size() << " 枚:";
    for (int c : used) {
        std::cout << " " << c;
    }
    std::cout << ";最少其實要 " << bestCount(coins, amount) << " 枚\n";
}

int main() {
    show({25, 10, 5, 1}, 63);
    show({4, 3, 1}, 6);
    show({12, 10, 5, 1}, 15);
}
執行結果（貪婪的結果與 DP 算出的最少枚數對照）
金額 63,貪婪用 6 枚: 25 25 10 1 1 1;最少其實要 6 枚
金額 6,貪婪用 3 枚: 4 1 1;最少其實要 2 枚
金額 15,貪婪用 4 枚: 12 1 1 1;最少其實要 2 枚

回溯：試、錯了就退回、再試別的

N 皇后：在 N×N 的棋盤放 N 個皇后，互相吃不到

皇后會吃同欄、同列、同斜線的棋子。做法：一列放一個，從第 1 列開始，一欄一欄試。能放就放下、去下一列；下一列每一欄都不行，就退回來，把這一列的皇后拿起來換下一欄。這種「走不通就退回上一步、換另一個選擇」的方法叫回溯(backtracking)。

回溯其實就是第 7 篇的遞迴加上「撤銷選擇」。和第 14 篇的 DFS 是同一個「一路鑽、走不通退回」的想法。

  1. 先看 N=4、「只看第一組解」，數數看嘗試了幾次、退回了幾次。
  2. 切到「全部解」：N=4 只有 2 組解。
  3. 改 N=6、「全部解」，拉到最後看總共嘗試多少次、有幾組解（答案是 4 組）。
  4. 留意「×」的格子：和哪個皇后衝突（同欄或同斜線）。
main.cpp
#include <cstdlib>
#include <iostream>
#include <string>
#include <vector>

bool safe(const std::vector<int>& cols, int row, int c) {
    for (int r = 0; r < row; ++r) {
        if (cols[r] == c || std::abs(cols[r] - c) == row - r) {
            return false;
        }
    }
    return true;
}

void solve(int n, int row, std::vector<int>& cols, std::vector<std::vector<int>>& sols) {
    if (row == n) {
        sols.push_back(cols);
        return;
    }
    for (int c = 0; c < n; ++c) {
        if (safe(cols, row, c)) {
            cols[row] = c;
            solve(n, row + 1, cols, sols);
        }
    }
}

int main() {
    for (int n = 4; n <= 8; ++n) {
        std::vector<int> cols(n, -1);
        std::vector<std::vector<int>> sols;
        solve(n, 0, cols, sols);
        std::cout << n << " 皇后:" << sols.size() << " 組解\n";
        if (n == 4) {
            for (int c : sols[0]) {
                std::cout << std::string(c, '.') << "Q" << std::string(n - c - 1, '.') << "\n";
            }
        }
    }
}

為什麼不是試完所有擺法？8 個皇后隨便放有上千萬種擺法；一列放一個、而且一發現衝突就不往下走（這叫剪枝），大部分擺法根本不用試。

初學者最常卡住的四個地方

貪婪沒想過反例就直接用

貪婪的程式短又快，很容易「看起來對」。先用小例子找反例（像 {4,3,1} 湊 6）；找得到反例就換 DP。找不到也要能說出「為什麼這一步選最好不會害到後面」。

回溯忘了撤銷選擇

遞迴回來之後，要把剛才做的選擇還原：放了皇后要拿起來、push_back 的要 pop_back、設成 true 的 visited 要設回 false。忘了還原，下一個選擇會在「髒掉」的狀態上試，答案錯得很奇怪。

沒有剪枝，速度爆炸

回溯本質是「試所有可能」，不剪枝就是指數時間。好的回溯在確定走不通的那一刻就退回（像 safe 一發現衝突就不放），而不是放滿再檢查。

容器選錯

常見的：在 vector 中間頻繁插入刪除（O(n)）、需要排序走訪卻用 unordered_map、只要判斷有沒有卻用 vector 一個一個找。先看上面「我需要」那張表。

第 1 題：活動安排（貪婪）

最多能安排幾個時間不重疊的活動？輸出應該是 4。

main.cpp
#include <algorithm>
#include <iostream>
#include <utility>
#include <vector>

// 一間會議室,每個活動是 (開始, 結束)。最多能安排幾個「時間不重疊」的活動?
// (一個活動的結束時間 == 下一個的開始時間,不算重疊。)
// 提示:貪婪 —— 依「結束時間」由小到大排序,能接上的就選(開始時間 >= 上一個選的結束時間)。
int maxActivities(std::vector<std::pair<int, int>> acts) {
    (void)acts;
    return 0;
}

int main() {
    std::cout << maxActivities({{1, 3}, {2, 4}, {3, 5}, {0, 6}, {5, 7}, {8, 9}, {5, 9}}) << "\n";   // 預期輸出 4
}
參考答案

依結束時間排序，從最早結束的開始選，能接上（開始時間 ≥ 上一個選的結束時間）就選。早點結束，留給後面的時間最多。時間 O(n log n)（排序）。

完整答案
#include <algorithm>
#include <iostream>
#include <utility>
#include <vector>

int maxActivities(std::vector<std::pair<int, int>> acts) {
    std::sort(acts.begin(), acts.end(), [](const std::pair<int, int>& a, const std::pair<int, int>& b) {
        return a.second < b.second;
    });
    int count = 0;
    int lastEnd = -1;
    for (const auto& a : acts) {
        if (a.first >= lastEnd) {
            ++count;
            lastEnd = a.second;
        }
    }
    return count;
}

int main() {
    std::cout << maxActivities({{1, 3}, {2, 4}, {3, 5}, {0, 6}, {5, 7}, {8, 9}, {5, 9}}) << "\n";
}
執行結果
4

第 2 題：有幾種挑法湊出總和（回溯）

輸出應該是 2 3 0。{2,3,5,7} 湊 10 有 3+7、2+3+5 兩種。

main.cpp
#include <iostream>
#include <vector>

// 從 nums 裡挑出一些數字(每個位置最多挑一次,可以一個都不挑),
// 總和剛好等於 target 的挑法有幾種?(位置不同就算不同挑法。)
// 提示:回溯 —— 對每個位置,先「挑」遞迴下去,再「不挑」遞迴下去。
int countSubsets(const std::vector<int>& nums, int target) {
    (void)nums;
    (void)target;
    return -1;
}

int main() {
    std::cout << countSubsets({2, 3, 5, 7}, 10) << " " << countSubsets({1, 1, 1}, 2) << " " << countSubsets({4}, 3) << "\n";   // 預期輸出 2 3 0
}
參考答案

每個位置兩種選擇：挑（剩下的目標減掉它）與不挑，都遞迴下去。走到最後一個位置時，剩下目標剛好是 0 才算一種。時間 O(2ⁿ)。因為用函式參數傳 remain，不需要手動撤銷選擇。

完整答案
#include <iostream>
#include <vector>

int go(const std::vector<int>& nums, int idx, int remain) {
    if (idx == static_cast<int>(nums.size())) {
        return remain == 0 ? 1 : 0;
    }
    int take = go(nums, idx + 1, remain - nums[idx]);
    int skip = go(nums, idx + 1, remain);
    return take + skip;
}

int countSubsets(const std::vector<int>& nums, int target) {
    return go(nums, 0, target);
}

int main() {
    std::cout << countSubsets({2, 3, 5, 7}, 10) << " " << countSubsets({1, 1, 1}, 2) << " " << countSubsets({4}, 3) << "\n";
}
執行結果
2 3 0
