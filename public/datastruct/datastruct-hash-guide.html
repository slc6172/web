雜湊表把 key 算成桶子編號，平均一步就找到

雜湊函數把 key 變成桶子編號，查詢直接走到那個桶子。這一篇用桶子動畫看雜湊值怎麼算、碰撞怎麼處理，再認識 std::unordered_map。

TL;DR 雜湊函數把 key 算成桶子編號；不同 key 算出同一個桶子叫碰撞，用 chaining 接成一條鏈。插入、查詢、刪除平均 O(1)，最壞 O(n)。實務上用 std::unordered_map 與 unordered_set。

雜湊表：用「號碼牌」一步找到東西

想像衣帽間

你把外套交給櫃台，拿到一張號碼牌 37。要取回時，不用把整間衣帽間的外套一件件翻過去，直接走到 37 號掛勾就好。

雜湊表就是這樣：用一個雜湊函數把 key（例如字串 "cat"）變成一個桶子編號，資料就放在那個桶子裡。找的時候再算一次編號，直接走到那個桶子，不必從頭找。

五個名詞

名詞
白話說明
key / value
key 是用來找的名字（"cat"），value 是附帶的資料（例如出現次數）。本篇動畫只放 key。
雜湊函數
把 key 算成桶子編號的規則。同一個 key 每次算出來都要一樣。
桶子（bucket）
雜湊表裡的格子，編號 0 到 m − 1。
碰撞（collision）
兩個不同的 key 算出同一個桶子編號。一定會發生（key 比桶子多）。
chaining
解決碰撞的一種方式：每個桶子放一條「鏈」，碰撞的 key 都接在同一個桶子裡。
負載因子
元素個數 ÷ 桶子數。越大，每條鏈越長，越慢。

動手玩：雜湊、碰撞與 chaining

這個迷你雜湊表有 7 個桶子，雜湊函數是「所有字元的編號加起來，再 % 7」（簡單，但不好，等一下就知道為什麼）。黑色那一行是雜湊值的計算過程。

  1. 按「放入 5 個範例」，觀察 cat、act、bird 擠在同一個桶子。
  2. 查詢（contains）act：要比較幾次？再查詢一個不存在的，例如 tac。
  3. 再自己放進 tac（cat 的字母換個順序），看它放哪裡。
  4. 刪除（erase）cat，看鏈怎麼變。

猜猜看：這一步會發生什麼？

雜湊函數是「字元編號加總 % 7」。cat 和 act 的字母一樣、只是順序不同，它們會放進？

選一個做法，看看對不對。

完整程式：自己做一個雜湊表

using Table = ... 是替一個很長的型別取別名：它就是「桶子的陣列，每個桶子是一個字串的 vector」。main 會放進動畫裡那五個 key。

main.cpp
#include <iostream>
#include <string>
#include <vector>

using Table = std::vector<std::vector<std::string>>;

int hashOf(const std::string& key, int m) {
    int sum = 0;
    for (char c : key) {
        sum += c;
    }
    return sum % m;
}

bool contains(const Table& t, const std::string& key) {
    int idx = hashOf(key, static_cast<int>(t.size()));
    for (const std::string& k : t[idx]) {
        if (k == key) {
            return true;
        }
    }
    return false;
}

void insert(Table& t, const std::string& key) {
    if (contains(t, key)) {
        return;
    }
    int idx = hashOf(key, static_cast<int>(t.size()));
    t[idx].push_back(key);
}

void erase(Table& t, const std::string& key) {
    int idx = hashOf(key, static_cast<int>(t.size()));
    std::vector<std::string>& bucket = t[idx];
    for (int i = 0; i < static_cast<int>(bucket.size()); ++i) {
        if (bucket[i] == key) {
            bucket.erase(bucket.begin() + i);
            return;
        }
    }
}

void print(const Table& t) {
    for (int i = 0; i < static_cast<int>(t.size()); ++i) {
        std::cout << i << ":";
        for (const std::string& k : t[i]) {
            std::cout << " " << k;
        }
        std::cout << "\n";
    }
}

int main() {
    Table t(7);                              // 7 個桶子
    for (const char* w : {"cat", "act", "dog", "god", "bird"}) {
        insert(t, w);
    }
    print(t);
    std::cout << contains(t, "act") << contains(t, "tac") << "\n";
    erase(t, "cat");
    std::cout << contains(t, "cat") << contains(t, "act") << "\n";
}

實務上：std::unordered_map 與 unordered_set

標準函式庫已經提供雜湊表：std::unordered_map<key, value>（有 value）與 std::unordered_set<key>（只有 key）。它會自動擴大桶子，讓負載因子不會太高。

main.cpp
#include <iostream>
#include <string>
#include <unordered_map>
#include <vector>

int main() {
    std::vector<std::string> words = {"cat", "dog", "cat", "bird", "dog", "cat"};
    std::unordered_map<std::string, int> count;
    for (const std::string& w : words) {
        ++count[w];                          // 沒有這個 key 時,會自動建立並從 0 開始
    }
    std::cout << "cat = " << count["cat"] << "\n";
    std::cout << "dog = " << count["dog"] << "\n";
    auto it = count.find("fish");            // 查詢用 find,不會新增
    std::cout << "fish found? " << (it != count.end()) << "\n";
    std::cout << "size = " << count.size() << "\n";
    count.erase("dog");
    std::cout << "has dog? " << count.count("dog") << "\n";
}
執行結果
cat = 3
dog = 2
fish found? 0
size = 3
has dog? 0
寫法
意思
count[w]
取 w 的 value；如果沒有就新增一個（value 為 0）。
count.find(w)
找 w，找不到回傳 count.end()。不會新增。
count.count(w)
w 出現幾次（對 map 來說是 0 或 1）。常用來判斷有沒有。
count.erase(w)
刪除 w。

平均 O(1) 的條件：雜湊函數要把 key 分散得均勻，而且負載因子別太大。這也是為什麼std::unordered_map 會在太擠時自動擴大桶子並重新放（rehash）。

初學者最常卡住的三個地方

用 m[key] 查詢，結果不小心新增了 key

operator[] 找不到時會「幫你建立」。只想看有沒有時，用 find 或 count：

main.cpp
#include <iostream>
#include <string>
#include <unordered_map>

int main() {
    std::unordered_map<std::string, int> m;
    std::cout << "size before = " << m.size() << "\n";
    if (m["x"] == 0) {                       // 只是想「看看有沒有」,卻不小心新增了 x
        std::cout << "x is zero\n";
    }
    std::cout << "size after = " << m.size() << "\n";
    std::cout << "count(y) = " << m.count("y") << ", size = " << m.size() << "\n";   // count 不會新增
}
執行結果
size before = 0
x is zero
size after = 1
count(y) = 0, size = 1
雜湊函數太差：全部擠進同一個桶子

我們的「字元加總」就很差：cat、act、tac 這些字母相同的字一定碰撞。好的雜湊函數會讓順序不同、內容稍有差異的 key 都分散開。標準函式庫對 std::string、int 等型別已經提供了好的雜湊函數。

依賴 unordered_map 的走訪順序

雜湊表沒有順序。用 range-for 走訪時，順序取決於內部實作，不同編譯器、甚至擴容之後都可能不同。需要有序的結果時，用 std::map，或先把結果排序。

動手寫（兩題）

第 1 題：把第 2 篇的 O(n²) 改成 O(n)

第 2 篇的 hasPairSum 用雙層迴圈。這次用 unordered_set 記住看過的數字。輸出應該是 1 0。

main.cpp
#include <iostream>
#include <unordered_set>
#include <vector>

// 回傳 v 裡有沒有「兩個不同位置的元素相加等於 target」。
// 第 2 篇的雙層迴圈寫法是 O(n²);用 unordered_set 記住「看過的數字」,可以做到 O(n)。
// 提示:對每個 x,看 target - x 是不是已經在 seen 裡。
bool hasPairSum(const std::vector<int>& v, int target) {
    std::unordered_set<int> seen;
    (void)v;
    (void)target;
    return false;
}

int main() {
    std::vector<int> v = {3, 8, 1, 9};
    std::cout << hasPairSum(v, 10) << " " << hasPairSum(v, 100) << "\n";   // 預期輸出 1 0
}
參考答案

對每個 x，看 target - x 以前有沒有出現過；有就找到了，沒有就把 x 記起來。每個元素只處理一次，查詢是平均 O(1)，所以整體 O(n)。

完整答案
#include <iostream>
#include <unordered_set>
#include <vector>

bool hasPairSum(const std::vector<int>& v, int target) {
    std::unordered_set<int> seen;
    for (int x : v) {
        if (seen.count(target - x) > 0) {
            return true;
        }
        seen.insert(x);
    }
    return false;
}

int main() {
    std::vector<int> v = {3, 8, 1, 9};
    std::cout << hasPairSum(v, 10) << " " << hasPairSum(v, 100) << "\n";
}
執行結果
1 0

第 2 題：找出出現次數最多的單字

完成 mostCommon。輸出應該是 cat。

main.cpp
#include <iostream>
#include <unordered_map>
#include <vector>
#include <string>

// 回傳出現次數最多的單字(假設只有一個最多的)。
// 提示:先用 unordered_map<std::string, int> 數每個單字出現幾次,再找最大的。
std::string mostCommon(const std::vector<std::string>& words) {
    (void)words;
    return "";
}

int main() {
    std::vector<std::string> w = {"cat", "dog", "cat", "bird", "dog", "cat"};
    std::cout << mostCommon(w) << "\n";      // 預期輸出 cat
}
參考答案

先用 unordered_map 數每個單字出現的次數（++count[w]），再走訪找最大的。注意：走訪順序沒有保證，所以題目假設最多的只有一個。

完整答案
#include <iostream>
#include <string>
#include <unordered_map>
#include <vector>

std::string mostCommon(const std::vector<std::string>& words) {
    std::unordered_map<std::string, int> count;
    for (const std::string& w : words) {
        ++count[w];
    }
    std::string best;
    int bestCount = 0;
    for (const auto& entry : count) {
        if (entry.second > bestCount) {
            bestCount = entry.second;
            best = entry.first;
        }
    }
    return best;
}

int main() {
    std::vector<std::string> w = {"cat", "dog", "cat", "bird", "dog", "cat"};
    std::cout << mostCommon(w) << "\n";
}
執行結果
cat
