C++ 演算法 · 第 13 篇 · 堆積與優先佇列

每次都先拿最大的：用陣列存的一棵樹

堆積讓你「馬上拿到最大（或最小）的」，push 與 pop 都是 O(log n)。這一篇用陣列與樹並排的動畫看上浮與下沉，再用 std::priority_queue。

TL;DR 堆積是完全二元樹，用陣列存：位置 i 的父在 (i-1)/2、左子 2i+1、右子 2i+2。最大堆積的根最大；push 放最後再上浮，pop 把最後一個搬到根再下沉，都是 O(log n)。std::priority_queue 預設是最大堆積。

直覺：每次都要「馬上拿到最大（或最小）的那個」

醫院急診：不是先來先看，是最嚴重的先看

第 5 篇的 queue 是先進先出。但有些場合要的是「優先順序最高的先出來」：急診、作業系統排程、遊戲裡最近的敵人、下一篇的最短路徑。這種資料結構叫優先佇列(priority queue)，最常見的實作是堆積(heap)。

用排序好的陣列也能做到，但插入要搬動元素（O(n)）。堆積只保證最大的在最上面，不要求其他位置排好，換來 push 與 pop 都只要 O(log n)。

兩個重點：規則，以及用陣列存

重點
說明
最大堆積的規則
每個節點的值都不小於它的左右子節點。所以最大的值一定在根。（最小堆積反過來。）
形狀：完全二元樹
一層一層填滿，最後一層從左填到右，中間不留洞。
用陣列存，不用指標
從位置 0 開始，一層一層排進陣列。位置 i 的父節點在 (i-1)/2，左子在 2*i+1，右子在 2*i+2。例：位置 1 的父是 0，子是 3 與 4。
上浮 / 下沉
push 把新值放最後再上浮(sift up);pop 把最後一個搬到根再下沉(sift down)。
為什麼不是排好序？堆積只比較「父與子」，兄弟之間（例如左子和右子）沒有大小關係。這是它比排序陣列便宜的原因。

完整程式：上浮與下沉

整個堆積就是一個 vector<int>。兩個核心動作都是「和父（或子）比較，不對就交換，換到對為止」，每次最多走過樹的高度那麼多層。

main.cpp
#include <iostream>
#include <utility>
#include <vector>

void siftUp(std::vector<int>& h, int i) {
    while (i > 0) {
        int parent = (i - 1) / 2;
        if (h[parent] >= h[i]) {
            break;
        }
        std::swap(h[parent], h[i]);
        i = parent;
    }
}

void push(std::vector<int>& h, int val) {
    h.push_back(val);
    siftUp(h, static_cast<int>(h.size()) - 1);
}

void siftDown(std::vector<int>& h, int i) {
    int n = static_cast<int>(h.size());
    while (true) {
        int largest = i;
        int left = 2 * i + 1;
        int right = 2 * i + 2;
        if (left < n && h[left] > h[largest]) {
            largest = left;
        }
        if (right < n && h[right] > h[largest]) {
            largest = right;
        }
        if (largest == i) {
            break;
        }
        std::swap(h[i], h[largest]);
        i = largest;
    }
}

int pop(std::vector<int>& h) {
    int top = h[0];
    h[0] = h.back();
    h.pop_back();
    if (!h.empty()) {
        siftDown(h, 0);
    }
    return top;
}

void print(const std::vector<int>& h) {
    for (int x : h) {
        std::cout << x << " ";
    }
    std::cout << "\n";
}

int main() {
    std::vector<int> h;
    for (int v : {5, 3, 8, 1, 9, 2}) {
        push(h, v);
        std::cout << "push " << v << ": ";
        print(h);
    }
    std::cout << "pop " << pop(h) << ": ";
    print(h);
    std::cout << "pop " << pop(h) << ": ";
    print(h);
    std::cout << "剩下依序取出: ";
    while (!h.empty()) {
        std::cout << pop(h) << " ";
    }
    std::cout << "\n";
}

pop 為什麼要搬最後一個到根？直接把根拿掉會留下一個洞，而且陣列要整排往前搬（O(n)）。改成把最後一個搬到根、刪掉最後一格，陣列一次就縮短；再讓根往下沉到對的位置。

實務上：std::priority_queue

std::priority_queue 就是把上面的做法包好：用 vector 存，push / pop 為 O(log n)，top 為 O(1)。注意預設是最大堆積。

main.cpp
#include <functional>
#include <iostream>
#include <queue>
#include <vector>

int main() {
    std::priority_queue<int> maxHeap;                  // 預設:最大的在最上面
    for (int v : {5, 3, 8, 1, 9, 2}) {
        maxHeap.push(v);
    }
    std::cout << maxHeap.top() << " size=" << maxHeap.size() << "\n";
    while (!maxHeap.empty()) {
        std::cout << maxHeap.top() << " ";
        maxHeap.pop();
    }
    std::cout << "\n";

    std::priority_queue<int, std::vector<int>, std::greater<int>> minHeap;   // 最小的在最上面
    for (int v : {5, 3, 8, 1, 9, 2}) {
        minHeap.push(v);
    }
    while (!minHeap.empty()) {
        std::cout << minHeap.top() << " ";
        minHeap.pop();
    }
    std::cout << "\n";
}
執行結果
9 size=6
9 8 5 3 2 1 
1 2 3 5 8 9

初學者最常卡住的四個地方

以為 priority_queue 預設是最小堆積

預設 std::less，top() 是最大的。想要最小的，要寫 priority_queue<int, vector<int>, greater<int>>。比較函式的方向和直覺相反，第一次寫幾乎都會搞反。

pop() 會回傳值？

std::priority_queue::pop() 回傳 void：要先 top() 拿值，再 pop() 刪掉。（本篇自己寫的 pop 為了教學直接回傳最大值，STL 不是這樣。）

對空的堆積 top() 或 pop()

空的 priority_queue 呼叫 top() 或 pop() 是未定義行為（可能直接當掉）。先檢查 !pq.empty()。

把堆積的陣列當成排好序的

堆積內部的順序只保證父不小於子。直接印陣列看起來「大概由大到小」，但並沒有排好。要排好序，得一個一個 pop。priority_queue 也不能走訪，只能看 top。

動手寫（兩題）

第 1 題：isMaxHeap

檢查一個 vector 是不是最大堆積（每個節點都不小於它的子節點）。輸出應該是 1011。

main.cpp
#include <iostream>
#include <vector>

// 判斷 h 是不是「最大堆積」:每個節點都 >= 它的左右子節點。
// 提示:位置 i 的左子是 2*i+1,右子是 2*i+2,要先檢查有沒有超出範圍。
bool isMaxHeap(const std::vector<int>& h) {
    (void)h;
    return false;
}

int main() {
    std::cout << isMaxHeap({9, 5, 8, 1, 3, 2}) << isMaxHeap({9, 5, 8, 6, 3, 2}) << isMaxHeap({}) << isMaxHeap({4}) << "\n";   // 預期輸出 1011
}
參考答案

逐一檢查每個位置 i：左子 2*i+1、右子 2*i+2 只有在範圍內才比較。O(n)。

完整答案
#include <iostream>
#include <vector>

bool isMaxHeap(const std::vector<int>& h) {
    int n = static_cast<int>(h.size());
    for (int i = 0; i < n; ++i) {
        int left = 2 * i + 1;
        int right = 2 * i + 2;
        if (left < n && h[left] > h[i]) {
            return false;
        }
        if (right < n && h[right] > h[i]) {
            return false;
        }
    }
    return true;
}

int main() {
    std::cout << isMaxHeap({9, 5, 8, 1, 3, 2}) << isMaxHeap({9, 5, 8, 6, 3, 2}) << isMaxHeap({}) << isMaxHeap({4}) << "\n";
}
執行結果
1011

第 2 題：第 k 大

只用一個「最小堆積」，大小不超過 k，回傳 nums 裡第 k 大的值。輸出應該是 5 4。

main.cpp
#include <functional>
#include <iostream>
#include <queue>
#include <vector>

// 回傳 nums 裡「第 k 大」的值(k 從 1 開始,保證 1 <= k <= nums.size())。
// 提示:用一個「最小堆積」只留下目前最大的 k 個數;堆積超過 k 個就 pop 掉最小的。
int kthLargest(const std::vector<int>& nums, int k) {
    (void)nums;
    (void)k;
    return 0;
}

int main() {
    std::cout << kthLargest({3, 2, 1, 5, 6, 4}, 2) << " " << kthLargest({3, 2, 3, 1, 2, 4, 5, 5, 6}, 4) << "\n";   // 預期輸出 5 4
}
參考答案

堆積只保留目前最大的 k 個數，超過就 pop 掉最小的，最後 top 就是第 k 大。時間 O(n log k)，比整個排序更省（尤其 k 很小時）。

完整答案
#include <functional>
#include <iostream>
#include <queue>
#include <vector>

int kthLargest(const std::vector<int>& nums, int k) {
    std::priority_queue<int, std::vector<int>, std::greater<int>> minHeap;
    for (int x : nums) {
        minHeap.push(x);
        if (static_cast<int>(minHeap.size()) > k) {
            minHeap.pop();
        }
    }
    return minHeap.top();
}

int main() {
    std::cout << kthLargest({3, 2, 1, 5, 6, 4}, 2) << " " << kthLargest({3, 2, 3, 1, 2, 4, 5, 5, 6}, 4) << "\n";
}
執行結果
5 4
