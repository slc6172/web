鏈結串列的插入刪除只改指標，代價是不能直接跳到第 i 個

每個節點存一筆資料和「下一個在哪」。這一篇用節點箭頭圖，逐行看指標怎麼改，再和上一篇的 vector 比較取捨。

TL;DR 節點用 next 串起來，頭插只改 2 個指標，是 O(1)；但沒有索引，讀第 i 個要從 head 走 O(n)。插入口訣：先接後面，再接前面；每個 new 都要有對應的 delete。

鏈結串列是一條「下一站在哪」的接力

用「尋寶遊戲的紙條」來想

每個節點是一張紙條，上面寫著寶藏（資料）和下一張紙條放在哪裡。你手上只有第一張（head），要看第 5 張，就得從第 1 張一路照著「下一站」走過去。

紙條可以散落在記憶體各處，不必緊貼。所以插入、刪除只要改「下一站」的指向，不用搬動任何資料；代價是沒有索引，不能一步跳到第 i 個。這正好和上一篇的 vector 相反。

五個名詞

名詞
白話說明
節點（node）
一張紙條：放一筆資料 val，加上指向下一個節點的 next。
next
指向下一個節點的指標（上一篇的指標）。
head
指向第一個節點的指標。串列只靠它找到整串資料，弄丟它就找不到了。
nullptr
最後一個節點的 next，表示「後面沒有了」。空串列是 head == nullptr。
走訪（traverse）
從 head 開始，沿著 next 一個個往下走，直到遇到 nullptr。
這一篇是「單向」的每個節點只知道下一個。還有「雙向」鏈結串列，節點多存一個指向前一個的指標，std::list 就是雙向的（見下方 STL 一節）。

動手玩：插入與刪除只改指標

下面的圖是一條鏈結串列，每個方框左邊是資料、右邊的圓點是 next 指標。按「執行」後，一步一步看每一行程式怎麼改指標。右上角的數字會告訴你改了幾個指標、走訪了幾個節點。

  1. 按「頭插」：改了幾個指標？再按「尾插」，走訪了幾個節點？
  2. 按「中間插入」（第 0 個節點後面）：看新節點先接哪裡、後接哪裡。
  3. 按「刪頭」，看被刪的節點變成虛線框後才消失。
  4. 重複幾次頭插到滿（6 個），看看會出現什麼提示。

猜猜看：這一步會發生什麼？

串列有 5 個節點，在最前面插入一個新節點，要改幾個指標？（對照上一篇：vector 要搬動 5 個元素）

選一個做法，看看對不對。

注意：這裡的「O(1)」有一個前提——你已經拿到要操作的位置（頭插是 head;insertAfter 是 prev）。如果要「在第 k 個之後插入」，光是找到第 k 個就要走訪 k 步。

完整程式：五個基本操作

這就是動畫裡用的函式，加上印出與清除。clear 會把每個節點 delete 掉，讓程式沒有記憶體洩漏。

main.cpp
#include <iostream>

struct Node {
    int val;
    Node* next;
};

struct List {
    Node* head = nullptr;
};

void pushFront(List& list, int value) {
    Node* node = new Node{value, list.head};
    list.head = node;
}

void pushBack(List& list, int value) {
    Node* node = new Node{value, nullptr};
    if (list.head == nullptr) {
        list.head = node;
        return;
    }
    Node* cur = list.head;
    while (cur->next != nullptr) {
        cur = cur->next;
    }
    cur->next = node;
}

void insertAfter(Node* prev, int value) {
    Node* node = new Node{value, prev->next};
    prev->next = node;
}

void eraseFront(List& list) {
    Node* old = list.head;
    list.head = old->next;
    delete old;
}

void eraseAfter(Node* prev) {
    Node* old = prev->next;
    prev->next = old->next;
    delete old;
}

void print(const List& list) {
    for (Node* cur = list.head; cur != nullptr; cur = cur->next) {
        std::cout << cur->val << " -> ";
    }
    std::cout << "null\n";
}

void clear(List& list) {
    while (list.head != nullptr) {
        eraseFront(list);
    }
}

int main() {
    List list;
    pushFront(list, 20);
    pushFront(list, 10);
    pushBack(list, 40);
    insertAfter(list.head->next, 30);        // 插在 20 後面
    print(list);
    eraseFront(list);
    eraseAfter(list.head);                   // 刪掉 20 後面的 30
    print(list);
    clear(list);                             // 全部 delete,避免洩漏
}
執行結果
10 -> 20 -> 30 -> 40 -> null
20 -> 40 -> null
編譯並執行（g++ 或 clang++ 皆可）
g++ -std=c++17 -Wall -Wextra -o main main.cpp
./main

三個要記住的小規則

規則
原因
插入：先設新節點的 next，最後才改 prev->next

和 vector 比：各有各的強項

n 是元素個數。「已拿到位置」表示你手上已經有 prev（或 head）。

平均 O(1)

實務上怎麼選？大多數時候 std::vector 就夠好，甚至更快：連續的記憶體對 CPU 快取比較友善，而鏈結串列的節點散在各處。鏈結串列的價值在於它讓你理解「用指標串起資料」，後面的樹、圖、雜湊表都是同一個想法。

實務上：std::list

std::list 是雙向鏈結串列，已經幫你寫好 push_front、push_back、insert、erase，也不用自己 delete。it 是「迭代器」，可以先當成「指向某個節點的位置」。

main.cpp
#include <iostream>
#include <list>

int main() {
    std::list<int> lst = {10, 20, 40};       // 雙向鏈結串列
    lst.push_front(5);                       // 頭插,O(1)
    lst.push_back(50);                       // 尾插,O(1)
    auto it = lst.begin();
    ++it;                                    // 往後走一個節點
    lst.insert(it, 15);                      // 插在 it 前面,O(1)
    lst.erase(lst.begin());                  // 刪掉第一個,O(1)
    for (int x : lst) {
        std::cout << x << " ";
    }
    std::cout << "\n";
}
執行結果
15 10 20 40 50

因為是雙向的，頭尾插入都是 O(1)。但它一樣沒有索引，lst[3] 是不能用的。只想要單向、更省空間時，有 std::forward_list。

初學者最常卡住的三個地方

插入時順序寫反：先改 prev->next，再設 node->next

下面這段可以編譯，但是會出問題：第一行改完之後，prev->next 已經是 node 自己，原本的下一個節點就弄丟了，而且 node->next 變成指向自己。

錯誤示範（不要執行）
// 錯誤示範:這份程式可以編譯,但執行會出問題,所以本站不執行它
struct Node {
    int val;
    Node* next;
};

void insertAfterWrong(Node* prev, int value) {
    Node* node = new Node{value, nullptr};
    prev->next = node;                       // 先改了 prev->next ...
    node->next = prev->next;                 // ... 這時 prev->next 已經是 node 自己了!
}

口訣：先接後面，再接前面。先讓新節點指向後面的人，最後才讓前面的人指向新節點。

走訪時沒檢查 nullptr,cur->next 當掉

如果 cur 本身已經是 nullptr，再寫 cur->next 就是對空指標取成員，程式會當掉。迴圈條件要寫對：走訪全部用 cur != nullptr；要停在最後一個節點用 cur->next != nullptr（而且要先確認串列不是空的）。

刪掉節點後記憶體洩漏，或 head 弄丟了

刪除第一個節點時，如果直接 list.head = list.head->next; 而沒有先記住舊的 head，舊節點就再也 delete 不到了。如果更慘，先 delete 了節點才去讀 old->next，那是在用已經還給系統的記憶體。順序是：記住 → 改指標 → delete。

動手演練：確認你真的懂了

動手寫（兩題）

兩題都是「走訪」：從 head 沿著 next 走到 nullptr。

第 1 題：數節點個數

完成 length，回傳串列有幾個節點。輸出應該是 3 0（最後的 0 是空串列）。

main.cpp
#include <iostream>

struct Node {
    int val;
    Node* next;
};

// 回傳串列有幾個節點(從 head 一路走到 nullptr)
int length(const Node* head) {
    int count = 0;
    // 在這裡寫迴圈
    (void)head;
    return count;
}

int main() {
    Node c{3, nullptr};
    Node b{2, &c};
    Node a{1, &b};
    std::cout << length(&a) << " " << length(nullptr) << "\n";   // 預期輸出 3 0
}
參考答案

用 cur 從 head 出發，只要不是 nullptr 就計數並往下走。時間是 O(n)。

完整答案
#include <iostream>

struct Node {
    int val;
    Node* next;
};

int length(const Node* head) {
    int count = 0;
    for (const Node* cur = head; cur != nullptr; cur = cur->next) {
        ++count;
    }
    return count;
}

int main() {
    Node c{3, nullptr};
    Node b{2, &c};
    Node a{1, &b};
    std::cout << length(&a) << " " << length(nullptr) << "\n";
}
執行結果
3 0

第 2 題：找出第一個值等於 target 的節點

完成 findNode，找不到回傳 nullptr。輸出應該是 20 -1。（這就是「插入之前要先找 prev」的那一步。）

main.cpp
#include <iostream>

struct Node {
    int val;
    Node* next;
};

// 在 list 的某個節點 prev 後面插入 value 之前,要先找到 prev。
// 回傳第一個 val 等於 target 的節點指標;找不到回傳 nullptr。
Node* findNode(Node* head, int target) {
    (void)head;
    (void)target;
    return nullptr;
}

int main() {
    Node c{30, nullptr};
    Node b{20, &c};
    Node a{10, &b};
    Node* p = findNode(&a, 20);
    std::cout << (p != nullptr ? p->val : -1) << " ";
    p = findNode(&a, 99);
    std::cout << (p != nullptr ? p->val : -1) << "\n";                // 預期輸出 20 -1
}
參考答案

一樣是走訪，每到一個節點就比較 val，相等就回傳它；走完都沒有就回傳 nullptr。

完整答案
#include <iostream>

struct Node {
    int val;
    Node* next;
};

Node* findNode(Node* head, int target) {
    for (Node* cur = head; cur != nullptr; cur = cur->next) {
        if (cur->val == target) {
            return cur;
        }
    }
    return nullptr;
}

int main() {
    Node c{30, nullptr};
    Node b{20, &c};
    Node a{10, &b};
    Node* p = findNode(&a, 20);
    std::cout << (p != nullptr ? p->val : -1) << " ";
    p = findNode(&a, 99);
    std::cout << (p != nullptr ? p->val : -1) << "\n";
}
執行結果
20 -1
