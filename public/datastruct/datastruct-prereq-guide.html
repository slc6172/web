指標只是「存別人地址的變數」，先搞懂它再往下學

鏈結串列、樹、圖都靠指標串起節點。這一篇用動畫把變數、參照、指標、struct 與 new/delete 講清楚，並教你怎麼編譯執行本站的範例。已經熟的人可以略過。

TL;DR 參照是別名，指標是存地址的變數；*p 走到它指的那格，p->x 走到節點再取成員；new 要配對 delete。

後面三分之二的主題，都靠指標把資料串起來

這一篇可以略過嗎？

如果你已經能說清楚 int* p = &x; 和 int& r = x; 的差別，也寫過 new/delete，可以直接跳到第 2 篇。

否則花 10 分鐘看完。鏈結串列、樹、圖的節點全都是「用指標指向下一個節點」，在這裡先把指標弄懂，後面會輕鬆很多。

這一篇要認識的名詞

名詞
白話說明
地址
每個變數在記憶體裡都佔一格，每一格有編號，就是地址。
參照 int& r = x;
替 x 取另一個名字。用 r 就是在用 x，沒有新的格子。
指標 int* p = &x;
一個變數，裡面存的是「別人的地址」。說「p 指向 x」。
解參考 *p
走到 p 指的那一格，讀或改裡面的值。
->
指標專用的箭頭：p->val 等於 (*p).val，走到節點再取成員。
nullptr
表示「不指向任何東西」。鏈結串列的最後一個節點，next 就是 nullptr。
& 和 * 會看錯，因為位置不同意思就不同int& r（宣告時）是參照，&x（運算時）是「取 x 的地址」；int* p（宣告時）是指標，*p（運算時）是「走到 p 指的那格」。看它前面有沒有型別。

動手玩：變數、參照與指標

下面逐行執行一段小程式。左邊是記憶體裡的變數，右邊是程式碼。看 x、r、p 三者怎麼互相影響。

  1. 到第 4 步，注意 r 是虛線框：它和 x 是同一格。
  2. 到第 5 步，看 p 裡存的是地址，不是 10。
  3. 第 6、7 步分別用指標和參照改 x，看 x 的變化。
  4. 第 8 步 p 改指 y,x 是不是還是 30?

猜猜看：這一步會發生什麼？

int x = 10; int* p = &x; *p = 20; 執行完，x 是多少？

選一個做法，看看對不對。
main.cpp
#include <iostream>

int main() {
    int x = 10;
    int y = 5;
    int& r = x;
    int* p = &x;
    *p = 20;
    r = 30;
    p = &y;
    *p = 99;
    std::cout << x << " " << y << "\n";
}
執行結果
30 99

動手玩：struct、new 與 ->

鏈結串列的節點就是一個 struct：裡面放資料，再放一個指向下一個節點的指標。這裡先用兩個節點練習 new、-> 與 delete。

  1. 第 2 步：new 在右邊 heap 做出節點，左邊的 a 存它的地址。
  2. 第 4 步：改 next，兩個節點就接起來了。
  3. 第 6、7 步：delete 之後節點變成虛線框，表示已還給系統。
main.cpp
#include <iostream>

struct Node {
    int val;
    Node* next;
};

int main() {
    Node* a = new Node{1, nullptr};
    Node* b = new Node{2, nullptr};
    a->next = b;
    std::cout << a->next->val << "\n";
    delete b;
    delete a;
}
執行結果
2
兩個新寫法Node{1, nullptr} 是依欄位順序一次填好 val 和 next。new 在 heap 要一塊空間並回傳地址；用 new 要來的，用完一定要 delete。

兩個之後會常看到的寫法：auto 與 lambda

auto 讓編譯器幫你推斷型別；lambda 是「沒有名字的小函式」，排序時常拿來寫比較規則（第 8、9 篇）。

main.cpp
#include <iostream>
#include <vector>

int main() {
    auto pi = 3.14;                          // auto:讓編譯器推斷型別(這裡是 double)
    std::vector<int> v = {1, 2, 3};
    auto square = [](int n) { return n * n; };   // lambda:沒有名字的小函式
    for (auto& e : v) {                      // auto& 拿到本尊,改 e 就是改 v 裡的元素
        e = square(e);
    }
    for (int e : v) {
        std::cout << e << " ";
    }
    std::cout << pi << "\n";
}
執行結果
1 4 9 3.14
寫法
意思
auto pi = 3.14;
pi 的型別由右邊決定（double）。
[](int n) { return n * n; }
lambda:[] 開頭，後面接參數和函式本體。可以存進 auto 變數，像一般函式一樣呼叫。
for (auto& e : v)
auto& 拿到元素本尊（參照），改 e 就是改 v；去掉 & 只是拿到複製品。

初學者最常卡住的三個地方

指標沒有初始化，或指到 nullptr 還去用

int* p; 只宣告、沒給值，裡面是亂數地址（野指標），用了會當掉或改壞別的資料。習慣寫成 int* p = nullptr;，並在用 -> 或 * 之前先檢查它不是 nullptr。

main.cpp
#include <iostream>

struct Node {
    int val;
    Node* next;
};

int main() {
    Node* p = nullptr;                       // 先明確寫成 nullptr:不指向任何東西
    if (p != nullptr) {
        std::cout << p->val << "\n";
    } else {
        std::cout << "p is null\n";          // 使用前先檢查,避免當掉
    }
}
執行結果
p is null
new 了卻忘記 delete（記憶體洩漏）

少了 delete，那塊空間要到程式結束才會被回收。小程式看不出來，但程式跑很久或 new 很多次就會越吃越多。規則很簡單：每個 new 對應一個 delete。用 -fsanitize=address 編譯執行，它會在結束時報告洩漏。

delete 之後又去用、或 delete 兩次

delete 之後，那個指標還存著舊地址，但那塊空間已經不屬於你。再讀寫或再 delete 一次，都是未定義行為。習慣上 delete 之後不要再碰它；需要時可以順手把指標設成 nullptr。

動手寫（兩題）

先在自己的電腦上試試，再展開參考答案。

第 1 題：用參照改呼叫者的變數（補一行）

addOne 要讓呼叫者的 x 加 1。補上那一行，輸出應該是 6。

main.cpp
#include <iostream>

void addOne(int& n) {
    // 在這裡加一行,讓呼叫者的變數加 1
}

int main() {
    int x = 5;
    addOne(x);
    std::cout << x << "\n";                  // 預期輸出 6
}
參考答案

因為參數 n 是參照，它就是 x 本尊，所以 ++n; 就會改到 x。

完整答案
#include <iostream>

void addOne(int& n) {
    ++n;
}

int main() {
    int x = 5;
    addOne(x);
    std::cout << x << "\n";
}
執行結果
6

第 2 題：交換兩個變數（完整寫出函式）

完成 swapInt，讓 a 和 b 的值對調。輸出應該是 7 3。提示：需要一個暫存變數。

main.cpp
#include <iostream>

// 寫一個 swapInt:交換呼叫者傳進來的兩個 int
void swapInt(int& a, int& b) {
}

int main() {
    int a = 3, b = 7;
    swapInt(a, b);
    std::cout << a << " " << b << "\n";      // 預期輸出 7 3
}
參考答案

先把 a 暫存起來，再把 b 放進 a，最後把暫存的放進 b。因為參數是參照，對調的是呼叫者的變數。

完整答案
#include <iostream>

void swapInt(int& a, int& b) {
    int tmp = a;
    a = b;
    b = tmp;
}

int main() {
    int a = 3, b = 7;
    swapInt(a, b);
    std::cout << a << " " << b << "\n";
}
執行結果
7 3
