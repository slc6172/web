切一半再處理，排序從 O(n²) 降到 O(n log n)

合併排序「分了再合」，快速排序「分區再遞迴」。這一篇用動畫看分治法怎麼運作，用實驗看差距有多大，並認識實務上的 std::sort。

TL;DR 合併排序：切一半、各自排好、合併，永遠 O(n log n)，要 O(n) 額外空間。快速排序：挑 pivot 分區再遞迴，平均 O(n log n),pivot 選很偏時最壞 O(n²)。實務上用 std::sort。

分治法：大問題切一半，各自解決再合起來

整理一大疊考卷

合併排序：把考卷分成兩半，請兩個人各自排好，最後把兩疊「已排好的」合併。合併很容易：兩疊最上面各看一張，每次取分數較小的那張。

快速排序：隨便抽一張當基準（pivot），把比它低分的放左邊、高分的放右邊，基準就定位了；再對左右兩堆各自重複。

為什麼會變快？

基礎排序要花 O(n²)，因為每個元素都和很多別的元素比較。分治法每次把問題切成一半，切到底只要約 log₂ n 層；每一層全部元素加起來只做約 n 次工作。所以總共是 n × log n。n = 100 萬時：n² 是 1 兆次，n log n 只有約 2 千萬次。

完整程式：合併排序與快速排序

兩個都是遞迴。merge 負責合併，partition 負責分區（回傳 pivot 最後的位置）。

main.cpp
#include <iostream>
#include <utility>
#include <vector>

void merge(std::vector<int>& v, std::vector<int>& tmp, int lo, int mid, int hi) {
    int i = lo;
    int j = mid + 1;
    int k = lo;
    while (i <= mid && j <= hi) {
        if (v[i] <= v[j]) {
            tmp[k++] = v[i++];
        } else {
            tmp[k++] = v[j++];
        }
    }
    while (i <= mid) {
        tmp[k++] = v[i++];
    }
    while (j <= hi) {
        tmp[k++] = v[j++];
    }
    for (int p = lo; p <= hi; ++p) {
        v[p] = tmp[p];
    }
}

void mergeSort(std::vector<int>& v, std::vector<int>& tmp, int lo, int hi) {
    if (lo >= hi) {
        return;
    }
    int mid = lo + (hi - lo) / 2;
    mergeSort(v, tmp, lo, mid);
    mergeSort(v, tmp, mid + 1, hi);
    merge(v, tmp, lo, mid, hi);
}

int partition(std::vector<int>& v, int lo, int hi) {
    int pivot = v[hi];
    int i = lo;
    for (int j = lo; j < hi; ++j) {
        if (v[j] < pivot) {
            std::swap(v[i], v[j]);
            ++i;
        }
    }
    std::swap(v[i], v[hi]);
    return i;
}

void quickSort(std::vector<int>& v, int lo, int hi) {
    if (lo >= hi) {
        return;
    }
    int p = partition(v, lo, hi);
    quickSort(v, lo, p - 1);
    quickSort(v, p + 1, hi);
}

void print(const std::vector<int>& v) {
    for (int x : v) {
        std::cout << x << " ";
    }
    std::cout << "\n";
}

int main() {
    std::vector<int> data = {38, 27, 43, 3, 9, 82, 10};
    int n = static_cast<int>(data.size());

    std::vector<int> a = data;
    std::vector<int> tmp(a.size());
    mergeSort(a, tmp, 0, n - 1);
    print(a);

    std::vector<int> b = data;
    quickSort(b, 0, n - 1);
    print(b);
}
執行結果（合併、快速）
3 9 10 27 38 43 82 
3 9 10 27 38 43 82

實測：n = 2000 時的比較次數

下面這份程式用固定的偽亂數資料，數出四種情況的比較次數（程式碼在你的電腦上也會得到一樣的數字）：

main.cpp（節錄：各排序前面加了 ++cmp）
#include <iostream>
#include <utility>
#include <vector>

long long cmp = 0;                           // 數比較次數

void bubbleSort(std::vector<int>& v) {
    int n = static_cast<int>(v.size());
    for (int i = 0; i < n - 1; ++i) {
        for (int j = 0; j < n - 1 - i; ++j) {
            ++cmp;
            if (v[j] > v[j + 1]) {
                std::swap(v[j], v[j + 1]);
            }
        }
    }
}

void merge(std::vector<int>& v, std::vector<int>& tmp, int lo, int mid, int hi) {
    int i = lo, j = mid + 1, k = lo;
    while (i <= mid && j <= hi) {
        ++cmp;
        tmp[k++] = (v[i] <= v[j]) ? v[i++] : v[j++];
    }
    while (i <= mid) {
        tmp[k++] = v[i++];
    }
    while (j <= hi) {
        tmp[k++] = v[j++];
    }
    for (int p = lo; p <= hi; ++p) {
        v[p] = tmp[p];
    }
}

void mergeSort(std::vector<int>& v, std::vector<int>& tmp, int lo, int hi) {
    if (lo >= hi) {
        return;
    }
    int mid = lo + (hi - lo) / 2;
    mergeSort(v, tmp, lo, mid);
    mergeSort(v, tmp, mid + 1, hi);
    merge(v, tmp, lo, mid, hi);
}

void quickSort(std::vector<int>& v, int lo, int hi) {
    if (lo >= hi) {
        return;
    }
    int pivot = v[hi];
    int i = lo;
    for (int j = lo; j < hi; ++j) {
        ++cmp;
        if (v[j] < pivot) {
            std::swap(v[i], v[j]);
            ++i;
        }
    }
    std::swap(v[i], v[hi]);
    quickSort(v, lo, i - 1);
    quickSort(v, i + 1, hi);
}

std::vector<int> makeData(int n, bool sorted) {
    std::vector<int> v(n);
    unsigned int x = 12345;
    for (int i = 0; i < n; ++i) {
        x = x * 1103515245u + 12345u;        // 簡單的偽亂數(固定種子,結果每次一樣)
        v[i] = sorted ? i : static_cast<int>((x >> 16) % 10000);
    }
    return v;
}

int main() {
    const int n = 2000;
    std::vector<int> tmp(n);

    std::vector<int> a = makeData(n, false);
    cmp = 0;
    bubbleSort(a);
    std::cout << "bubble (random)  : " << cmp << "\n";

    a = makeData(n, false);
    cmp = 0;
    mergeSort(a, tmp, 0, n - 1);
    std::cout << "merge  (random)  : " << cmp << "\n";

    a = makeData(n, false);
    cmp = 0;
    quickSort(a, 0, n - 1);
    std::cout << "quick  (random)  : " << cmp << "\n";

    a = makeData(n, true);
    cmp = 0;
    quickSort(a, 0, n - 1);
    std::cout << "quick  (sorted)  : " << cmp << "\n";
}
執行結果
bubble (random)  : 1999000
merge  (random)  : 19413
quick  (random)  : 24235
quick  (sorted)  : 1999000
你會看到隨機資料時，氣泡排序比了約 200 萬次，合併與快速只要約 2 萬次，差了 100 倍。但快速排序遇到「已排序」的資料，也掉到 200 萬次。

實務上：std::sort 與 std::stable_sort

std::sort 是快速排序、堆積排序與插入排序的混合體（introsort）：平常像快速排序一樣快，遇到會退化的情況就自動換方法，所以最壞也保證 O(n log n)。需要「相同的值維持原本順序」（穩定）時，用 std::stable_sort（以合併排序為基礎）。

main.cpp
#include <algorithm>
#include <iostream>
#include <string>
#include <vector>

struct Player {
    std::string name;
    int score;
};

int main() {
    std::vector<Player> players = {{"A", 90}, {"B", 85}, {"C", 90}, {"D", 85}};
    std::stable_sort(players.begin(), players.end(),
                     [](const Player& a, const Player& b) { return a.score > b.score; });
    for (const Player& p : players) {
        std::cout << p.name << ":" << p.score << " ";
    }
    std::cout << "\n";
}
執行結果（分數相同者維持原本的 A、C 與 B、D 順序）
A:90 C:90 B:85 D:85

初學者最常卡住的三個地方

快速排序遇到已排序的資料變成 O(n²)

如果每次都用最後一個當 pivot，而資料已經排好，pivot 永遠是最大的，每次分區只切掉 1 個，遞迴深度變成 n。上面實測就是 200 萬次。解法是隨機挑 pivot，或取頭、中、尾三個的中位數。std::sort 已經處理好了。

合併排序需要額外的 tmp 空間

合併時不能直接在原陣列裡覆蓋（會蓋掉還沒比較的元素），所以要借一塊同樣大小的暫存區。這是合併排序穩定、永遠 n log n 的代價：空間 O(n)。

邊界差一：lo >= hi、mid + 1、p - 1

遞迴的範圍是「閉區間」[lo, hi]。左半是 [lo, mid]，右半是 [mid + 1, hi]；快速排序在 pivot 位置 p 切開後，左邊是 [lo, p - 1]、右邊是 [p + 1, hi]（p 本身已定位）。少了 ±1 會無限遞迴或漏排。

第 1 題：合併兩個已排序的 vector

完成 mergeTwo：這就是合併排序裡 merge 的核心。輸出應該是 1 2 3 4 7 9 10。

main.cpp
#include <iostream>
#include <vector>

// 把兩個「已排序」的 vector 合併成一個新的、也是已排序的 vector。
// 這就是合併排序裡 merge 的核心:兩個指標 i、j 各指著 a 和 b 的最前面,每次取較小的。
std::vector<int> mergeTwo(const std::vector<int>& a, const std::vector<int>& b) {
    std::vector<int> result;
    (void)a;
    (void)b;
    return result;
}

int main() {
    std::vector<int> r = mergeTwo({1, 4, 7}, {2, 3, 9, 10});
    for (int x : r) {
        std::cout << x << " ";
    }
    std::cout << "\n";                       // 預期輸出 1 2 3 4 7 9 10
}
參考答案

兩個指標 i、j 各指著 a 和 b 的最前面，每次取較小的；一邊用完後，另一邊剩下的直接接上去。時間 O(n),n 是兩個加起來的長度。

完整答案
#include <iostream>
#include <vector>

std::vector<int> mergeTwo(const std::vector<int>& a, const std::vector<int>& b) {
    std::vector<int> result;
    int na = static_cast<int>(a.size());
    int nb = static_cast<int>(b.size());
    int i = 0;
    int j = 0;
    while (i < na && j < nb) {
        if (a[i] <= b[j]) {
            result.push_back(a[i++]);
        } else {
            result.push_back(b[j++]);
        }
    }
    while (i < na) {
        result.push_back(a[i++]);
    }
    while (j < nb) {
        result.push_back(b[j++]);
    }
    return result;
}

int main() {
    std::vector<int> r = mergeTwo({1, 4, 7}, {2, 3, 9, 10});
    for (int x : r) {
        std::cout << x << " ";
    }
    std::cout << "\n";
}
執行結果
1 2 3 4 7 9 10

第 2 題：用 lambda 做「多重條件」排序

完成 lambda：分數高的在前；分數相同時，名字小的在前。輸出應該是 Ann Dan Bob Cara。

main.cpp
#include <algorithm>
#include <iostream>
#include <string>
#include <vector>

struct Player {
    std::string name;
    int score;
};

int main() {
    std::vector<Player> players = {{"Cara", 80}, {"Ann", 90}, {"Bob", 80}, {"Dan", 90}};
    // 用 std::sort 排:分數高的在前;分數相同時,名字照字母順序(小的在前)。
    // 提示:在 lambda 裡先比分數,分數相同再比名字。
    std::sort(players.begin(), players.end(), [](const Player& a, const Player& b) {
        (void)a;
        (void)b;
        return false;
    });
    for (const Player& p : players) {
        std::cout << p.name << " ";
    }
    std::cout << "\n";                       // 預期輸出 Ann Dan Bob Cara
}
參考答案

先比分數；分數不同就用分數決定順序，分數相同再用名字決定。lambda 回傳「a 是否該排在 b 前面」。

完整答案
#include <algorithm>
#include <iostream>
#include <string>
#include <vector>

struct Player {
    std::string name;
    int score;
};

int main() {
    std::vector<Player> players = {{"Cara", 80}, {"Ann", 90}, {"Bob", 80}, {"Dan", 90}};
    std::sort(players.begin(), players.end(), [](const Player& a, const Player& b) {
        if (a.score != b.score) {
            return a.score > b.score;
        }
        return a.name < b.name;
    });
    for (const Player& p : players) {
        std::cout << p.name << " ";
    }
    std::cout << "\n";
}
執行結果
Ann Dan Bob Cara
