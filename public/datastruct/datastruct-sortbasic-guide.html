三種直覺的排序法都是 O(n²)，資料一多就撐不住

氣泡排序、選擇排序、插入排序，是最容易想到的三種排序。這一篇用長條圖逐步看它們怎麼動，並用實驗數出比較與交換次數。

TL;DR 氣泡：相鄰比較浮到右邊。選擇：挑最小放前面。插入：像整理手牌。三種最壞都是 O(n²)；資料幾乎排好時，氣泡與插入接近 O(n)。實務上用 std::sort。

排序是把一堆東西整理成有順序

三種你本來就會的整理法

氣泡排序：一排人由左往右，相鄰兩個比身高，左邊比較高就對調。走一趟，最高的會被一路換到最右邊。

選擇排序：從還沒排好的人裡找出最矮的，請他站到最前面；再從剩下的找最矮的，站到第二位……

插入排序：像整理手上的撲克牌。左邊那幾張已經排好，每抽一張新的，就把它插進左邊正確的位置。

為什麼要排序？

排好序之後，第 6 篇的二分搜尋才能用，重複的資料會相鄰、找最大最小也變得簡單。所以排序是很多演算法的第一步。

動手玩：長條圖逐步排序

長條越高，數字越大。選一種排序法、設定資料，一步步看它怎麼把長條排成由矮到高。右上的兩個計數器會告訴你它花了多少力氣。

  1. 用「隨機」資料，三種排序各跑一次，看比較次數。
  2. 按「已排序」，再跑氣泡排序和插入排序：發生什麼？
  3. 按「反向」（由大到小），看哪一種最辛苦。
  4. 試試自己輸入資料（2 到 10 個、1 到 99 的數字）。

猜猜看：這一步會發生什麼？

資料有 6 個、而且已經排好了（例如 1 2 3 4 5 6），用插入排序要比較幾次？

選一個做法，看看對不對。

做實驗：資料變多會怎樣？

這裡不播動畫，直接讓三種排序在同一份資料上跑完，數出比較與交換次數。拉大 n，看看數字怎麼成長；換不同的資料排列，看哪一種變快或變慢。

你應該會發現：n 變成 2 倍，比較次數大約變成 4 倍，這就是 O(n²)。已排序的資料對氣泡與插入排序很友善（幾乎只要 n − 1 次），但對選擇排序沒有幫助。

完整程式：三種排序

三個函式都「原地」排序：直接改傳進來的 vector，不需要額外的陣列。std::swap(a, b) 會交換兩個值。

main.cpp
#include <iostream>
#include <utility>
#include <vector>

void bubbleSort(std::vector<int>& v) {
    int n = static_cast<int>(v.size());
    for (int i = 0; i < n - 1; ++i) {
        bool swapped = false;
        for (int j = 0; j < n - 1 - i; ++j) {
            if (v[j] > v[j + 1]) {
                std::swap(v[j], v[j + 1]);
                swapped = true;
            }
        }
        if (!swapped) {
            break;
        }
    }
}

void selectionSort(std::vector<int>& v) {
    int n = static_cast<int>(v.size());
    for (int i = 0; i < n - 1; ++i) {
        int minIdx = i;
        for (int j = i + 1; j < n; ++j) {
            if (v[j] < v[minIdx]) {
                minIdx = j;
            }
        }
        std::swap(v[i], v[minIdx]);
    }
}

void insertionSort(std::vector<int>& v) {
    int n = static_cast<int>(v.size());
    for (int i = 1; i < n; ++i) {
        int key = v[i];
        int j = i - 1;
        while (j >= 0 && v[j] > key) {
            v[j + 1] = v[j];
            --j;
        }
        v[j + 1] = key;
    }
}

void print(const std::vector<int>& v) {
    for (int x : v) {
        std::cout << x << " ";
    }
    std::cout << "\n";
}

int main() {
    std::vector<int> data = {5, 2, 9, 1, 7, 3};
    std::vector<int> a = data;
    std::vector<int> b = data;
    std::vector<int> c = data;
    bubbleSort(a);
    selectionSort(b);
    insertionSort(c);
    print(a);
    print(b);
    print(c);
}

實務上：直接用 std::sort

自己手寫是為了理解。實務上直接用 std::sort：又快、又正確，下一篇會講它為什麼快。第二個參數那個 [](int a, int b) { return a > b; } 是 lambda（第 1 篇），用來告訴它「誰該排在前面」。

main.cpp
#include <algorithm>
#include <iostream>
#include <vector>

int main() {
    std::vector<int> v = {5, 2, 9, 1, 7, 3};
    std::sort(v.begin(), v.end());                       // 由小到大
    for (int x : v) {
        std::cout << x << " ";
    }
    std::cout << "\n";
    std::sort(v.begin(), v.end(), [](int a, int b) { return a > b; });   // 由大到小
    for (int x : v) {
        std::cout << x << " ";
    }
    std::cout << "\n";
}
執行結果
1 2 3 5 7 9 
9 7 5 3 2 1

空間：三種都只多用幾個變數，是 O(1)。但它們的最壞情況都是 O(n²)：資料一多就撐不住（n = 100 萬時要一兆次）。所以下一篇要學更快的排序。

初學者最常卡住的三個地方

內層迴圈的範圍寫錯，越界讀到 v[n]

比較 v[j] 和 v[j + 1] 時，j 最大只能到 n - 2，否則 v[j + 1] 就超出範圍（第 3 篇的越界）。氣泡排序的 j < n - 1 - i 同時也把「已排好的右邊」排除在外。

條件寫 >= 而不是 >

兩個值相等時沒有必要交換。多交換不但浪費時間，還會讓「相等元素的原本順序」被打亂（排序的穩定性）。比較用 >，相等不動。

給 std::sort 的比較規則寫成 <=

比較函式要回答「a 是不是嚴格排在 b 前面」，a <= b 對相等的元素也回 true，違反規則，在某些資料上可能導致當掉。想由大到小排，寫 a > b，不是 a >= b。

第 1 題：補上交換的條件

把 if (false) 改成正確的條件，輸出應該是 1 2 3 4。如果想改成由大到小排，條件要怎麼改？

main.cpp
#include <iostream>
#include <utility>
#include <vector>

// 在 bubbleSort 的內層迴圈裡,「該不該交換」的條件是什麼?補上它。
// 如果想改成由大到小排,條件要怎麼改?
void bubbleSort(std::vector<int>& v) {
    int n = static_cast<int>(v.size());
    for (int i = 0; i < n - 1; ++i) {
        for (int j = 0; j < n - 1 - i; ++j) {
            if (false) {                     // 把 false 改成正確的條件
                std::swap(v[j], v[j + 1]);
            }
        }
    }
}

int main() {
    std::vector<int> v = {4, 3, 1, 2};
    bubbleSort(v);
    for (int x : v) {
        std::cout << x << " ";
    }
    std::cout << "\n";                       // 預期輸出 1 2 3 4
}
參考答案

左邊比右邊大就交換：v[j] > v[j + 1]。由大到小只要把 > 改成 <。

完整答案
#include <iostream>
#include <utility>
#include <vector>

void bubbleSort(std::vector<int>& v) {
    int n = static_cast<int>(v.size());
    for (int i = 0; i < n - 1; ++i) {
        for (int j = 0; j < n - 1 - i; ++j) {
            if (v[j] > v[j + 1]) {
                std::swap(v[j], v[j + 1]);
            }
        }
    }
}

int main() {
    std::vector<int> v = {4, 3, 1, 2};
    bubbleSort(v);
    for (int x : v) {
        std::cout << x << " ";
    }
    std::cout << "\n";
}

第 2 題：完成插入排序的兩個空格

完成 while 的條件，和最後把 key 放回去的那一行。輸出應該是 1 2 3 4。

main.cpp
#include <iostream>
#include <vector>

// 這個版本的插入排序是在「已排序的 v[0..i-1]」裡,從後面往前找 key 該放的位置。
// 請完成 while 的條件,以及迴圈之後把 key 放回去的那一行。
void insertionSort(std::vector<int>& v) {
    int n = static_cast<int>(v.size());
    for (int i = 1; i < n; ++i) {
        int key = v[i];
        int j = i - 1;
        while (false) {                      // 把 false 改成正確的條件(提示:要同時檢查 j 沒有越界、v[j] 比 key 大)
            v[j + 1] = v[j];
            --j;
        }
        // 把 key 放到正確的位置(提示:現在的 j 是第一個「不比 key 大」的位置)
    }
}

int main() {
    std::vector<int> v = {4, 3, 1, 2};
    insertionSort(v);
    for (int x : v) {
        std::cout << x << " ";
    }
    std::cout << "\n";                       // 預期輸出 1 2 3 4
}
參考答案

條件：j >= 0 && v[j] > key（順序不能反，要先確認沒越界）。迴圈結束時 j 指在「第一個不比 key 大」的位置，所以 key 放在 v[j + 1]。

完整答案
#include <iostream>
#include <vector>

void insertionSort(std::vector<int>& v) {
    int n = static_cast<int>(v.size());
    for (int i = 1; i < n; ++i) {
        int key = v[i];
        int j = i - 1;
        while (j >= 0 && v[j] > key) {
            v[j + 1] = v[j];
            --j;
        }
        v[j + 1] = key;
    }
}

int main() {
    std::vector<int> v = {4, 3, 1, 2};
    insertionSort(v);
    for (int x : v) {
        std::cout << x << " ";
    }
    std::cout << "\n";
}
執行結果
1 2 3 4
