堆疊後進先出，佇列先進先出，兩端的操作都是 O(1)

堆疊像一疊盤子，佇列像排隊買票。這一篇用動畫看 push 與 pop，再用 stack 解決經典的括號配對問題。

堆疊是一疊盤子，佇列是排隊買票

兩個生活比喻

堆疊（stack）像一疊盤子：新盤子只能放在最上面，要拿也只能拿最上面那個。最後放進去的，最先拿出來（後進先出，LIFO）。

佇列（queue）像排隊買票：新來的人排到隊伍最後面，服務永遠從最前面開始。最先排隊的，最先離開（先進先出，FIFO）。

名詞對照

名詞
白話說明
push
放進去。stack 放在頂端；queue 排到最後面。
pop
拿出來。stack 拿頂端；queue 拿最前面。
top(stack)
只看頂端是誰，不拿走。
front / back(queue)
最前面的人 / 最後面的人。
LIFO / FIFO
Last In First Out（後進先出）/ First In First Out（先進先出）。
它們的重點是「限制」stack 和 queue 都只讓你碰「一端」或「兩端」，不能隨便存取中間。這個限制讓用法很清楚，操作也都很快(O(1))。

動手玩：堆疊 push 與 pop

這個 Stack 是用上一篇學過的 vector 包起來的：push 就是 push_back,pop 就是取尾端再 pop_back。尾端就是頂。

  1. 依序 push 1、2、3（把數值改成 1、2、3，各按一次「push」）。
  2. 按一次「pop」：取出的是哪一個？
  3. 再 pop 兩次，看看順序，然後試著對空 stack 再 pop。

猜猜看：這一步會發生什麼？

依序 push 1、2、3，然後 pop 一次，取出來的是？

選一個做法，看看對不對。
main.cpp
#include <iostream>
#include <vector>

struct Stack {
    std::vector<int> data;

    void push(int x) {
        data.push_back(x);
    }

    int pop() {
        int x = data.back();
        data.pop_back();
        return x;
    }

    bool empty() const {
        return data.empty();
    }
};

int main() {
    Stack st;
    st.push(1);
    st.push(2);
    st.push(3);
    while (!st.empty()) {
        std::cout << st.pop() << " ";
    }
    std::cout << "\n";
}
執行結果（後進先出）
3 2 1

動手玩：佇列 push 與 pop

佇列一樣用 vector 包，但多一個 head 記著「最前面是第幾格」。pop 不搬資料，只是把 head 往後移。（這個簡化版不會回收離開的格子；真正的 std::queue 會。）

  1. 依序 push 1、2、3，看 front 與 back 標籤。
  2. pop 一次：這次取出的是哪一個？和 stack 比較。
main.cpp
#include <iostream>
#include <vector>

struct Queue {
    std::vector<int> data;
    int head = 0;                            // 隊伍最前面在 data 的哪個位置

    void push(int x) {
        data.push_back(x);
    }

    int pop() {
        return data[head++];
    }

    bool empty() const {
        return head == static_cast<int>(data.size());
    }
};

int main() {
    Queue q;
    q.push(1);
    q.push(2);
    q.push(3);
    while (!q.empty()) {
        std::cout << q.pop() << " ";
    }
    std::cout << "\n";
}
執行結果（先進先出）
1 2 3
你會看到同樣依序放進 1、2、3:stack 取出 3 2 1,queue 取出 1 2 3。

實務上：std::stack 與 std::queue

標準函式庫已經幫你寫好了，直接 #include <stack>、<queue> 就能用。

main.cpp
#include <iostream>
#include <queue>
#include <stack>

int main() {
    std::stack<int> st;
    st.push(1);
    st.push(2);
    st.push(3);
    std::cout << "stack top = " << st.top() << "\n";   // 只能看頂端
    st.pop();                                          // pop() 不回傳值
    std::cout << "stack top = " << st.top() << "\n";

    std::queue<int> q;
    q.push(1);
    q.push(2);
    q.push(3);
    std::cout << "queue front = " << q.front() << ", back = " << q.back() << "\n";
    q.pop();                                           // 移除最前面的
    std::cout << "queue front = " << q.front() << ", size = " << q.size() << "\n";
}
執行結果
stack top = 3
stack top = 2
queue front = 1, back = 3
queue front = 2, size = 2
注意：pop() 不會回傳值在 std::stack 與 std::queue 裡，pop() 只負責移除、回傳 void。要先用 top()（或 front()）讀出來，再 pop()。我們自己寫的版本為了簡單，才讓 pop 回傳值。

實戰：用 stack 檢查括號配對

寫程式時，( [ { } ] ) 必須成對、而且不能交叉。想想看：最後打開的括號，一定要最先關上，這正是「後進先出」。

  1. 按「配對正確」預設，看左括號進 stack、右括號配對消掉。
  2. 按「交叉」預設：([)] 在哪一步失敗？
  3. 自己輸入一個字串試試。
main.cpp
#include <iostream>
#include <stack>
#include <string>

bool matches(char open, char close) {
    return (open == '(' && close == ')') ||
           (open == '[' && close == ']') ||
           (open == '{' && close == '}');
}

bool isBalanced(const std::string& s) {
    std::stack<char> st;
    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') {
            st.push(c);
        } else if (c == ')' || c == ']' || c == '}') {
            if (st.empty()) {
                return false;
            }
            char open = st.top();
            st.pop();
            if (!matches(open, c)) {
                return false;
            }
        }
    }
    return st.empty();
}

int main() {
    const char* tests[] = {"{[()]}", "([)]", "((())", "())", "a(b)c"};
    for (const char* t : tests) {
        std::cout << t << " -> " << (isBalanced(t) ? "balanced" : "not balanced") << "\n";
    }
}
執行結果
{[()]} -> balanced
([)] -> not balanced
((()) -> not balanced
()) -> not balanced
a(b)c -> balanced

流程只有三條：左括號就 push；右括號就看頂端能不能配、配得上就 pop；走完時 stack 要是空的。每個字元只處理一次，時間 O(n)。

初學者最常卡住的三個地方

對空的 stack 或 queue 取 top() / front() / pop()

這是未定義行為，可能當掉、也可能讀到亂值。習慣先檢查 empty()。

main.cpp
#include <iostream>
#include <stack>

int main() {
    std::stack<int> st;
    if (!st.empty()) {                       // 先檢查,再 top() / pop()
        std::cout << st.top() << "\n";
        st.pop();
    } else {
        std::cout << "stack is empty\n";
    }
}
執行結果
stack is empty
int x = st.pop(); 編不過

因為 std::stack::pop() 回傳 void。正確寫法是 int x = st.top(); st.pop();，兩個步驟。

用 vector 當 queue，每次 erase(v.begin()) 會很慢

從 vector 最前面刪除要把後面全部往前搬(上一篇的 O(n))。要用 queue 就用 std::queue，或像本篇用 head 索引記錄前端位置。

第 1 題：用 stack 反轉字串

完成 reverseString。輸出應該是 cba kcats。

main.cpp
#include <iostream>
#include <stack>
#include <string>

// 用 stack 把字串反過來:"abc" → "cba"
std::string reverseString(const std::string& s) {
    std::stack<char> st;
    // 1. 把每個字元 push 進去
    // 2. 一個個 pop 出來接成新字串
    (void)s;
    return "";
}

int main() {
    std::cout << reverseString("abc") << " " << reverseString("stack") << "\n";   // 預期輸出 cba kcats
}
參考答案

先全部 push，再一個個取頂端接起來。後進先出，所以順序剛好反過來。

完整答案
#include <iostream>
#include <stack>
#include <string>

std::string reverseString(const std::string& s) {
    std::stack<char> st;
    for (char c : s) {
        st.push(c);
    }
    std::string result;
    while (!st.empty()) {
        result += st.top();
        st.pop();
    }
    return result;
}

int main() {
    std::cout << reverseString("abc") << " " << reverseString("stack") << "\n";
}
執行結果
cba kcats

第 2 題：只有一種括號時，不用 stack

完成 isBalancedParen。輸出應該是 100（依序是三個字串的結果）。想想：為什麼多種括號時就不行了？

main.cpp
#include <iostream>
#include <string>

// 只有一種括號 ( ) 時,不需要 stack,一個計數器就夠了。
// 遇到 ( 加 1,遇到 ) 減 1;中途變成負數,或最後不是 0,都不配對。
bool isBalancedParen(const std::string& s) {
    (void)s;
    return false;
}

int main() {
    std::cout << isBalancedParen("(())") << isBalancedParen("(()") << isBalancedParen("())(") << "\n";   // 預期輸出 100
}
參考答案

只有一種括號時，只要記得「目前有幾個沒關的左括號」，一個計數器就夠。多種括號時，還得記得是哪一種、順序是什麼，所以需要 stack。

完整答案
#include <iostream>
#include <string>

bool isBalancedParen(const std::string& s) {
    int depth = 0;
    for (char c : s) {
        if (c == '(') {
            ++depth;
        } else if (c == ')') {
            --depth;
            if (depth < 0) {
                return false;
            }
        }
    }
    return depth == 0;
}

int main() {
    std::cout << isBalancedParen("(())") << isBalancedParen("(()") << isBalancedParen("())(") << "\n";
}
執行結果
100
