C++ 演算法 · 第 11 篇 · 二元樹與走訪

同一棵樹，換個「處理自己」的時機，走訪順序就不同

二元樹的每個節點最多有左右兩個子節點。這一篇用動畫看前序、中序、後序（遞迴）與層序（queue）如何走過每個節點。

TL;DR 一棵樹 = 根 + 左子樹 + 右子樹，所以走訪用遞迴最自然。前序、中序、後序只差「印出自己」那一行的位置；層序改用 queue 一層層走。走訪都是 O(n)。

樹：一層一層往下分岔的資料

像家族圖，或電腦的資料夾

資料夾裡有子資料夾，子資料夾裡又有子資料夾……這就是樹。最上面只有一個起點（根），每個節點往下連到它的子節點。

這一篇的二元樹規定：每個節點最多兩個子節點，分別叫「左」和「右」。你在第 4 篇學的鏈結串列，其實就是「每個節點只有一個子節點」的樹。

名詞對照

名詞
白話說明

最上面的節點，沒有父節點。
葉（leaf）
沒有任何子節點的節點。

一個節點往下連到的，是它的子；反過來是父。

某個節點和它底下的全部。一棵樹 = 根 + 左子樹 + 右子樹，這正是遞迴的形狀。
高度
從根到最遠的葉，最長的那條路上有幾個節點。
走訪（traversal）
把每個節點恰好看過一遍的方式，順序有好幾種。
節點長這樣跟第 4 篇的鏈結串列節點很像：struct TreeNode { int val; TreeNode* left; TreeNode* right; };，多了一個指標。沒有子節點時，指標是 nullptr。

動手玩：四種走訪，看順序怎麼來

選一棵樹、一種走訪法，按「下一步」。橘色是目前所在的節點，綠色是已經印出來的。上面的「呼叫堆疊」（前、中、後序）或 queue（層序）會顯示目前的狀態。

  1. 用完全二元樹跑前序、中序、後序：同一棵樹，印出來的順序差在哪？
  2. 看遞迴版的 nullptr 返回：每個葉的左右兩邊都會呼叫一次。
  3. 跑層序，看 queue 怎麼讓同一層的節點「一起排隊」。
  4. 換成鏈狀的樹，看呼叫堆疊最深能到多深。

猜猜看：這一步會發生什麼？

對完全二元樹做後序走訪（左 → 右 → 根），根節點 1 會在什麼時候印出來？

完整程式：四種走訪

前、中、後序的程式碼幾乎一模一樣，只差印出那一行放在哪裡：遞迴呼叫左子樹之前（前序）、兩個呼叫之間（中序）、之後（後序）。層序則不用遞迴，改用 queue。

main.cpp
#include <iostream>
#include <queue>

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
};

void preorder(const TreeNode* node) {
    if (node == nullptr) {
        return;
    }
    std::cout << node->val << " ";
    preorder(node->left);
    preorder(node->right);
}

void inorder(const TreeNode* node) {
    if (node == nullptr) {
        return;
    }
    inorder(node->left);
    std::cout << node->val << " ";
    inorder(node->right);
}

void postorder(const TreeNode* node) {
    if (node == nullptr) {
        return;
    }
    postorder(node->left);
    postorder(node->right);
    std::cout << node->val << " ";
}

void levelOrder(const TreeNode* root) {
    if (root == nullptr) {
        return;
    }
    std::queue<const TreeNode*> q;
    q.push(root);
    while (!q.empty()) {
        const TreeNode* node = q.front();
        q.pop();
        std::cout << node->val << " ";
        if (node->left != nullptr) {
            q.push(node->left);
        }
        if (node->right != nullptr) {
            q.push(node->right);
        }
    }
}

void destroy(TreeNode* node) {
    if (node == nullptr) {
        return;
    }
    destroy(node->left);                     // 先刪子樹
    destroy(node->right);
    delete node;                             // 最後才刪自己(後序)
}

int main() {
    TreeNode* root = new TreeNode{1,
        new TreeNode{2, new TreeNode{4, nullptr, nullptr}, new TreeNode{5, nullptr, nullptr}},
        new TreeNode{3, new TreeNode{6, nullptr, nullptr}, new TreeNode{7, nullptr, nullptr}}};
    preorder(root);
    std::cout << "\n";
    inorder(root);
    std::cout << "\n";
    postorder(root);
    std::cout << "\n";
    levelOrder(root);
    std::cout << "\n";
    destroy(root);
}
執行結果（依序：前序、中序、後序、層序）
1 2 4 5 3 6 7 
4 2 5 1 6 3 7 
4 5 2 6 7 3 1 
1 2 3 4 5 6 7
編譯並執行（g++ 或 clang++ 皆可）
g++ -std=c++17 -Wall -Wextra -o main main.cpp
./main
最後的 destroy 是後序釋放整棵樹時，要先 delete 左右子樹，最後才 delete 自己。如果先刪自己，就再也找不到子樹了（和第 4 篇鏈結串列的 old 一樣的道理）。這份程式用 -fsanitize=address 檢查過，沒有洩漏。

注意 h 的角色：同樣 n 個節點，樹長得「矮胖」還是「又高又瘦」，會影響很多操作的速度。下一篇的二元搜尋樹會看到這個差別。

初學者最常卡住的三個地方

忘了先檢查 nullptr

遞迴走訪的第一件事一定是 if (node == nullptr) return;。少了它，走到葉子的子節點（nullptr）就會去讀 node->val，程式當掉。這就是遞迴的基底條件（第 7 篇）。

分不清前序、中序、後序

只看「根在什麼時候被處理」：根在最前面 → 前序；根在左右之間 → 中序；根在最後 → 後序。左一定在右前面，三種都是。

樹很深時遞迴會爆掉

鏈狀的樹有 n 層，遞迴走訪就是 n 層呼叫堆疊（第 7 篇）。節點數幾萬以上、又很不平衡時，可能 stack overflow。這是平衡樹很重要的原因之一。

動手寫（兩題）

兩題都用「一棵樹 = 根 + 左子樹 + 右子樹」的遞迴想法。

第 1 題：數節點個數

完成 countNodes。輸出應該是 3 0。

main.cpp
#include <iostream>

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
};

// 回傳這棵樹有幾個節點。空的樹(nullptr)是 0 個。
// 提示:節點數 = 1(自己)+ 左子樹節點數 + 右子樹節點數
int countNodes(const TreeNode* node) {
    (void)node;
    return 0;
}

int main() {
    TreeNode c{3, nullptr, nullptr};
    TreeNode b{2, nullptr, nullptr};
    TreeNode a{1, &b, &c};
    std::cout << countNodes(&a) << " " << countNodes(nullptr) << "\n";   // 預期輸出 3 0
}
參考答案

基底條件：空的樹有 0 個節點。否則 = 1（自己）+ 左子樹節點數 + 右子樹節點數。

完整答案
#include <iostream>

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
};

int countNodes(const TreeNode* node) {
    if (node == nullptr) {
        return 0;
    }
    return 1 + countNodes(node->left) + countNodes(node->right);
}

int main() {
    TreeNode c{3, nullptr, nullptr};
    TreeNode b{2, nullptr, nullptr};
    TreeNode a{1, &b, &c};
    std::cout << countNodes(&a) << " " << countNodes(nullptr) << "\n";
}
執行結果
3 0

第 2 題：算樹的高度

完成 height：最長路徑上的節點數。輸出應該是 3 1 0。

main.cpp
#include <algorithm>
#include <iostream>

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
};

// 回傳樹的高度:最長的那條路徑上有幾個節點。空的樹是 0,只有一個節點是 1。
// 提示:高度 = 1 + max(左子樹高度, 右子樹高度)
int height(const TreeNode* node) {
    (void)node;
    return 0;
}

int main() {
    TreeNode d{4, nullptr, nullptr};
    TreeNode c{3, &d, nullptr};
    TreeNode b{2, nullptr, nullptr};
    TreeNode a{1, &b, &c};
    std::cout << height(&a) << " " << height(&d) << " " << height(nullptr) << "\n";   // 預期輸出 3 1 0
}
參考答案

空的樹高度 0；否則高度 = 1 + 左右兩邊較高的那個。用 std::max 取較大值。時間 O(n)。

完整答案
#include <algorithm>
#include <iostream>

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
};

int height(const TreeNode* node) {
    if (node == nullptr) {
        return 0;
    }
    return 1 + std::max(height(node->left), height(node->right));
}

int main() {
    TreeNode d{4, nullptr, nullptr};
    TreeNode c{3, &d, nullptr};
    TreeNode b{2, nullptr, nullptr};
    TreeNode a{1, &b, &c};
    std::cout << height(&a) << " " << height(&d) << " " << height(nullptr) << "\n";
}
執行結果
3 1 0
